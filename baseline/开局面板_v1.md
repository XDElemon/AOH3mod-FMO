## 三、实现（无一处手写 smali）

```
data/tno_opening_layout.json        版式唯一真源
tools/gen_tno_opening_assets.py     生成 6 张贴图（面板底图/页签/导航/海报）
tools/gen_tno_opening.py            生成两个新 smali 类 + 注入 MenuManager 钩子
tools/selftest_tno_opening.py       汇编前自检（标签/极性/引用/版式）
baseline/build_candidate.sh         换 dex + 注素材 + 对齐签名 + 三重自检
```

新增两个类（5,530 → 5,532）：

- `menusInGame/TNO_PanelImage` extends `Button`
  - 一张贴图 + 可选文字 + 点击回调；`mode` 0 装饰 / 1..4 切页 / 10·11 翻页 / 12 关闭
  - 重写 `draw()` 绕开 `Button.draw` 的"不可点→45% 透明"分支
- `menusInGame/TNO_OpeningScreen` extends `Menu`
  - 构造时算几何 → 建 15 个元素 → `initMenu(菜单矩形外扩 offX/offY)` 
  - `showPage(i)`：正文显隐 + 页签换图 + 功能页要点显隐
  - `doClose()`：先 `takeEventDecision` 给事件结案（避免读档重弹），再 `actionCloseMenu()`

挂载点：`MenuManager.rebuildInGame_Event()` 开头判 `event.id == "TNO_opening"`，
把 `IN_GAME_EVENT` 槽换成 `TNO_OpeningScreen`（与 `InGame_Event` 同一槽位、同一套
`setVisible + setOrderOfMenu` 流程）。事件侧只需 `popUp=true`（默认是 false！）。

## 四、踩过的坑（都写进了自检）

1. **元素坐标是相对 `menuPosX` 的**。`drawMenuElements` 里屏幕 X = `element.posX + menuPosX`，
   而 `initMenu` 会把 menuPosX 设成面板位置 —— 直接写绝对坐标会**偏两倍**。
   → 元素坐标必须写成 `面板内偏移 + 面板坐标`。
2. **分支极性**。`if-lt/if-ge`、`if-eq/if-ne` 写反不会汇编失败，只会"点了没反应"。
   首版连续写错 6 处（页签高亮、正文显隐、要点显隐、翻页回绕、关闭空判）。
   → `tools/selftest_tno_opening.py` 的 S2 项专门盯这批判断，已用变异测试验证能抓到。
3. **寄存器上限**。`move/iput/iget` 等 12x/22c 指令只能用 v0..v15；
   参数从 `registers - 参数个数` 起算。为塞下 `Button.init` 的 11 个参数，
   构造函数改成 `flags = (mode<<1)|clickable` 压成 6 个参数。
4. **`Event.popUp` 默认 false**，不显式写 `popUp=true` 就不会弹面板。
5. **贴图懒注册**。6 张图在 `TNO_OpeningScreen.<clinit>` 里 `ImageManager.addImage`，
   不用改 `InitGame.loadImages_1()`（960 个静态字段的坑绕开）。
