## 调研回填 1：现有防空拦截机制（2026-10-25，子代理报告）

**结论：AD 是项目自建的「按回合、按省」系统，不是原版机制；目标写死 `AirMission`，不能原样拿来拦 AGM/ALBM。**

| 关键事实 | 内容 |
|---|---|
| 触发 | `AirForceManager.updateAll()` 末尾 → `AirDefense.tickTurn()`，每回合一次（不是按帧） |
| 开火条件 | 本省有 AAA 阵地（`airDefenseAt>0`），阵地数 = 本回合发数；无弹药/无冷却 |
| 命中率 | 每发 **80%**（`adHitChance`），过 roll 后伤害**固定 50**，无末端判定 |
| 目标 | 只扫 `activeMissions` 里的 `AirMission`（敌国+交战+有活机+射程内），**不按任务类型过滤** |
| 结算 | 可见：逐帧追到才爆；不可见：`tickHits` 按 `due+12h/48h/10s` 兜底 |
| 目标绑定 | 16 个 `ad*` 字段挂在 `AirMission`；11 个方法签名全是 `AirMission` |

**对 AGM/ALBM 的结论**
- 不能复用「管线」，只能复用零件：命中率常数、固定伤害、`AirLat` 射程数学、弹迹绘制数学；
- **绝不能**把导弹伪装成 `AirMission` 塞进 `activeMissions`：`recordLoss` 会调 `sourceAirport.removeAircraft` 且无空检查（NPE），还会污染 30+ 个消费者；
- 推荐：新建 `StrikeMissile` 状态（`civID/hp/provinceID/worldX/Y/targetRef/intercepted`）+ 一份 `AdIntercept`（`due/dmg/fx*`），拦截在**发射时/终端**判定；地面伤害入口先检查 `intercepted`；
- 触发时机要选：现有 AD 只在回合末开火，同一回合内发射并命中的弹来不及拦 → 走「发射时判定」或「终端判定」，不要依赖 `tickAll`。

**附带发现（建议单独修）**：AD 射程的「雷达加成」极性疑似反了——无雷达 130、有雷达+长波反而 100；而红圈按正确的 100/130 画，会出现「圈内打不到、圈外能打到」。门禁 `check_airrange.py` / `sim_airrange.py` 的语义也反了，所以一直是绿的。

## S5/S6 拦截设计（按上述结论）

- **AGM**：低空可见 → 发射时按路径省/目标省 AAA 做 1 次拦截 roll；拦下则空中爆炸，没拦下继续飞；可见弹迹可复用 `adFxStep` 数学。

## 调研回填 2：ALBM 能打掉什么（2026-10-25，子代理报告）

**一句话：城市不是独立可损伤对象，打城市 = 打它所在的省；机场是"建筑+Airport 对象"两层，没有耐久，只能拆或减容量。**

| 目标 | 推荐改的值 | 说明 |
|---|---|---|
| 城市（=省） | **人口**（按族比例扣 10–30%）+ **荒废度**（+0.25~0.5，封顶 0.5）+ **经济**（-10~30%，下限 0.1） | 三个值都存盘、有慢恢复；荒废最长效（约 100 个月才退），经济立刻影响预算 |
| 机场（部分损伤） | `Airport.maxCapacity -= 10` + 按比例 `removeAircraft`（只删 `!isInFlight`） | 挡新建 + 干掉部分停放飞机；持久化到存档 |
| 机场（彻底瘫痪） | 先 `clearPatrolForAirport`，再 `destroyBuilding(空军基地)` | 建筑拆了，机场/雷达自动注销；停放飞机随对象消失 |
| 驻军（可选） | 每团 `num -= 比例`，然后 `ArmyDivision.updateArmy(true)` | 不刷会显示旧强度 |

**收尾刷新（必须做，否则面板/预算看不到）**
`updateProvinceIncome()` → `gameThread.addCivUpdateTotalIncomePerMonth(civID)` → `updateProvinceValue()` → 玩家面板 `rebuildInGame_ProvinceInfo(true)`。
经济改动用 `updateAfterEconomyChange()`。

**已知坑（实现时避开）**
1. `setDevastation` 内部的收入刷新是死代码（阈值 6.0 vs 荒废上限 0.5）——必须自己刷；
2. `setPopulationOfCivID` 正常路径恒返回 false，别拿返回值判成功；
3. `executeAttack` 改经济/人口后不刷收入——ALBM 别照抄；
4. `unregisterAirport` 的 null 判断写反（`if-nez` 应为 `if-eqz`），靠每帧 `syncAirports()` 兜底；
5. 拆机场前不 `clearPatrolForAirport` 会留孤儿任务；
6. 省份面板不自动重读，要 `rebuildInGame_ProvinceInfo(true)`。
