## 总原则

1. 核战（战术核弹/核 ALBM）是独立大类，**不在本线**；核字段只保留数据，不接逻辑。
2. 原版类不许新增分支/算术（`gate_java_first`）；能力判定走 Java / 生成物。
3. 每步：数据 → 生成器 → stage 同步 → 闸门 4/4 → 变更范围 → 出包 → 台账。
4. 每步都要有"负样本"（先红后绿）或真机验收口径。

## S2 空空导弹闸门

**改动**：`AirModelStats.missileCountOf(aid)` / `missileRangeOf(aid)` 对 `CanAAMissile=false` 的机型返回 0。
弹池初始化 0 ⇒ `strikeKind=2`（dry）⇒ 一发都打不出；`missileTick` 一行不改。

**验收**：J-20（有 AAM）能打；F-117（无 AAM）在拦截任务里也打不出；`nMS dry` 日志可见。负样本：把 `missileCountOf` 改回不看 flag，B 系列/真机复现。

## S3 对地机炮（只打陆军师）

**口径**：`CanAGGun=true` 的机型，对**陆军师**（敌方 army division）造成伤害，不打省/建筑/机场。

**设计要点**
- 触发：任务进入对地攻击状态、目标为敌方陆军师、距离满足（同省/邻省）。
- 伤害：`groundAttack` 或单独系数；是否消耗 `currentPayload` 待定（用户口径"只打师"，但弹药制未定）。
- 表现：第一版可以只结算、不加曳光特效。
- 实现位置：`AirMission.executeAttack` 已有对地路径；用 Java 助手做判定，原版类只加 invoke。

**待定**：是否消耗挂载、是否受防空拦截（机炮扫射近距，倾向不拦）。

## S4 取消原版战略轰炸（大改动，AI 受影响）

**现状（4 个创建点）**
| 位置 | 方法 | 归属 |
|---|---|---|
| `AirForceManager:394` | `a1Dispatch(II)Z` | AI 调度 |
| `AirForceManager:3982` | `createMissionForClick(Airport;I)` | 玩家点击创建 |
| `AirForceManager:6457` | `executeAIAssignmentForAirport(Airport)` | AI 机场任务分配 |
| `AirForceManager:12011` | `tryStrikeForAirportP(Airport;Random;AirType)` | AI 出击尝试 |

**约束**
- `MissionType.STRATEGIC_BOMBING` **不能删枚举值**（ordinal 进存档；删了会串档）。只能"不再创建"。
- 旧存档里已存在的战略轰炸任务：允许飞完/或读档时转成 `ATTACK_ARMY`——二选一，需拍板。
- UI：创建入口（按钮/任务类型选择）要隐藏或禁用。

**AI 影响**
- 三处 AI 创建点关掉后，AI 的轰炸机会没有任务 → 需要回退策略：
  a) 改派 `ATTACK_ARMY`（对陆军）；
  b) 暂时让轰炸机待命（会明显削弱 AI）；
  c) 等 ALBM（S6）上线后再给轰炸机新任务。
- 建议先 a，避免 AI 空转；S6 上线后再切 ALBM。

**验收**：玩家点不出战略轰炸；AI 不再生成该类型任务；旧档读入不崩；AI 仍有对地/对空任务可做。

## S5 空地导弹 AGM

**已定口径**
- 目标：**只打陆军师**；
- 射程：**按飞机自己的配置**（建议新增每机型 `AGMRange`，单位同 `MissileRange`；缺省继承 `MissileRange`）；
- 可被防空拦截。

**设计要点**
- 发射：任务在射程内选敌方陆军师 → 消耗弹（每机 N 发，`MaxPayload` 或新字段）。
- 飞行：定时命中（1–3 游戏小时），不依赖相机；表现可后加。
- 拦截：进入敌方防空圈按能力判定，拦下则空中爆炸。
- 伤害：对陆军师兵力，数值待定。

**依赖**：防空拦截调研报告（现有 AD 只打 `AirMission`，需扩展目标类型或新列表）。

## S6 常规空射弹道 ALBM

**已定口径**
- 目标：**可点名机场/城市**；
- 载机：`capabilities.CanALBM=true`；
- **可被防空拦截**（用户明确）。

**设计要点**
- 发射：战略轰炸机在任意距离（或 3+ 省）选敌方省份内的机场/城市。
- 飞行：高空、快、固定时间；只给发射/命中特效，不逐帧画。
- 拦截：只给 1 次拦截机会（避免战略弹太廉价），命中判定与 AGM 共用一套。
- 伤害：**待"省份/城市/机场可削减数值"调研报告**——预计改人口/发展/建筑/驻军中的 2–3 项，并处理刷新顺序。
