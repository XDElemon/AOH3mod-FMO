# 真机验收清单（基线包 / 候选包）

> 目的：验证 **PairIP 剥壳是否奏效**、以及候选批次的代际改动是否生效。
> 这一步只能真机做；静态验证（结构指纹、门禁、签名）已全部通过。

## 0. 前置

- 包名：`age.of.history3.polaris.xuanxing`（**不是** `qiamxi.zhiri`，两者互不覆盖）
- 两个包都是 debug 签名，**与官方包签名不同**，若已装同包名版本必须先卸载
- 建议先备份 `Android/data/age.of.history3.polaris.xuanxing/`（若存在）

## 1. 装基线包

```bash
adb install -r /sdcard/Download/fmo_baseline/fmo_baseline.apk
# 或手机文件管理器点开安装
```

**期望**：安装成功（约 741 MB，耗时较长）。若失败：

| 现象 | 含义 |
|---|---|
| `INSTALL_FAILED_UPDATE_INCOMPATIBLE` | 有同包名旧版，先 `adb uninstall age.of.history3.polaris.xuanxing` |
| `INSTALL_FAILED_INSUFFICIENT_STORAGE` | 空间不足（需 ≥2 GB 余量） |
| 解析失败 | 包损坏，核对 md5 |

## 2. 启动（**关键判据**）

点开图标，观察 5 秒内：

| 现象 | 判定 |
|---|---|
| 正常进入主菜单 | ✅ PairIP 剥壳成功 |
| 闪退（无界面） | ❌ 多半是 PairIP 校验或 Application 类问题，抓 logcat |
| 卡在黑屏/白屏 | ⚠️ 资源或 dex 校验问题，抓 logcat |
| 提示"请从官方渠道下载" | ❌ PairIP 许可校验仍在生效 |

抓日志：

```bash
adb logcat -c
adb shell am start -n age.of.history3.polaris.xuanxing/aoc.kingdoms.lukasz.jakowski.AndroidLauncher
sleep 8
adb logcat -d > /sdcard/Download/fmo_baseline/log_baseline.txt
```

关注 `FATAL EXCEPTION`、`VerifyError`、`NoClassDefFoundError`、`pairip`、`SecurityException`。

## 3. 基线包的功能核对

- 主菜单可见、能新建剧本、科技树能打开（说明 5,530 类与壳资源匹配）
- 机场界面里飞机图标**显示为占位文字图**（说明 149 张占位素材生效）
- 若某处显示 `imageNotFound` → 记下位置，追加到占位清单

## 4. 候选包（可选，验证代际）

```bash
adb install -r /sdcard/Download/fmo_baseline/fmo_candidate_gen.apk
```

差异只在 `unitGenOf`：5/6 代机应拿到 4 发导弹（原为全部 2 发）。

- 观察点：机场任务面板里 `missilePerPlane` 的读数（调试版可看 `airdbg` 日志）
- 若 5/6 代仍是 2 发 → `bestIdx` 返回 -1 或无匹配机型，属预期兜底，需补数据

## 5. 回滚

```bash
adb uninstall age.of.history3.polaris.xuanxing
# 或装回官方包
```
