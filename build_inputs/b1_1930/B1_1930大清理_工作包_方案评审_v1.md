## 二、判定顺序与规则

1. **冻结输入**：记录原始 99 节点逐项 `ID/Name/TreeColumn/TreeRow/RequiredTech/RequiredTech2/所有效果字段`、文件校验和、引用台账；记录源数据和输出的 diff。非 `assets_r6t007` 工作树的实际 APK 覆盖关系，须由本地工具链确认（待验证）。
2. **选择删除对象**：仅以 `TreeColumn <= 26` 为条件；满足条件的旧节点必须精确等于 `{0,1,…,66,96}`。剩余旧节点必须精确等于 `{67,…,95,97,98}`。这里的“1930”是本次**约定的列分界**，不是对每个节点史实年代的判断（旧 67/68 等一战条目依决定保留）。
3. **添加 R1 根**：建议内部键 `ModernTechFoundation`，`ID:0`、`TreeColumn:26`、`TreeRow:2`、`RequiredTech:-1`、`RequiredTech2:-1`、`Repeatable:false`、`AI:5`、`ResearchCost:250`（新参数，方案值、待真机确认；成本参照旧根 0 `Library`）。新根占用已被清空的 col26 是**新节点视觉布局**，不是保留旧科技。`ImageID:0` 借用已有图标；名称本地化必须查实所用目录、双语键名，不允许无依据填路径。
4. **重编号，保持原始数组顺序**：输出先放新根，再按源文件的**顺序**放旧 `67..95、97、98`；更新每个新节点 `ID` 为新列表下标，目标为 `ID == index`。此策略是针对当前旧数据 `ID == index` 的防位移设计；加载时 ID/下标是否严格等价、UI/存档是否按哪一种引用，必须用本地代码断言和探针核验（待验证）。
5. **前置转换**：所有保留节点的 `RequiredTech` / `RequiredTech2`，旧值 `-1` 保持 `-1`；旧值属于保留集合则用映射；旧值属于被删集合则重挂到新根 `0`。若两条前置变成同一个根，保留一条根前置、另一条设 `-1`。当前源数据可见旧 `67 EarlyFighter` 的前置为 `65/66`、旧 `68 EarlyTank` 为 `66/64`：建议两者都变为 `(0,-1)`。其余节点前置全量跑审计，不凭主观推定。
6. **外部引用归一**：对各字段先识别真实语义，判明是科技 ID、列表下标、枚举 ID、还是与科技无关的普通数字；按**字段上下文**迁移，绝不能全仓替换数字。保持 `-1` 原语义；保留旧科技者走 ID 映射；指向被删科技者，按各领域基线功能重挂至根 `0` 或经审阅的等价保留科技；逐条记录旧/新值及决策原因。不将未知或非法值悄悄替换为根。
7. **静态门禁**：数量、ID 唯一、索引一致、前置闭合、无自环/环路、字段类型、数组长度相容、外部引用命中范围、差异白名单；全部通过才进本地工具链测试。
8. **发布门禁**：B2 完成保留剧本下标重算、删除旧剧本，并在真机证明开局后，才允许将 B1+B2 组合包发给玩家。

## 五、CivDefault_Technology 下标重算（B1 产出算法，B2 执行）

文档 `r6s5/方案_1930分界大清理_v1.md` §1.4 根据 `Civilization.buildTechTree_UnlockTechnologies(I)` 指出：`CivDefault_Technology` 置位的是**列表下标**，而非简单复用旧数字。重算流程：

1. 取 B1 冻结的 `oldList`（不按 `TreeColumn` 排序），逐项生成 `oldIndex → (旧 ID, Name, 其他识别字段)`。
2. 根据 B1 新 `newList` 生成 `oldIndex/旧 ID → newIndex`，要求旧保留 ID 在源内唯一；重复 `Name`（如 WarTactics、FutureTechnology）禁止单凭名称匹配。
3. 对保留剧本的 `Details.json` 读取原 `CivDefault_Technology`，定位目标原节点；如果目标删除，不能简单钳到 0：需逐剧本指定一个具有对应年代意义的保留节点或根并留下审查说明。
4. 代入新索引，并按源码记载验证“解锁本项 + 递归补双前置”的真实执行。剧本 `Data.json` 的每文明 `TechnologyID` 用字段实际语义另行映射（不能未经验证直接套 Details 的规则）。
5. 对每个剧本输出 `tag,oldValue,oldTarget,newValue,newTarget,递归解锁集合对比,测试状态`。脚本必须断言 `newList[newValue]` 是期望节点、而非只看数值合法。

**6 个保留剧本的候选映射（仅是对已读取 `Details.json` 及拟定 ID/index 顺序的静态推导；B2 装机复核）：**

| `qianxi` (2000) | 81 | ModernInfantry | **15** | ModernInfantry |
