## 2. 语义依据（读取链，只读留证）
- **Scenarios.txt**：单行分号表；`MapScenarios.smali :9184+` 按 `;` 解析并拼 `map/…/scenarios/<name>/Details.json` 路径（菜单项=列表项）。
- **CivDefault_Technology**：`MapScenarios$Details:34` 字段；`Civilization.buildTechTree()`（5400+）在"civ 自身 TechnologyID == DEFAULT(-2)"时用之调用 `buildTechTree_UnlockTechnologies(I)`。
- **TechnologyID（Data.json 每文明）**：`ScenarioCivData:50` 字段；`>=0` 直用；`==DEFAULT(-2)` 用剧本默认；`Unlock(I)` = `lTechResearched.set(I,true)` + TechQueue1/2（**下标语义**）。
- 本批映射沿用 B1 的 MAP；旧值 ∈ 被删集合（≤66）→ `0`（公共根）。USA_States 的 `-2` 为 DEFAULT 哨兵 → **不动**；其余保留剧本无 TechnologyID 行。
