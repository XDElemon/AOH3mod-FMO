# 【铁律】机型编号：枚举序号顺序 ≠ 字段声明顺序（2026-10-01 r6d124 血案）

## 一、血案
r6d124 我以为"图配错了"，把机场界面 4 处**图索引**改了 → 图与按钮错位，用户看到"贴图和按钮的顺序被换了"。
真相：**图一直是对的**，错的是**左边文字**。

## 二、根因
`AirUnit$AirType` 的 smali **字段声明顺序**是：
```
ATTACKER, BOMBER, FIGHTER, INTERCEPTOR   ← 这是"声明序"，不是序号！
```
但 **`values()` 的序号顺序由 `<clinit>` 的实例化顺序决定**：
```
values()[0]=INTERCEPTOR  [1]=FIGHTER  [2]=BOMBER  [3]=ATTACKER
```
⇒ 我之前按"声明序"推断编号，全错。**判定枚举序号必须读 `<clinit>`，绝不能看 `.field` 顺序。**

## 三、项目里现存的两套机型编号（必须逐点对照）

换算：`airNameForTypeP ← AirType`：0→3、1→2、2→1、3→0（即 `3-k`）
　　　`pickAirImage ← AirType`：0→2、1→3、2→0、3→1
