# 铁律与坑 · r6d137（本批新增部分，其余沿用 r6d125 台账）

## 一、本批新增血案（★★★ 必读）

### ① 分支极性写反 = 合法指令 + 语义反，验证器抓不到
- **症状**：国家读对了（探针 `a=73/226` 正确），但卡片图**仍然不变**。
- **错误规则**：`if-ge v6, v0, :retorig`（v6=国家ID，v0=0）⇒ 语义是「国家 ≥ 0 就跳到原样返回」⇒ **国家有效时反而早退**。
- **正确规则**：`if-lt v6, v0, :retorig` ⇒ 「国家 < 0（无效）才原样返回」。
- **为什么之前会错**：手写跳转助记时按「小于 0 就跳走」的中文语序写成了 `if-ge`；汇编器完全接受，验证器也过。
- **唯一发现手段**：r6d135 的返回值探针 `CARDRET` **0 行** ⇒ 断定「从未走到返回新编号」⇒ 回头查跳转极性。

### ② 读外部状态必须抽成独立小方法
- r6d131/132/134 三次证明：同一读法「放在大方法里读不到、放进独立方法读得到」。
- **对策**：`activeArmyCiv()I` 这种一行调用的小方法，是**必需**而非风格偏好。

### ③ 探针「0 行」是最高价值信号
- 不要反复猜，先看探针有没有输出；0 行 ⇒ 逻辑未走到，立刻转去查前置分支。

### ④ 「谁 new 了它」反查法
- 按钮类变体共 6 个（`ButtonUnit` / `_02` / `_03` / `3` / `3_2` / `3_3`），名字不含使用场景。
- 全树只有 `InGame_ListOfUnits` 一个面板 new 卡片按钮，用的是 **`ButtonUnit_03`** ⇒ 靠反查才定位到真靶。

### ⑤ 装机 apk 必须先落到 `/data/local/tmp/`
- 直接给 `/sdcard/Download/xxx.apk` ⇒ `avc: denied { read } … fuse` ⇒ `Can't open file` ⇒ 失败。
- 正确：`cp` 到 `/data/local/tmp/` → `sh toolchain/autotap_install.sh /data/local/tmp/xxx.apk <log>`。

## 四、本批新增事实

- 卡片图真身＝`armyImages[ Data_Army.ImageID ]`；`Data_Army` 是「兵种模板」，不是「某支部队」。
- 图库是**全局单一序列**，编号不按国家分；`armyID` 是「等级/代」不是国家 ⇒ **只能运行时按国家选图**。
- `Game.hoveredArmy` 在编制面板**恒为 0**（死字段）；`Game.activeArmy[iActiveID]` 索引语义错；正解＝`Game.activeArmy.get(0)`。
- 图库前缀 `{H,XH,XXH}` 来自 `CFG.getRescouresPath_Short()`，是**画质后缀，不是国家**。
- 卡片规格：**200×118，蓝底 RGB(0,70,142)**，飞机居中（高≈92px，宽超 188 时按宽缩）。
- 素材文件名有别名：`俄罗斯四代战机SU-57.png`（「战机」而非「战斗机」）⇒ 生成脚本需别名判定（先长词后短词）。
