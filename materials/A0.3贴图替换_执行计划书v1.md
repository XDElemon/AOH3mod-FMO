## 3. 甲策略执行步骤（分布明确）

### Step 1　备份（防回滚）
```
mkdir -p /sdcard/GLG/历史23/kb_assets/backup_airimg/
cp 母本→当前生效图（从 dbg_signed.apk 解出 C1 四图 + unitsImages 12 张）→ backup_airimg/
# 或直接 zip 包内 cp（推荐直接解包一份 dbg_signed.apk 的 assets/game/AirUnit/ 与 units/unitsImages/）
```

### Step 2　素材整理（Gen3/CN → 规范命名）
从**母本 APK** 解出：
```
assets/game/AirUnit/AirUnitlmages/Gen3/CN/{INTERCEPTOR,FIGHTER,BOMBER,ATTACKER}.png  ×4
```
→ 暂存 `/tmp/airimg_src/`（300×200 RGBA，带透明）。

### Step 3　生成三层缩放（C2 缩略图）
目标：**保持目标层既有格式**（PIL 处理，勿用工具截图）：
| 目标层 | 目标尺寸 | 目标模式 | 处理 |
|---|---|---|---|
| H | 200×118 | RGB | 300×200 RGBA → resize → **合成到 RGB**（透明改白底或黑底？——**用白底合成**，原版缩略图无透明；若飞机图主体带深色，白底观感最稳；实施时先出一张 sample 给用户看） |
| XH | 266×157 | RGB | 同上 |
| XXH | 332×196 | RGBA | resize 原样保留 alpha |

> 说明：libGDX 加载链 `loadTexture_RGB888`（RGB 层）/ RGBA（XXH）——格式与层匹配即可，**非 2 次幂尺寸项目已实证可用**（200×118 现役正常）。

示例（PIL）：
```python
from PIL import Image
src = Image.open('/tmp/airimg_src/FIGHTER.png')          # 300x200 RGBA
out = src.resize((200,118), Image.LANCZOS)
bg = Image.new('RGB', out.size, (255,255,255))
bg.paste(out, mask=out.split()[3]) if out.mode=='RGBA' else bg.paste(out)
bg.save('/tmp/airimg_out/H/67.png')
```
（66=Intercept/67=Fighter/68=Bomber/69=Attacker 映射，**与 Air*.json ImageID 对齐**）

### Step 4　生成 C1/C3 地图图标（4 张直接替换）
```
/tmp/airimg_out/AirUnitlmages/{INTERCEPTOR,FIGHTER,BOMBER,ATTACKER}.png
= Gen3/CN 对应原图（300×200 RGBA 原样，无需缩放）
```

### Step 5　接入 mkzip.py（新增 16 个 replace 键）
```python
# —— A0.3 贴图（甲·静态基线）——
replace['assets/game/AirUnit/AirUnitlmages/INTERCEPTOR.png'] = open('/tmp/airimg_out/AirUnitlmages/INTERCEPTOR.png','rb').read()
replace['assets/game/AirUnit/AirUnitlmages/FIGHTER.png']     = open('/tmp/airimg_out/AirUnitlmages/FIGHTER.png','rb').read()
replace['assets/game/AirUnit/AirUnitlmages/BOMBER.png']      = open('/tmp/airimg_out/AirUnitlmages/BOMBER.png','rb').read()
replace['assets/game/AirUnit/AirUnitlmages/ATTACKER.png']    = open('/tmp/airimg_out/AirUnitlmages/ATTACKER.png','rb').read()
for _l in ['H','XH','XXH']:
    for _i in ['66','67','68','69']:
        replace[f'assets/game/units/unitsImages/{_l}/{_i}.png'] = open(f'/tmp/airimg_out/unitsImgs/{_l}/{_i}.png','rb').read()
# 注意：既有的 A0.2 键 unitsImages 66-69（kb_assets 源）必须由本步骤**覆盖**（同一键，后写者胜；或直接改 A0.2 键的源路径为本步产物）
```
> 键冲突处理（经验）：A0.2 在 mkzip.py 已注册 `unitsImages/{H,XH,XXH}/66..69.png`（源=kb_assets）——**把它们统一替换为本步产物路径**，避免同键二次 replace 报错（教训 10）。
