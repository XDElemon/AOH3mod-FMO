mods/YOUR_MOD_NAME/game/events/common/

如何创建新的活动/任务
七海天明子汉化

##### STEP 1 #####
如果要设置全局事件那么在下面的路径中创建新的txt文件:
game/events/common/

或者，如果这是场景的事件，那么路径将是:
map/Earth3/scenarios/WW2/events/common/

Earth3是地图，WW2是场景.


将其命名为（此处是测试文档，请将该命名为你自己事件的名字）: economys_golden_milestone.txt


也可以将其创建在你的mod文件夹下:
game/events/common/economys_golden_milestone.txt
->
mods/NAME_OF_YOUR_MOD/game/events/common/economys_golden_milestone.txt

或

map/Earth3/scenarios/WW2/events/common/economys_golden_milestone.txt
->
mods/NAME_OF_YOUR_MOD/map/Earth3/scenarios/WW2/events/common/economys_golden_milestone.txt

##### STEP 2 #####

不要在代码中使用空格！！

// -- 示例代码

id=economys_golden_milestone
title=economys_golden_milestone.t
desc=economys_golden_milestone.d
mission_desc=economys_golden_milestone.m

popUp=false

// -- 结束

id=NAME_OF_THE_FILE
title=NAME_OF_THE_FILE.t
desc=NAME_OF_THE_FILE.d
mission_desc=NAME_OF_THE_FILE.m

popUp=false

#重要的
mission_desc是可选的，只有在任务视图中显示此任务时才需要

我们现在添加了一个事件id（仅适用于游戏）、标题（密钥）、描述（密钥）和可选任务描述（密钥
在这个例子中，我将使用“economy_gold里程碑”作为NAME_OF_THE_FILE

popUp=true
popUp=false
# 如果是真的，这个事件会在屏幕上弹出！默认值为false.

possible_to_run=false
# 如果为false，则该事件无法主动启动，只能由其他事件运行

在使用事件选项时：
run_event=german_ultimatum

其中“german_ultimatum”是要运行的事件的id。

// -- 示例

trigger_and
next_and
invested_in_economy_over=1
next_or
civ_provinces_over=10
trigger_and_end

trigger_and
next_and
civ_gold_over=75
trigger_and_end

// -- 结束

在这个例子中，我们有两个单独的触发条件.
如果文明在经济上投资超过1个，或者文明拥有10个以上的省份，则将激活第一个触发条件。此触发方式为 AND(trigger_and)
如果文明的预算中有超过75枚金币，第二个触发条件将被激活。此触发方式为AND(trigger_and)

在这种情况下，如果两个触发条件都为真，则会弹出事件。


让我们为事件创建一个触发条件

# 首先是开始 'AND'
trigger_and

# 内部触发条件

trigger_and_end
# 结束 'AND'


#您可以在一个事件中使用多个触发方式
##您可以从以下选项中进行选择：

trigger_and
trigger_and_end
#全部满足

trigger_and_not
trigger_and_not_end
#全都不满足

trigger_or
trigger_or_end
#有一个满足

trigger_or_not
trigger_or_not_end
#有一个不满足

### 内部触发条件

# 内部触发条件 'AND'

next_and
invested_in_economy_over=1

#结束 'AND'

next_and
# The next line inside the trigger will be "and"
invested_in_economy_over=1
#在这个例子中，一个文明必须在其经济中投资超过1个经济点。

You must always choose what type the next inside trigger will be, in this case we have used "next_and".
## 您可以从以下选项中进行选择:
next_and
next_and_not
next_or
next_or_not


# 您可以在一个触发条件中使用多个内部触发条件
