## 1. 空军系统数据结构（冻结）

### 1.1 AircraftTypeData（JSON 条目类，19 字段）
| 字段 | 类型 | 说明 |
|---|---|---|
| ID | int | 机型ID（JSON=1..4） |
| Name | String | INTERCEPTOR/FIGHTER/BOMBER/ATTACKER |
| CanAttackAir / CanAttackGround | boolean | 能力位 |
| AirAttack / GroundAttack / Defense / Agility / Speed / Stealth / Ecm / MaxFuel / FuelConsumption / CombatRadius / RadarRange | float | 战斗/航程参数 |
| MaxPayload | int | 挂载量 |
| CostGold / ConstructionTime / RequiredTechID | int | 建造参数（applyType未使用，供UI/建造使用） |

### 1.2 实际加载的文件与容器
- 文件：`game/AirUnit/AircraftTypes.json`（**硬编码，load() 只读此文件**）
- 容器：`ConfigAircraftData.AircraftTypes: ArrayList<AircraftTypeData>`（libGDX Json 解析，`setElementType(AircraftTypes)`）
- 解析失败：catch 后 `loaded=true`、`types=null`（静默降级，无报错）

### 1.3 AirType 枚举（数组索引 = ordinal）
`INTERCEPTOR=0, FIGHTER=1, BOMBER=2, ATTACKER=3` —— types[] 顺序必须与 JSON 数组顺序一致（当前原版 JSON 顺序恰好匹配✅）

### 1.4 AirUnit（运行时单位，30+字段）
type/typeID/civID/unitID(long,currentTimeMillis)/airportID(-1=无)/maxHp,hp(=Defense*2)/defense/airAttack/groundAttack/agility/speed/stealth/ecm/maxFuel,fuel/fuelConsumption/combatRadius/radarRange/maxPayload,currentPayload/canAttackAir/canAttackGround/currentMission(AirUnit$Mission)/currentTarget(Object)/distanceToTarget/roundsInFlight/isAlive/isShotDown/isInFlight
- 构造器 `AirUnit(AirType, civID)` → `applyTypeDefaults()` → `AircraftDataManager.applyType()`；**加载失败时 fallback 默认值**（燃料100/耗油10/半径500/速度500/HP30/防15/载荷2）
- 行为：`canAttackGround()`=payload>0&&位；`canIntercept()`=canAttackAir；`consumeFuel()`=燃料-耗油，≤0 返回 false（坠毁判定由调用方）

### 1.5 AirUnit$Mission 枚举
`AIR_PATROL=0, INTERCEPT=1, GROUND_ATTACK=2, RETURNING=3, IDLE=4`

### 1.6 AirMission（任务，1100行）
- 枚举：MissionType（PATROL/STRATEGIC_BOMBING/AIR_SUPERIORITY/ATTACK_ARMY/INTERCEPT 等，以 create 方法为准）；MissionState（PLANNING=0, EN_ROUTE=1, EXECUTING=2, RETURNING=3, COMPLETED=4, ABORTED=5，以 packed-switch 索引为准）
- 字段：assignedAircraft/aliveAircraft/lostAircraft/targetAirUnitIDs/targetArmyID/targetProvinceID/sourceAirport/sourceProvinceID/civID/type/state/roundsInFlight/distanceToTarget/flightProgress/maxAttackRounds/attackRoundsExecuted/maxLingerRounds/lingerRounds/totalDamageDealt/enemyAircraftShotDown/missionID
- 创建：createPatrol / createStrategicBombing / createAirSuperiority / createAttackArmy / createIntercept（静态工厂，含目标指派与机型选择）
- update()：PLANNING→(EN_ROUTE, 置GROUND_ATTACK)→EN_ROUTE 逐回合推进(roundsInFlight<distanceToTarget, 耗油, 全损→ABORTED)→EXECUTING(executeAttack, lingerRounds++, shouldReturn→RETURNING)→RETURNING 逐回合返航(RETURNING=COMPLETED→returnToBase)
- 辅助：calculateDistance(centerX_Real/Y_Real 欧氏距离)、consumeFuel、executeAttack、returnToBase、shouldReturn、recordDamage/Kill/Loss、allAircraftLost

### 1.7 AircraftDataManager 方法
- `load()`：一次加载（loaded 标志），只读 AircraftTypes.json（如上）
- `applyType(AirUnit)`：types==null → 写默认值；否则 ordinal 索引 types[]→写全部战斗字段；**索引越界/空元素→直接 return（静默无默认值）**；maxHp = Defense*2

### 1.8 AirForceManager（单例，1827行）
- 字段：allAirports: Map<civID,List<Airport>>, radarProvinces: Set<Integer>, activeMissions: List<AirMission>, selectedAirports, multiSelectMode
- 机场：registerAirport(provinceID,civID)（建 Airport(provinceID,civID,1) + load()）、syncAirports（无建筑→移除）、hasAirportBuilding（检查 BuildingsManager.AIRPORT_BUILDING_ID）、registerRadar/unregisterRadar/syncRadar
- 射程：getAircraftRange(type)=types[ordinal].CombatRadius（null→300，≤0→500）；canReach=欧氏距离≤CombatRadius；getProvincesInRange；**isInRange 硬编码 800.0f（未用类型数据！）**
- 回合：updateAll()=syncAirports+syncRadar+updateMissions+updateAirCombat+逐civ update(I)（每步 try-catch 静默）；update(civID)=updateBuild+updateDeployedCount+executeAIAssignment+updatePatrols
- AI：executeAIAssignment(civID)：仅 Airport.mode==AI 的机场；战争中 30%概率 createStrategicBombing(敌省)，和平 50%概率 createPatrol(本国随机省=getRandomBorderProvince 实际取 FIGHTER 航程内本国省)
- updateMissions：**⚠️ 核心 bug（见 §2）**

### 1.9 Airport（573行）
- Airport(provinceID, civID, int)（registerAirport 传 1）；Mode 枚举（AI/PATROL/手动？以 smali 为准）；updateBuild()/updateDeployedCount()

### 1.10 建筑 ID 机制
- BuildingsManager.loadBuildings() 读 `game/buildings/Buildings.json`：`Name[0]=="空军基地"`→AIRPORT_BUILDING_ID=索引(34)；`Name[0]=="雷达"`→RADAR_BUILDING_ID=索引(35)；失败→保持 -1 且静默
- Province.smali 建造完成回调中：building==AIRPORT_BUILDING_ID → registerAirport(province,civID)（两处：建造+bonus更新）
- 关键约束：**Name[0] 必须是精确字符串"空军基地"/"雷达"**，改动 JSON 名称会静默失效

## 2. 已确认的 Bug（严重级）

| # | 位置 | 现象 | 根因 |
|---|---|---|---|
| B1 | AirForceManager.updateMissions() | **所有任务1回合后被清空，空军任务系统整体瘫痪** | 条件分支写反：仅 state==COMPLETED 走移除分支；任何非 COMPLETED 状态（EN_ROUTE/EXECUTING/RETURNING/PLANNING/ABORTED）也落入 remove() |
| B2 | assets/game/AirUnit/Aircraft.json | 该文件**完全不被代码读取**，作者修改无效 | load() 硬编码 AircraftTypes.json；Aircraft.json 且为损坏 JSON（ID:1 后缺逗号） |
| B3 | Aircraft.json 字段 `nCanAttackAir` 等 | 即使被读取也与 AircraftTypeData 字段名不匹配 | 字段名带 n 前缀，而解析类字段无前缀 |
| B4 | AirForceManager.isInRange() | 射程判定与机型数据无关 | 硬编码 800.0f（应为 getAircraftRange） |
| B5 | getRandomBorderProvince() | 命名为"边界省"，实为"FIGHTER 航程内任意本国省" | 实现与语义不符（影响 AI 巡逻点质量，非致命） |
| B6 | AircraftDataManager.applyType() 越界/空元素 | 静默返回，飞机保留构造默认值 | 与 B1 叠加导致"飞机存在但不干活"观感 |
| B7 | updateAll() 每步 try-catch 吞异常 | 任何空军异常被静默（CFG.exceptionStack 仅日志） | 排查困难，行为退化 |

**结论**：以 B1 为主因（任务被删→无作战行为），B2/B3 为作者数据层改造失败（两个并存文件、双份不一致 schema），B4-B7 为质量缺陷。M1 最小修复集 = B1 + B2/B3 统一 schema + B4 + B7 降噪。

## 3. 核战争系统盘点（M3 锚点）

**已有（AoH3 原版能力）**
- 生产：核电站（建筑 ImageID94）→ Civilization.updateNukeProduction(turns)；核弹计数 getNukes/setNukes；nukesDaysLeft 队列（生产倒计时）
- 建造/发射 UI：`menusInGame/AtomicNukes/InGame_BuildAtomicBomb`（建造）、`InGame_Nukes`（发射界面）、TextTop_Nukes（顶部计数）、InGame_ProvinceInfo（省份面板）
- AI：AI_Manager（交战）→ AI_Nuke.useNukes(civID)（收集交战国省份→选目标→发射+扣减）
- 结算：GameThread_Turns.civsNukes: ConcurrentLinkedDeque<Integer>（**生产队列**，非发射队列）→ 每回合 updateNukeProduction
- 表现：RendererAnimationNuke（核爆动画）、MapModeManager（核弹地图图层）、SoundEffects
- 参数：GameValues$GameValue_Atomic（AI_NUKES_LIMIT、ATOMIC_BOMB_COST/DEVASTATION/ECONOMY/POPULATION_CASUALTIES/PRODUCTION_TIME、NUCLEAR_REACTOR_* 等）
- 事件：EventOutcome_NuclearReactor / EventTrigger_CivNuclearReactorOver/Below（核反应堆事件）
- 防护：BombShelter（CasualtiesNuclearAttacks -0.75）

**缺失（M3 目标）**：ICBM 式导弹分级（ICBM/SLBM/MRBM/AL-ICBM）、MIRV、当量分级、拦截链、DEFCON、EMP/污染、CBRN 等级、生化弹头、ASAT、核防空。当前核弹是"无射程直接落点"的简化形式（选省份→结算），无飞行阶段/拦截。
