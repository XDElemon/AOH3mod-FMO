## 一、现状（当前实现）
- 方法：`ProvinceDrawArmy.drawAirMissileFx(SB, AirMission)`（`ProvinceDrawArmy.smali:8140`）
- 当前位置算法（8143-8217）：
  - 起点 = `getAirDrawPosX/Y(发射方任务.airDivisionAtProvinceID)`（**省锚点**）
  - 终点 = 同法取目标任务 `airDivisionAtProvinceID`（**省锚点**）
  - 进度 = `(now-lastMissileMs)/playSpeedTIME`（1200ms 兜底，clamp 1）→ 线性插值 → `Images.pix` 14×14 方块
- 问题：省锚点 ≠ 飞机贴图位置 → 观感"从省份/机场中心飞出、命中省份中心"。

## 二、关键发现：飞机贴图的真实绘制链与定位公式
1. 绘制入口（每帧）：`RendererGame(*).drawAirForce(SB)`（PD:1094）
   - → `drawAirForceMissions(SB)`（PD:1125；**航线** `drawLinePts` 与机炮/导弹特效所在）
   - 飞行机体贴图：由 `drawProvinceArmyWithFlag(SB,省,军队序)`（PD:4776）遍历省内军队绘制；key 以 `airhq_` 开头 → 调用 **`drawAirDivisionAsPlane(SB, x, y, key)`（PD:420）**（**唯一调用点 PD:4859**）
2. `drawAirDivisionAsPlane` 定位公式（PD:472-546）：
   ```
   若 state∈{EN_ROUTE(1), RETURNING(3)} 且 prev≥0 且 prev≠at：
      sp = airDivSegAnimMs*100 / airDivSegDurMs（dur≤0 时 ÷400 兜底），clamp≤100
      位置 = lerp( getAirDrawPosX/Y(prev), getAirDrawPosX/Y(at), sp/100 )
   否则：位置 = 传入基座（getArmyPosX/Y(省,军队序)，即省内军队槽位）
   ```
   （即"**段插值**"：每跨一省，贴图用 `segAnim/dur` 从旧省锚点滑到新省锚点）
3. 贴图锚点/尺寸（PD:580-712）：
   - 所有机型贴图（interceptor/fighter/bomber/attacker）与光环均**以 (x+20, y+20) 为视觉中心**
     （bomber 60×60 从 x-10 起；其余 40×40 从 x 起；环 ord2 84×84 从 x-22、其余 56×56 从 x-8）
   - 类型序：ord0=拦截机｜1=战斗机｜2=轰炸机｜3=攻击机（`getKeyOrd` PD:7104）
4. 坐标空间：`getAirDrawPosX/Y(省,scale)` = `(iCenterShift + mapCoords) × 当前缩放`（屏幕坐标、含相机；PD:6340-6394）
   → 与导弹/机炮特效**同坐标系**，可直接复用。

## 三、改造方案（R4c103 预案）
1. **新增 2 个 helper**（PD，static）：`getAirSpriteX(AirMission)I` / `getAirSpriteY(AirMission)I`
   - 内部复刻 `drawAirDivisionAsPlane` 段插值公式（含 dur≤0→÷400、clamp100、state∈{1,3}、prev≥0、prev≠at 门；失败返回 -1）
   - 非飞行态回退 = `getAirDrawPos(at)`（省锚点；见 §五已知近似）
2. **改写 `drawAirMissileFx` 端点**（8174-8189 区段）：
   - 起点 = 发射方贴图中心 = `getAirSpriteX/Y(p1) + 20`
   - 终点 = 目标贴图中心 = `getAirSpriteX/Y(目标任务) + 20`（保留循环中命中任务的引用）
   - 端点逐帧重算（敌机移动时导弹实时追踪）；保留全部原门链与 `nMS gx` 探针
3. 航线（`drawLinePts`）、机炮特效、进度公式、颜色（蓝=我/红=敌）**不变**。

## 四、预期效果
导弹方块从**我方飞机图标中心**出发 → 飞向**敌方飞机图标中心**，随敌机移动实时追踪；命中后停在敌机贴图上直到结算（T+1）。

## 五、边界与已知近似
| 场景 | 处理 |
|---|---|
| 发射/目标为"飞行中"（主场景） | 段插值精确复刻 ✓ |
| 停驻态（EXECUTING/刚创建 prev<0/prev==at） | 近似=省锚点（与真实"军队槽位"最多差数十 px）→ 候选后续精修（如需复刻 `getArmyPosX/Y` 槽位） |

| 合拢（同省） | 两端=两机贴图中心，短线动画（R4c100b 已保证仍绘制） |

## 八、拓展调研增补（v2，2026-09-11）

### 8.1 z 序实证（特效 vs 飞机贴图）
- 三条渲染路径中 `drawAirForce`（内含航线/机炮/导弹特效）**均在 `drawProvincesArmy`（飞机贴图所在）之后调用**：
  - `RendererGame.smali:133→147`｜`RendererGame$3.smali:345→373`｜`RendererGame$4.smali:584→621`
- 结论：**导弹方块/航线天然画在飞机贴图之上**（"从贴图上飞出、命中在贴图上"的可见性成立），无需调整绘制顺序。

### 8.2 停驻态"精确槽位"（消掉 v1 的已知近似）
- 基座 = `getArmyPosX/Y(省, 军队序)`（PD:6677/6774；内部使用 `ArmyDivision.iShiftX/iShiftX_Scaled` 槽位偏移）。
- 军队序 = 该师在省军队列表中的下标：遍历 `province.getArmy(i).key` 与 `AirMission.airhqKey`（public 字段）比对即得。
- **最终口径（覆盖 §三.1 的近似条款）**：非飞行态 = 精确槽位；槽位查找失败/省为空 → 回退省锚点；全失败 → 返回 -1（不绘制）。

### 8.3 getKeyOrd 实证
- `getKeyOrd`（PD:7104）：`split("_")[3]` 得类型序（0=拦截｜1=战斗｜2=轰炸｜3=攻击）；异常/缺段 → 默认 1（战斗机）。

### 8.4 R4c103 施工清单（开工即用）

1. 新增 2 个 helper（建议置于 `getAirDrawPosY` 之后）：
