## 二、雷达圈的距离制实证
- 探测判定（`PlayerFogOfWar.smali:413-437`，读 `Airport.radarRange` @425）：
  `dx=X_Real差, dy=Y_Real差 → dx²+dy² ≤ (int)radarRange²` —— **Real 坐标平方距离直接比较**。
- 配置实测（游戏内 `RadarConfig.json`，坐标单位）：
  | 雷达 | Range |
  |---|---|
  | 机场圈 BasicAir | 200 |
  | 短波 ShortWave | 600（代际升级 750→…→1300） |
  | 长波 MIDCOURSE_ABM | 2400（900→…→1400） |
  | 反导 ABM_SITE | 300 |
- 官方换算：`DistanceKm = 1.95`（km/坐标单位，EarthM Config）→ 机场圈≈390km、反导≈585km、短波≈1170km。
- 雷达计划书的"km 语义统一 + 椭圆几何（D7）"属未竟项；**当前实现 = Real 坐标圆**（本改造与其对齐即可）。

## 三、现成的"距离制半径圈"模板（机队航程）
- `getProvincesInRange(Airport, AirType)`（`AFM:3071-3202`）：
  `getAircraftRange(type) = CombatRadius`（AFM:1271；空表兜底 300、≤0 兜底 500）；全图遍历省，`Math.sqrt(dx²+dy²) ≤ range → 收入集合`。

- **即：项目已有"半径圈 = Real 坐标欧氏距离"的成体系先例，导弹照此办理即可。**

## 五、改造方案（R4c104 预案）
1. **替换 `missileIsNeighbor` 内部**（保留方法名/签名 → 调用点零改动）：
   ```
   p0<0 || p1<0 → false；p0==p1 → false（双保险；调用侧已排除同省）
   prov0/prov1 null → false
   dx = CenterX_Real(p1)-CenterX_Real(p0)；dy = CenterY_Real(p1)-CenterY_Real(p0)
   d² = dx*dx + dy*dy
   return d² ≤ R²（R=射程常量，int，一处可调）
   ```
   （与雷达判定同构；无 sqrt、无浮点，性能零负担）
2. **射程值 R 的存法**：
   - 本包：方法内常量（必带注释），初值**待拍板**（候选见 §六）；
   - 预留代际钩子 `missileRangeForGen(I)I`（镜像 `missileCountForGen` 风格；M2-A 接线后按代差取值）。
3. **探针**：`nMS fire` 追加 ` d=`（发射瞬间双方 Real 距离，int）与 ` r=`（当前射程常量）→ **实测标定用**（一发即知"1 跳真实距离"，一次调准）。
4. 不动项：同省机炮专属、敌我/状态/存活筛选、冷却/弹药、T+1 伤害链、动画。
5. 影响面：斜角相邻、仅隔 1 省但距离在半径内的省 → **变为可打**（这正是本次需求）；更远的省取决于 R。

## 七、实施与验收预案
- 单文件单方法补丁（+~40 行 + 探针 ~30 行）；标准构建链 + 八检防线。
- 验收：
  1. 相邻省照常发射（`d≤R`）；
  2. **非相邻但在 R 内的省可发射**（对账 `fire d=` 值）；
  3. 同省仍不发（机炮）；冷却/弹药/T+1/零闪退不回归。
- 风险：R 过大 → "隔山打牛"手感 → 常量一处可调 + `d=` 数据支撑调参；无结构风险。
