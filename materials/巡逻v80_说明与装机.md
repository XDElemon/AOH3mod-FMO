## 一、先更正我上一轮的一个错判

我上一轮说"getRandomBorderProvince 只收外国省 → 内陆机场永远不巡逻"。**这条是错的**——那是我用自研 DEX 解码器读分支跳转时把 `if-ne` 的方向读反了。反汇编出真 smali 后确认：

```smali
invoke-virtual {v4}, Province;->getCivID()I
iget v5, p1, Airport;->civID:I
if-ne v4, v5, :cond_f      # 不等 → 跳回循环 = 丢弃
... add                     # 相等才收
```

**候选省 = 本国省** ⇒ 引擎原本就是"绕基地巡逻"，跟 ICBM 3510 *"patrol around the base"* 一致，**没有内陆机场 bug**。

不过真反汇编翻出了**两个更严重的真 bug**（见下 B2/B3）——这两个才是巡逻从来没生效的原因。

## 二、v80 改了什么（6 处）

### AirForceManager.smali

| # | 问题 | 修法 |
|---|---|---|
| **B1** | `tryPatrolForAirport` **第一条指令就是 `return-void`**（整个方法被短路，后面全是死代码） | 删掉短路 |
| **B2** | `hasActivePatrol` 判定**写反**：`if-eqz v0, :cond_31`（= 没有在飞的任务就跳过）⇒ **永远发不出第一次巡逻** | 改 `if-nez`（已有任务才跳过） |
| **B3** | `assignedAircraft.isEmpty()` 判定**写反**：`if-eqz v1`（= 有飞机就跳过不加入任务列表）⇒ **有机反而不飞** | 改 `if-nez`（空才跳过） |
| **B4** | 概率 `0x3ECCCCCD`(0.4f) → 起飞率 60% | 改 `0x3E4CCCCD`(0.2f) → **起飞率 80%**（语义 = 开关打开后，每回合该机场派出一批巡逻机的概率；调度=GameThread_Turns→updateAll→update(civ)→updatePatrols，回合级） |
| **B5** | `getRandomBorderProvince` 里 `sget FIGHTER` **硬编码战斗机航程**（代差不友好 D2） | 拆成两个重载：`(Airport)` 包装（传 FIGHTER，旧调用点零改动）+ `(Airport, AirType)` 本体（按传入机型取 CombatRadius） |
| **B6** | `Airport.<init>` 默认 `mode = PATROL` ⇒ 解短路后**AI 机场也会自动巡逻** | 加 civ 守卫：`Game.player.iCivID == airport.civID` 才执行（**AI 完全保持原样**） |

新增两个 public 方法（逻辑都在 AirForceManager 内，UI 只负责调用）：
- `toggleAirportPatrol(int provinceID) : int` —— 机场级开关，返回 1=开 / 0=关 / -1=没找到机场
- `startDivisionPatrol(String divKey, int provinceID) : int` —— 师级立即巡逻，返回目标省 / -1 失败 / -2 该师已有任务 / -3 无可用飞机
  - 机型按 divKey 第 4 段 ord 映射：**0=截击 1=战斗 2=轰炸 3=攻击**，航程按各自 CombatRadius 算（截击 400 / 战斗 500 / 轰炸 800 / 攻击 300）

## 五、验收清单（M-P1）

1. **默认就是开的**：引擎 `Airport.<init>` 默认 mode=PATROL，所以装完不用点也应该开始自动巡逻——若干回合内看到战斗机自己飞向本国某省再飞回（探针 `pt:go`）
2. 选中空军师 → 点 **[自巡]** → Toast「本机场自动巡逻：关」→ 之后不再自动派；再点 → 「开」
3. 选中战斗机师 → 点 **[巡逻]** → Toast「已进入巡逻」→ 该师立刻起飞（探针 `pt:div`）
4. 该师已有任务时点 [巡逻] → Toast「无法巡逻…」（-2 分支）
5. **AI 机场全程无变化**（civ 守卫）
6. 每机场同时最多 1 个自动巡逻任务（`hasActivePatrol` 机场级防重复）
7. 存档 → 读档：机场开关状态保持（`Airport.mode` 本来就在 Save/Load 里）
8. 面板 5 个键不重叠、文字不串行
