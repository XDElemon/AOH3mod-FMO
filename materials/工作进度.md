## 构建/装机管线（全部通过 Ubuntu terminal 执行）
```
1. cd /tmp/build_work && nohup java -Xmx4g -jar /tmp/apktool.jar b /tmp/build_work -o /tmp/pkg2.apk > /tmp/pkg2.log 2>&1 &   (~70s)
2. unzip -p /tmp/pkg2.apk classes.dex > /tmp/classes_new.dex && rm -f /tmp/full_aligned.apk && cd /tmp && nohup python3 /tmp/mkzip.py > /tmp/mkzip.log 2>&1 &   (~55s)
3. cp /tmp/full_aligned.apk '/sdcard/GLG/历史23/build_apk/dbg_unsigned.apk'
4. apk_reverse_sign（keystore=/data/user/0/com.ai.assistance.operit/files/pkcs12.keystore，alias=androidkey，store/pass=android）→ dbg_signed.apk
5. am force-stop 包名; cp dbg_signed.apk /data/local/tmp/ && chmod 644 && pm install -r /data/local/tmp/dbg_signed.apk
6. logcat -c; am start -n age.of.history3.qiamxi.zhiri/aoc.kingdoms.lukasz.jakowski.AndroidLauncher
```

## 血泪教训（smali）
1. 高寄存器逻辑抽独立方法（VerifyError: 寄存器类型合并冲突）
2. const/high16 低16位非零非法；setColor(FFFF) 覆盖 int 寄存器
3. 标签重复/残留 → 顶格 grep 统计清理
4. 行号偏移 → 用内容锚点+动态定位
