## 一、决策：为什么燃油可以去掉

| 维度 | 燃油（旧） | 航程（新，保留） |
|---|---|---|
| 语义 | MaxFuel/FuelConsumption 逐帧扣减 | CombatRadius = 任务可飞最大距离（ICBM Range 语义） |
| ICBM 对应 | 无直接对应（ICBM 用 Range + `Point of no return to base!` 返航点） | **正是 ICBM 的 Range/返航点语义** |
| 限制效果 | 需要逐帧扣油、油尽坠毁/返航两套逻辑 | 任务创建时**超航程拒绝** + 返航判定按距离，逻辑更少更稳 |
| 惩罚性 | "油尽坠毁"惩罚重，玩家挫败感强 | 只有"打不到/到不了"，符合大战略层直觉 |

**处理原则**：
- **逻辑层废除**：consumeFuel()/fuel 字段不再参与任何逻辑（任务创建、返航、拦截全部改用 CombatRadius/距离）；
- **数据层保留字段**（AirUnit.fuel/maxFuel、JSON MaxFuel/FuelConsumption、Save_AirUnit.fuel 保持原样）——避免动存档结构引发兼容问题；后续大版本再清理；
- 原 M3（A5+A6 油耗/速度）改为 **M3' 航程约束正式化**：任务创建超航程拒绝（AFM:1845 航程检查强化）+ 返航判定=距离>combatRadius×返回系数 → 强制返航（不坠毁）。

## 三、成品形态（做完之后的完整流程，玩家视角）

**场景：敌方轰炸机编队来袭**
1. **预警**：敌机任务进入我方机场雷达圈（每帧扫描）→ 红色警报提示（方向/机型/距离）
2. **自动拦截（P2）**：我方拦截机自动起飞（地图可见飞行轨迹、逐省推进）→ 与敌编队遭遇 → 空战结算
3. **空战结算（P1）**：逐机开火（属性公式：Defense 减伤 / Agility 命中 / Stealth / Ecm）→ 击落记录 / 敌机逃逸
   - 我方拦截机：Agility 0.8 高命中，Defense 12 偏脆
   - 敌轰炸机：Defense 22 抗揍，但 **canAttackAir=false → 不还手**
4. **航程制（M3'）**：拦截机飞不到（距离>航程）→ 不追了自动返航；敌机同样受航程约束（ICBM 返航点语义）
5. **巡逻制空（P3）**：机场开巡逻（Patrol 配额）→ 巡逻机持续空中巡航，巡逻空域内敌任务**即时交战**
6. **护航/制空（P3）**：我方轰炸任务自动带护航（先打护航机）；可派 AIR_SUPERIORITY 主动清场敌机场
7. **敌 AI 对抗（P3）**：敌国同样造机/巡逻/拦截/反击——空战成为双向对抗，有"夺取制空权"叙事

## 四、机制设计（架构图）

```
【每帧心跳】AA_Game.render → AirForceManager.updateMissions（每帧）
   ├─ 雷达扫描：敌任务 vs 我方机场雷达圈（radarRange）→ 威胁事件
   ├─ 巡逻机巡航：巡逻航线推进 + 空域交战判定（P3）
   ├─ 任务状态机推进：PLANNING→EN_ROUTE→EXECUTING→RETURNING→COMPLETED
   │     └─ 航程约束：到达判定用距离 vs combatRadius×系数（M3'）
【威胁响应】（P2）
   └─ 威胁进入防御圈（或无自卫目标航线相交） → createIntercept 接线
        └─ 拦截机升空（INTERCEPT 任务）→ 遭遇 → airCombatOne 结算 → 击落/返航
【空战结算】（P1）
   ├─ airCombatOne 属性公式（A1 Defense 减伤 / A2 Agility 命中 / A3 Stealth / A4 Ecm）
   ├─ canAttackAir=false → 无反击（轰炸/攻击机纯挨打）
   └─ 敌方对称（N5 一并修复：双方循环 + recordKill 审计）
【生产】（M4/M6）
   └─ 扣金 + 科技门控 + 代际属性注入（applyType 升级）
【敌 AI】（P3）
   └─ 建机/巡逻/拦截/反击（AIR_AI_INTERCEPT_FIRST_CHANCE 接线）
```

### 空战公式（P1 一次性定型）
- 命中概率：P = 0.5 × (1 - Stealth守×1.2) × (1 - Ecm攻×3)
- 伤害：D = airAttack × 0.5 × (1 - Defense/(Defense+40)) × (0.8 + 0.4×Agility攻)
- 无自卫：canAttackAir=false 机型不参与进攻侧（无反击伤害）
