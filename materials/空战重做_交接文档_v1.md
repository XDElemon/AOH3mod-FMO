  org.jf.baksmali.Main d <dex> -o <输出目录>

# ③ 八件套验证（六防线+Cast/Undef）

## 2. 标准工作流（每批改动 10 步）

> **第 4~9 步已固化成脚本（见 §10），优先用脚本，别手抄命令**；第 1~3 步（备份/写补丁/应用补丁）仍是手工，补丁一律 `.py` + count 断言。

1. **备份** 目标 smali → `<文件>.pre_<批次>.bak`；
2. **写补丁脚本**（`.py` 文件，禁止 shell 双引号传 `$` 类名）→ `python3 -m py_compile` 预检；
3. **应用补丁**：行级定位 + `count` 断言（每处改动断言命中数）；**空格无关比对**（smali 实际是 `, ` 风格）；
4. **汇编** → 新 dex；
5. **八件套**：与上一版 dex 做**对照组 diff**（正常只会多一行 Sig 计数变化）；
6. **结构核验**：baksmali 全类 diff（确认"只改了预期类"）+ DumpMeth 抽检（确认每方法动了几条指令）；
7. **打包**：重建 → zipalign → 签名 → 归档 `build_apk/dbg_signed77_v119_<批次>.apk`；
8. **装机**：推送（md5 对齐）→ `autotap_install.sh` → **设备 dex md5 == 本地 dex md5** → EARTH3 18510 完整；
9. **收尾**：`am force-stop`（**必做**，否则旧进程跑旧代码）＋ 清理 `/data/local/tmp` ＋ 基线重置；
10. **归档 + 回滚点**：专档条目 + 设计v2 章节 + 计划书更新 + 补丁存档；**留回滚点 apk**。

> 验收模式：改动 → 装 → **用户实测 → 喊"抓"** → 抓增量样本 → 解析探针对账 → 通过则登记验收。

## 3. 铁律与坑（动 smali 前必读）

**寄存器/指令类**
- `.registers ≤ v15`，**任何方法不得上调寄存器数**（工具链硬顶）；新方法寄存器算足但别超。
- `invoke` 的 kind 必须与声明一致：`static→invoke-static`、`private→invoke-direct`、实例→`invoke-virtual`。
- **invoke 与 move-result 必须紧贴**；插入代码要插在 invoke **之前**，不要再插到 move-result 前。
- 含宽参（J/D）方法**禁用 pN 别名**，一律显式 v；`const-wide` 目标别落进引用寄存器。
- 条件跳转**方向必须逐条复核**（历史重灾区，本项目已犯 5+ 次）：`if-ltz`＝<0 跳、`if-gez`＝≥0 跳、`if-nez`＝非零跳、`if-lez`＝≤0 跳……新写分支**旁边写意图注释 + 用真值表回放所有路径**。
- 循环回边寄存器类型要一致（合并点类型冲突 → VerifyError）。

**跨类访问类（最新血案）**
- **跨类读写私有字段/方法＝IllegalAccessError**（R4c176 闪退根因：`AirMission` iget `Province.iArmiesSize`）。
  → 一律走公开 getter：`Province.getArmySize()`（先例：ColonizationManager）；
  → 动手前先 `grep '\.field'` 看可见性。

**探针类**
- 探针用 `AirDbgLog.dKey`（写 `airdbg_key.txt`，500ms 批量刷盘）；`logOnce` 有全局 500ms 节流会被洪水饿死，新探针一律 dKey。
- 探针/新代码的**标签不要放方法尾部**（异常处理器/其他分支会流入 → Undefined → VerifyError）。
- 热方法里做字符串拼接 → 抽成静态辅助方法（主方法只传 key）。
- 加代码前先画**寄存器活跃区间**（不能只看"当前值没用"）。

**工具/流程类**
- 补丁**行级定位 + 空格无关比较**（整块字符串匹配易因空行/版式失败）。
- `$` 类名（`AirMission$MissionType`）**严禁经 shell 双引号**，补丁一律 `.py` 文件。
- 本地八件套 **不覆盖** ART 级 VerifyError / IllegalAccessError / NoSuchField → 必须真机启动验证。
- 装机后**必 force-stop**；装完**清理** `/data/local/tmp`（历史曾撑爆 /data）。
- **汇编产物非确定**：同源两次汇编 md5 可能不同 → **装哪版就核哪版**（别拿旧 md5 对）。
- 别并行跑终端调用（会话串流）；Ubuntu 内别 find/du 扫 /sdcard。
- 更全的教训：大计划书 v2.1 §7/§9.7/§12.5/§13.6/§16.4…（累计 111+ 条）＋设计v2 各章"教训"节。
