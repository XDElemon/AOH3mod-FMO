## 3. 环境事实（实测，踩过的坑）
- 文件策略必须 **danger-full-access**：proot 没有 user namespace / bwrap，`workspace-write` 会让所有 bash 直接失败。
- `write` 工具**只能改已存在文件**；**新建文件用 bash heredoc**（proot `--link2symlink` 拦 `link()` → EPERM）。
- **`/sdcard` 上禁止 `ln` / `cp -l` / `cp -a`**：源文件会被改名成 `.l2s.*` 而"消失"。备份用 `cp -p`。
- `unzip -t` 对签名 apk **误报 CORRUPT**；判完整性用 `unzip -Z1` 计数。
- proot 内**禁 `find`/`du` 扫 `/sdcard` 大目录**（会卡死）；FUSE 大文件**别用 `dd skip`**（读 0 字节），用 `tail -c`。
- 备份已就位：`build_inputs/`（keystore、rebuild 脚本、base_v119.apk、smali tar）＋`toolchain/lib/`（5 jar）。

## 4. 铁律 TOP（细节见交接文档 §3）
1. `.registers ≤ v15`，**任何方法不得上调寄存器数**。
2. 跨类读写私有字段/方法 = IllegalAccessError（R4c176 闪退根因）→ 一律走公开 getter。
3. `invoke` kind 与声明一致；**invoke 与 move-result 紧贴**；含 J/D 方法禁 pN 别名。
4. 条件跳转方向**逐条真值表复核**（历史重灾区，已犯 5+ 次）。
5. 探针一律 `AirDbgLog.dKey`；标签**不放方法尾部**。
6. 补丁一律 `.py` 文件（`$` 类名禁过 shell 双引号）+ 行级定位 + count 断言 + 空格无关比较。
7. 本地八件套**不覆盖** ART 级校验 → **必须真机启动验证**。
8. 装机后**必 force-stop**；装完清 `/data/local/tmp`；**汇编非确定 → 装哪版核哪版 md5**。
