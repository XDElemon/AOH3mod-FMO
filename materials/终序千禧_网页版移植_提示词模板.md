# 【改造版提示词】终序千禧（AoH3 改版）APK → HTML5/WebAssembly 可执行技术方案

> 模板改编说明：原模板为“通用 LibGDX APK 转网页”。本版替换全部参数为《终序千禧》项目实际情况（包名 age.of.history3.qiamxi.zhiri、smali 双源、无 Java 源码、超大 dex、mod 改动清单化）。

## 【角色】

你是一位精通 LibGDX、字节码逆向（smali/baksmali/jadx）、TeaVM 与 WebGL 渲染的全栈架构师。

## 【任务】

根据以下约束，生成一份完整的“将闭源 Android APK（LibGDX 游戏《终序千禧》，AoH3《文明时代二》改版）转换为 HTML5/WebAssembly 网页”的可执行技术方案。

## 【输出要求】

### 1. 字节码提取与环境搭建
- 反编译命令（适配现有环境）：
  ```bash
  # 从已签名 APK 提取 dex（可直接用 /tmp/classes_new.dex 等价物）
  unzip -p dbg_signed77_v119_R4c86.apk classes.dex > classes.dex
  # jadx 全量反编译（含资源路径）
  jadx -d out_java --no-debug-info -j 8 classes.dex
  # 保真对照：baksmali 出 smali 后与 /tmp/w3/smali diff，把 mod 文件单独覆盖回 out_java
  baksmali d classes.dex -o out_smali
  # 对 mod 类用 jadx 单类反编译并手工核对（smali 权威源为准）
  ```
- Gradle 多模块结构：`core/`（反编译 Java + assets）、`html/`（TeaVM 入口 + index.html）、`android/`（保留仅作 APK 参照，不进构建）
- 资源迁移：`unzip APK assets/* → core/src/main/resources/assets/`（注意 assets 含 5522 省大数据、地图图集、AircraftTypes.json 等；镜像目录结构）

### 2. 构建脚本
- 根 build.gradle：
  ```groovy
  buildscript { repositories { mavenCentral(); maven { url "https://jitpack.io" } }
    dependencies { classpath "io.github.tommyettinger:gdx-teavm-teavm:0.10.1" } }
  allprojects { repositories { mavenCentral(); google(); maven { url "https://jitpack.io" } } }
  ```
- core/build.gradle：依赖 `implementation files('libs/classes-decompiled.jar')`（jadx 产物，**排除 android.* / com.badlogic.gdx.backends.android 包**）；mod 类从 smali 手译覆盖
- html/build.gradle：
  ```groovy
  apply plugin: 'io.github.tommyettinger.gdx-teavm'
  gdxTeavm {
    optimizeLevel = 2; sourceMap = true; sourceMapIncludeSources = true
    // 保留类反射清单引用的类
  }
  ```

### 3. 反射与 JNI 处理
- reflection-classes.txt 示例（覆盖 LibGDX 核心 / Box2D（如启用）/ 游戏逻辑）：
  ```
  com.badlogic.gdx.graphics.g2d.SpriteBatch
  com.badlogic.gdx.graphics.Pixmap
  com.badlogic.gdx.utils.JsonValue
  aoc.kingdoms.lukasz.map.province.Province
  aoc.kingdoms.lukasz.map.battles.AirMission
  aoc.kingdoms.lukasz.map.battles.AirForceManager
  aoc.kingdoms.lukasz.jakowski.Player.More.PlayerFogOfWar
  ...（按 Class.forName 预检结果补全）
  ```
- 若启用：`gdx-box2d-teavm` 替代原生 JNI；TeaVM native 代理规则（@TeaNativeInterface 映射 gdx-box2d-jni）

### 4. 自定义 Shader 与资源加载
- WebGL vs GLES2.0 差异：精度限定符（WebGL 必须 `precision mediump float;`）、内置变量、texture2D→texture、#version 差异
- 自动化修复脚本（Gradle Task）：扫描 assets 下 shader 源，缺失 `precision` 则前插
- AssetManager 路径：Web 下用相对路径（`Gdx.files.internal("data/...")` 不变；注意大小写与 // 资源打包确定性）

### 5. HTML 入口与调试服务
- 最小 index.html：`<script src="game/gdx-teavm.js"></script>` + canvas 容器 + loading 提示
- Gretty：`./gradlew html:appRun` 一键启动；Gretty 配置端口 8080、contextPath `/`
- SourceMap：开启后浏览器可看 Java 源码栈

### 6. 常见错误与解决方案（≥3）
- `ClassNotFoundException: javax.swing` → TeaVM 不支持 AWT/桌面库：剥离（库内引用类）或 JRE stub
- `WebGLShader 编译失败` → precision/版本差异（用 4 的自动修复脚本）
- 音频格式不兼容（.ogg/.wav 平台差异）→ 转 WebM/OGG + TeaVM WebAudio 后端；或降级静音开关
- 附加：`Gdx.input` 相关 Android 特有 API（Keyboard.OnscreenKeyboardType 等）→ 平台代码剥离
- 附加：超大 dex（7.3MB≈万余方法）TeaVM 编译 OOM → 分模块增量 + optimizeLevel 平衡 + 排除未用包

## 【附加要求】

- 技术难度评级：**S 级**（无源码双层逆推 + 超大 dex + 保存格式 JSON/JsonValue 全量 + 自研 mod 逻辑多）；预估工时 120~300 小时（含调试），建议 POC 先只转“主菜单+单省渲染”





## 【修订补遗 2026-09-07（APK 实测结论，覆盖上方条件项）】

**实测 R4c86 APK**：
| 项 | 实测 | 影响 |
|---|---|---|
| assets 规模 | 31,643 文件（game 13,775 / gfx 8,011 / map 7,991 / ui 1,678 / audio 165） | **超大资源包**：浏览器加载需 Preload 策略+大文件（音乐 10MB+）流式；TeaVM 资源打包体积/内存预处理 |
| 音频 | 全部 .ogg（无 wav/mp3） | **Web 原生兼容**（WebAudio+OGG）；风险仅剩“大音乐流式” |
| Box2D | lib/ 只有 libgdx.so + libgdx-freetype.so + 壳（无 box2d.so）→ **确认未用 Box2D** | 删除模板中 Box2D 章节（gdx-box2d-teavm 不需要） |
| FreeType | **libgdx-freetype.so 存在** → 游戏用 gdx-freetype | **必须加 gdx-freetype-teavm 依赖**（TeaVM 移植字体渲染） |
| 加固壳 | libpairipcore.so + libstub.so（Google Play 保护壳） | classes.dex 可独立提取（本项目已长期操作）→ 壳仅影响原机启动，转 Web 忽略 |
| 桌面痕迹 | assets 含 steam_appid.txt / desktop.ini / build.gradle；dex 内含 lwjgl3 后端残留引用 | 原版存在 Desktop(LWJGL3) 后端——移植参照多一个平台；需注意 lwjgl3 相关类不可被 TeaVM 解析（排除） |

**对输入参数的修正**：
- 框架：LibGDX 1.12.x + **gdx-freetype**（有）；Box2D 删除
- 自定义 GLSL：未在 assets 搜索到独立 shader 文件（以 Pixmap/位图渲染为主）——第 4 章降级为“防御性准备”
- 构建依赖补充：`gdx-freetype-teavm`（或 jitpack gdx-teavm 对应版本）；核心 gdx 依赖坐标 `com.badlogicgames.gdx:gdx:1.12.1` + gdx-teavm 后端（以官方 README 为准：插件 id 与 TeaVM 版本匹配校验）
- 入口：AndroidLauncher 替换为 `GdxTeavmApplication(new aoc.kingdoms.lukasz.jakowski.AoHGame(), config)`（TeaVM 入口类样例见注释；**游戏主类名以 jadx 输出为准**）
- 存档/外部存储逻辑：AoH3 在 Android/data/... 读写 Config JSON（RadarConfig/AircraftTypes/GameValues 等被本项目改过）→ Web 需移植为 Gdx.files.local（localStorage 后端）——**列出所有“读写文件”调用点作为必改清单**（在 jadx 输出 grep `Gdx.files\|FileHandle\|File\(`）
- 构建资源：TeaVM 编译 7.3MB dex 建议 Gradle JVM 参数 -Xmx6g；optimizeLevel 与增量构建策略见第 6 章
