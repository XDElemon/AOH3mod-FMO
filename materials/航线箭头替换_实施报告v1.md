## 一、调研结论（实施前逐项核过）

| 项 | 结论 | 出处 |
|---|---|---|
| 航线绘制现状 | 每 **1px** 叠一个 **5×5 方块**（用 1×1 白像素 `Images.pix` 拉伸）；全库 **唯一** 调用点=航线（PD:2099） | `Image.drawLinePts` / PD:2099 |
| 用户素材 | **5×5** 蓝色向上箭头（126B PNG） | attachment_507599134…png |
| 素材落位 | 启用**闲置贴图位 `airDot`**（`ui/graph/airDot.png`，原 32×32、注册在案但全库无人引用）→ **零新增字段、零改注册** | InitGame:1031 / 全树 airDot 引用清单 |
| 旋转绘制 API | `Image.draw2(…,rotation)` 现成；底层 y-up 世界、**逆时针为正**；省界线（ProvinceBorder）有同类先例 | Image.smali 769/1031/222；ProvinceBorder:874 |
| 箭头指向公式 | `θ = toDegrees(atan2(dy, dx)) − 90°`（素材"向上"→朝飞行方向；去/返程端点互换→自动掉头） | 坐标系推导（y-up+CCW） |

## 二、实现（三处）

1. **素材注入**：`rebuild_v119fix.py` 增分支——用箭头替换 `assets/ui/graph/airDot.png`（注入后 apk 内该文件 126B，md5 与素材一致）。
2. **`Image.smali` 新增 `drawRot(SB;IIF)`**：16px、**绕自身中心**旋转（内部调私有 `draw2`，`origin=(w/2,h/2)`、src=图片自身尺寸、scale=1、无翻转）。
3. **`drawLinePts` 重写**：沿线段每 **32px** 画一个 **16×16** 箭头；旋转=上述公式（整段一条线=同一角度）；绘制前 `setColor` 置白→**箭头保持素材原蓝**。

> 迭代记录：v1 版因 `move/from16` 目标寄存器限 v0-v15 汇编报错 → v2 压缩调用组（drawRot 固定 16px、签名减参）后通过。

## 四、复测清单

1. 航线上出现**一串蓝色箭头**（代替原实心方块线）；
2. 箭头**指向飞行方向**（去程=源→目标；返程自动掉头）；
3. 飞机跨省/换向时箭头方向随航线更新；
4. 零闪退。

> 若箭头呈"镜像/反向"：方向公式已按引擎坐标系推导（y-up、逆时针为正），一处符号即可矫正。
> 参数（间距 32px / 尺寸 16 / 恒蓝）均可单点调节。
