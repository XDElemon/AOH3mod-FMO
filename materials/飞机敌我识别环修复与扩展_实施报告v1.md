## 二、实现（口径：我蓝 / 同阵营绿 / 其余红）

1. **新 helper** `ProvinceDrawArmy.getRingImageId(I)I`（单一判定源）：
   - `civ<=0` 或 player 为空 → 蓝（兜底）；
   - `civ == player.iCivID` → 蓝（`airRingFriend`）；
   - `DiplomacyManager.isAlly(player,civ) || isAlly(civ,player)` → 绿（**双向**：联盟/附庸/傀儡/宗主全覆盖）；
   - 否则 → 红（`airRingEnemy`）。
2. **①处**：环选择前计算 ringId（源=`mission.civID`；mission 为空→蓝兜底）→ 两分支改用同一 ringId；
   **②处**：复用该方法内的 key 解析（`airhq_<civ>_<prov>_<ord>_<n>`）新增 `civ=split("_")[1]`（默认 -1 兜底）→ helper；
   **③处**：用 `airport.civID` → helper；**④处**：不动（死代码，登记）。
3. **绿环素材**：`ringAlly.png`（由 ringEnemy 红→绿**通道互换**生成，保持同款风格/透明度，6683B）；
   - `Images.airRingAlly:I` 新字段；
   - `InitGame` 注册：`addImage("game/AirUnit/AirUnitlmages/ringAlly.png")`；
   - `rebuild_v119fix.py` 增加打包分支（自动注入 assets）。

## 七、R4c112 修正记录（停放态蓝环 / "实时性"，2026-09-12）

- **现象**：切换/查看其他国家时，部分飞机的识别环仍为蓝色。
- **定位（不是"缓存不刷新"）**：环颜色本就**每帧实时计算（无缓存）**；"蓝"来自 site1 的**兜底分支**——`getAirMissionByKey` 只查活跃任务且跳过已完成任务：**"从未出击 / 返航归位后的停放飞机"没有任务记录 → v2==空 → 旧逻辑兜底为蓝**（与"切换国家"无因果；切去别国查看时满屏停放飞机最易撞见）。
- **修复**：兜底改为**从编队钥匙解析国别**——新增 `getKeyCiv(String)I`（`airhq_<civ>_<prov>_<ord>_<n>` 第 1 段；`NumberFormatException→-1`；与 getKeyOrd 同风格）；site1 无任务时 `getKeyCiv(p3)→getRingImageId`；蓝色仅在钥匙不可解析的理论情形出现。
- 构建链：八检对照无回归（SIG **152167**/15（+2）；Cast 50=50；Undef **4 vs 3**——新增 1 条为**检查器 DEF_OPS 漏收 `array-length` 的同型已知误报**（与 `getKeyOrd` 存量完全一致，真机 dex2oat 为准））→ 724,245,935 B → 签名 OK → 装机 Success（01:29）+ dex2oat 零警告。
- 复测：停机坪/停放飞机（我方蓝、盟绿、敌与别国红）；飞行态维持正确；零闪退。
