# 飞行飞机贴图 ↔ 师同步移动方案 v1.0

> 需求提出人：项目负责人
> 编写日期：2026-08-25
> 目标：飞行中的飞机贴图（地图上可见的那架飞机）与军队栏中的"空军师"单位**同节奏、同步移动**，消除现在"贴图连续飞、师慢半拍跳省"的脱节感。

---

## 一、现状问题

| 层 | 当前实现 | 问题 |
|---|---|---|
| 飞机贴图 | 任务动画插值（`animElapsedMs` 进度 → 源省→目标省屏幕坐标连续插值） | 连续、平滑，但**是虚的**：与师的真实位置无关 |
| 空军师 | `moveDivisionAlongFlight()` 逐省 `setProvinceID_Point`（离散跳变 + 节流） | 真实、但**离散且慢半拍**：省跳变、节奏与动画不一致 |
| 两者关系 | **完全独立**，两套时钟 | 视觉上"贴图在空中飞，师在后面追" |

用户核心诉求：**贴图跟着师走** —— 即师的移动是"真身"，贴图是"化身"。

---

## 二、目标效果（验收标准）

1. 飞行中：地图上的飞机贴图与军队栏师单位**同步推进**（同一节奏，贴图不领先、师不落后）
2. 贴图运动轨迹：**连续平滑**（不是和省一样跳变）
3. 逐省推进仍保留（省的粒度是师存在的载体，贴图在省间连续过渡）
4. 返航对称（同样的逻辑反向执行）
5. 到达/返结束：贴图消失，师落在目标省/机场省（无瞬移感）

---

## 三、方案设计

### 核心思路：单一进度源，贴图坐标 = "省间插值"

不再用"动画进度插值"作为贴图坐标，改为：

```
贴图坐标 = lerp( 师当前所在省中心, 师下一目标省中心, 省间过渡progress )
```

即：**师每换一个省，贴图就绘在该省与下一省之间的过渡线上**；师跳省时，贴图"落户"到该省中心再向下一省过渡。贴图与师的移动逻辑同源，天然同步。

### 具体改动点

**AirMission.smali（数据层）**
1. 新增字段：`airDivLastProv: I`（师上一次所在省）、`airDivNextProv: I`（师当前目标省）
2. `moveDivisionAlongFlight()` 重构：
   - 去掉"任务动画"依赖，改为**每帧调用**（不再节流）
   - 用与贴图相同的进度计算师应处省 → `setProvinceID_Point`
   - 记录 `airDivLastProv/airDivNextProv`（供绘制层插值）
3. 到达/返航终点时：重置缓存，`placeAirDivision/returnAirDivisionHome` 保持现状

**ProvinceDrawArmy.smali（绘制层）**
4. 飞机贴图绘制坐标改为：
   - 若 `airDivLastProv == airDivNextProv`（同一省内）：贴图 = 该省中心（`getAirDrawPosX/Y`）
   - 否则：贴图 = 两省中心的插值点（`progress` 来自与师移动同源的进度）
5. 删除原"任务动画插值"坐标路径（保留动画时钟仅用于节奏控制）

### 关键技术问题与对策

| 问题 | 对策 |
|---|---|
| `setProvinceID_Point` 每帧调用开销/抖动 | 仅当"师应处省"变化时才调用（跨省检测）；同一省不重复调用 |
| 省的离散粒度 vs 贴图连续 | 贴图在省间过渡线段上连续移动，省切换瞬间贴图落在省中心（视觉可接受） |
| 直线插值经过"非路径省"（直线穿越国界/海上） | 保持现状（与陆军移动路径不同，空军直线飞行符合直觉）；M2 再引入航路点 |
| 返航进度 | 与 EN_ROUTE 对称：progress 用 `100 - 原进度`，源/目标互换 |
| 师在"空中省间"时军队栏归属 | 师始终归属 `airDivNextProv`（目标省），贴图在过渡段——军队栏以省为单位，天然如此 |

## 四、实施顺序（约3个构建轮）

1. **轮 1**：`moveDivisionAlongFlight` 重构（每帧调用 + last/next 缓存 + 日志 `um_mv2:last=X:next=Y`）→ 装机验证日志
2. **轮 2**：绘制层改用"省间插值"坐标 + 删除旧动画插值 → 装机视觉验证
3. **轮 3**：返航对称 + 边界（起点不动/终点贴图消失）打磨

预计改动：AirMission.smali ~40 行、ProvinceDrawArmy.smali ~30 行。

---

## 五、暂不做（后续阶段）

- 航路点/曲线航线（保持直线）
- M2 多机种：师=机种单位，贴图按机种切换（本方案数据结构已预留 `airDivNextProv` 扩展位）
- 朝向动态旋转（贴图随移动方向旋转，非180°死板翻转）
