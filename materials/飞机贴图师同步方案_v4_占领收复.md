## 一、陆军"移动占领"机制解剖（空军禁用项 ①）

### 调用链

```
陆军移动（MoveUnits，逐省寻路）
   → 到达敌国省 / 敌国边境
   → SiegeManager.checkForSiege(I)          （251行：检查是否进入围城状态）
   → SiegeManager.addProvinceSiege(I)       （114行：添加围城）
   → SiegeManager.updateSieges()            （1922行：每日推进围城进度）
   → 围城成功
   → Province.occupyProvince()              （Province.smali 14594行：占领！）
```

### 关键方法

| 方法 | 位置 | 作用 |
|---|---|---|
| `checkForSiege(I)` | SiegeManager:251 | 陆军到位后检查触发围城 |
| `addProvinceSiege(I)` | SiegeManager:114 | 建立围城状态（含围城天数/进度） |
| `updateSieges()` | SiegeManager:1922 | 每日结算围城进度/士气 |
| `occupyProvince()` | Province:14594 | **占领**：变更省所有权（占领方=围城方） |
| `setOccupiedByCivID(I)` | Province:18568 | 设置省占领者 civID |
| `isOccupied()` | Province:13907 | 省是否处于被占领状态 |

**本质**：占领 = **省所有权/控制权变更**（旗标、税收、驻军归属联动），**由围城进度驱动，必须陆军进驻**。

## 二、陆军"收复"机制解剖（空军禁用项 ②，独立于占领）

### 调用链（两条路径）

```
路径A - 围城收复：
   SiegeManager（围城中，攻方收复被占领土）
   → Province.retakeOccupiedProvince()          （Province.smali 16153行）

路径B - 和平收复：
   War.smali:2896（和平条约/停战归还）
   → Province.retakeOccupiedProvince_Peace()     （Province.smali 16914行）
```

### 关键方法

| 方法 | 位置 | 触发方 | 作用 |
|---|---|---|---|
| `retakeOccupiedProvince()` | Province:16153 | SiegeManager:335/2042 | 武力收复被占领省 |
| `retakeOccupiedProvince_Peace()` | Province:16914 | SiegeManager:347 / War:2896 | 和平收复（停战后归还） |

**本质**：收复 = **被占领土地的归还/夺回**，与占领是**两套独立代码**（占领进、收复出），仅省状态字段（occupiedByCivID 等）共享。

## 三、空军系统边界：不调用任何占领/收复逻辑

### 空军任务全流程（v4 明确）

```
创建任务（选中机场飞机 → 行进 → 目标省）
  → PLANNING → EN_ROUTE（飞行：贴图 lerp + 师坐标反查省转移）
  → EXECUTING（到达：师 placeAirDivision 落省）
  → RETURNING（返航：师 returnAirDivisionHome）
  → COMPLETED（师回机场省）
```

**过程中**：✅ 师省归属转移（`addArmy/removeArmy`，纯军队数据）
❌ **不调用**：`occupyProvince` / `retakeOccupiedProvince*` / `SiegeManager.*` / `setOccupiedByCivID`

### 明确排除项（防止后续误实现）

| 陆军能力 | 空军 | 原因 |
|---|---|---|
| 移动占领（occupyProvince） | ❌ 不实现 | 飞机空中无法占地 |
| 围城（SiegeManager） | ❌ 不实现 | 围城需陆军驻留 |
| 武力收复（retakeOccupiedProvince） | ❌ 不实现 | 同上 |
| 和平收复（retakeOccupiedProvince_Peace） | ❌ 不实现 | 外交事件，与任务无关 |
| 省归属转移（师 addArmy/removeArmy） | ✅ 实现 | 师=单位实体，位置随任务 |
