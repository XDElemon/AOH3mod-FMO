# A4 攻轰区分 · 具体方案 v1（2026-09-18）

> 目标（用户拍板方向）：
> ①轰炸机＝战略轰炸（省损＋**扣军队人力**）；攻击机＝**陆军开罐器**（打敌师人力为主）；
> ②两机型对"战略轰炸/对地支援"两行动的适应性差异＝伤害差异（矩阵）；
> ③配套：**自动巡逻=战/截**、**自动打击=攻/轰**（按钮配对，B3-A1 批次接活）。

## 一、现状锚点（调研结论，全部源码实证）
- 执行体唯一：`AirMission.executeAttack()`（AM:1457）——`dmg=Σ(canAttackGround机的 groundAttack)`；经济×0.1、人口×1000；**targetArmyID 零消费**。
- 点击路由：`AirForceManager.createMissionForClick()`（AFM:598）——ord2(BOMBER)/ord3(ATTACKER)→`createStrategicBombing`；ord0/1→`createPatrol`；本国非被占省→移动；被占省→可打击（v78/v79）。
- 任务工厂：`createStrategicBombing`（AM:814，主队=BOMBER或ATTACKER按 divKey ord；护航仅 BOMBER/legacy；maxAttackRounds=1）；`createAttackArmy`（AM:419，ATTACKER+FIGHTER，maxAttackRounds=2）——**目前无人调用**。
- ord 映射：0=INTERCEPTOR 1=FIGHTER 2=BOMBER 3=ATTACKER（`getKeyOrd`）。
- 军队结构：`Province.iArmiesSize`／`getArmy(i)`；`ArmyDivision{ civID, lArmyRegiment, iArmyRegimentSize, key, ... }`；`ArmyRegiment.num:I`；`ArmyDivision.updateArmy(Z)`、`removeRegiment(I)` 可用。
- 核爆范式（照抄对象）：`Province.atomicBombDropped()`——团`num −= num×pct`（floor/max0）→ 逐师 `updateArmy(true)`。
- 巡逻消费点：`AFM.updatePatrols(civID)`（AFM:6196）→`tryPatrolForAirport`（AFM:2494）——`mode==PATROL`＋FIGHTER pickIdleDivKey＋createPatrol＋防重复；自动打击可镜像此链。

## 二、R4c176 施工设计（本批）
### 2.1 executeAttack 重构（矩阵）
- 新静态 helper `unitMul(AirMission$MissionType, AirUnit$AirType)F`：矩阵（Rev2：仅轰炸/攻击两行）——
 | unit \ mission | STB | ATTACK_ARMY |
 |---|---|---|
 | BOMBER | **1.0** | 0.2 |
 | ATTACKER | 0.25 | **1.0** |
 | FIGHTER / INTERCEPTOR | **不参与矩阵**（维持现行为不乘系数；在打击任务中仅护航/对空） | 同左 |
 > Rev2 口径（2026-09-18）：**战斗/截击不参与矩阵**——其打击相关经“巡逻/移动链”（三入口实证：即时栏[巡逻]按钮任意机型；战/截点省→巡逻；攻/轰点本国→巡逻），**一律保持原样、不进矩阵；矩阵与对军伤害仅作用于真·打击任务（STB/ARM）结算**。
- 循环内改为：`mul=unitMul(p0.type, unit.type); if mul>0: v4 += groundAttack×mul; payload--`。
- 省损分档（默认）：STB 维持 econ×0.1／pop×1000；**ARM 档 econ×0.02／pop×100**（开罐器不主攻省）。

### 2.2 新增 applyArmyDamage（新静态方法，照抄核爆范式）
`applyArmyDamage(Province, int attackerCivID, float pct, int targetArmyID)`：
- 遍历省内部队：跳过己方/盟友（`isAtWar(attacker, div.civID)` 过滤）；`targetArmyID>=0` 时仅命中该师（**v1 先用 -1＝整省敌军**，精确锁师后置）；
- 逐团 `num = max(0, num - floor(num×pct))` → 完后逐师 `updateArmy(true)`；
- pct 注入：
 - **STB**：`pct = clamp(v4×0.001, 0, 0.15)`（单任务一次；maxAttackRounds=1）；
 - **ARM**：`pct = 0.35`（每轮一次；maxAttackRounds=2 → 累积≈58%）。
- 探针：`nAH pct=… civ=… n=<改动的团数>`。

### 2.3 createMissionForClick 路由补充（AFM:598）
- `ord3(ATTACKER)` 分支：从 `createStrategicBombing` 改为 **`createAttackArmy(airport, -1, targetProvinceID, divKey)`**；
- BOMBER 分支、fighter/interceptor 分支一字不动。

### 2.4 攻击机 × 护航：双边规则（Rev2.1，2026-09-18 用户指示）
- ①**攻击机不担任护航**（护航编成＝战斗机/截击机；全树唯一护航构建点＝`createStrategicBombing` 护卫段，无攻击机——现状保持）；
- ②**攻击机的打击任务不借用护航**（去掉 `createAttackArmy` 的 FIGHTER `addAll`；对齐 v78“攻击机不借护航”裁定）；
- ③攻击机保留**少量对空**（现载 `AirAttack=10` 不动；`CanAttackAir=false` 维持，如需“能还手”另行拍板）。

### 2.5 交付与验收
- 探针核对：轰炸机队→目标省 pop/econ 下降＋敌师团人力↓（≤15%/任务）；攻击机队(ARM)→目标省敌师团人力↓↓（35%/轮）＋省损小；
- 回归口径：护航/扫荡/游猎/雷达 全链不动、零崩溃；五件套＋八件套→装机。
- 回滚点：R4c175b。

## 八、防错调研补充（Rev2.2，2026-09-18；只调研、未动码）

> 本轮对 R4c176 的每处改动做了"锚点级"复核。结论：**计划可行**，并补充以下防错要点与实施细节。

### 8.1 执行链确认（"每轮一次"语义成立）
- `executeAttack` **全树唯一调用点**＝`AirMission.update()` 抵达段落（AM:4379，紧邻 `um_p2:l=` 探针）；内部 `attackRoundsExecuted < maxAttackRounds` 门槛＋每次调用自增 ⇒ 每轮一次：
 STB `maxAttackRounds=1`（1 次）；ARM `maxAttackRounds=2`（2 次，已核 `createAttackArmy` 设 2）。
- 对军/省损的"每轮施加"因此成立（ARM 35%×2 轮；STB 一次）。

### 8.2 executeAttack 改造的寄存器映射（.registers7 实测可行）
- v3＝hoist `p0.type`（全程持有）；v0＝迭代器；v1＝unit；v4＝Σfloat（伤害）；v5＝乘数/临时 float；v6＝零常量。
- 逐机：`iget-object v2, v1->type` → `invoke-static {v3, v2}→unitMul→v5` → `const/high16 v6,0x0`＋`cmpl-float`＋`if-lez :mx_skip`（mul≤0 跳过）→ `iget v2,groundAttack` → `mul-float/2addr v2, v5` → `add-float/2addr v4, v2` → 原载油（payload）扣减保持原位。
- 省损分档：按 v3 选系数（STB：`0x3dcccccd`(0.1)/`0x447a0000`(1000)；ARM：`0x3ca3d70a`(0.02)/`0x42c80000`(100)），套用现锚点（经济/人口两处）；`recordDamage(v4)` 保持。
- 新标签用唯一名（如 `:mx_skip`），复核不撞现有 `:cond_*`。

### 8.3 unitMul 规格（新静态方法）
- 签名 `unitMul(AirMission$MissionType, AirUnit$AirType)F`：
 STB：BOMBER=**1.0f**｜ATTACKER=**0.25f**｜其余=**1.0f**（战/截恒 1.0＝维持现行为、不进矩阵）；
 ARM：BOMBER=**0.2f**｜ATTACKER=**1.0f**｜其余=**1.0f**；未知类型=0f（防御）。
- 实现模式抄现网（AM:4732 现例：`iget-object` ＋ `sget-object AirType` ＋ `if-eq`）。
- 常用 float 常量已列：1.0=`0x3f800000`；0.25=`0x3e800000`；0.2=`0x3e4ccccd`；0.35=`0x3eb33333`；0.15=`0x3e19999a`；0.001=`0x3a83126f`。

### 8.4 applyArmyDamage 规格（新静态方法；核爆逐字同款）
- 签名 `applyArmyDamage(Province, I, F, I)V`＝(省, 攻击方civ, pct, armyID)。
- 主循环：`i = prov.iArmiesSize-1 .. 0` → `div = prov.getArmy(i)`：跳 null；跳 `div.civID == 攻击方`；`invoke-static {攻方, div.civID}, DiplomacyManager.isAtWar(II)Z`（**静态签名已核**：DiplomacyManager.smali:9684），非交战→跳过。
- 团循环：`j = div.iArmyRegimentSize-1 .. 0` → `r = div.lArmyRegiment.get(j)`：`t = (int)(r.num × pct)`（int→float→mul→float→int 截零）→ `r.num = max(0, r.num − t)`；计数 n。
- 每师完毕：`div.updateArmy(true)`（**与核爆一字不差**）；**不删团**（同核爆语义，保持观感一致）。
- armyID 参数：v1 由路由恒传 `-1`＝"整省交战敌军"；`>=0` 的"精确锁师"语义未实锤（`iArmy`/key 线索见 §一），本轮**保留参数、不做过滤**。
- 探针（dKey）：一条 `nAH pct=… civ=… n=<受影响团数>`。

### 8.5 createMissionForClick 分叉点（AFM:598；★本轮最大防错项）
- **陷阱：`:cond_9a` 是 BOMBER/ATTACKER 共用分支**（两者同经 `:goto_69`→占用/国别检查）。**直接替换该处工厂调用=轰炸机被一并改走**，不可取。

 `sget ATTACKER→空闲寄存器`；`if-eq v5, 该寄存器, :cmc_arm` → 原 `createStrategicBombing(p1,p2,v3)`（轰炸机路径不变）；`:cmc_arm` → `createAttackArmy(p1, -0x1, p2, v3)` → `return-object v7`。
- 空机预检两分支共用（无攻击机时照旧 `return null`=不建任务）；`:goto_89`（本国省→巡逻）路径不动。
