## 3. 标准作业流程（SOP：照抄即可）

```bash

cp X.smali X.smali.pre_<批次>

# 1) 写补丁脚本（patch + gate 两模式）并跑

# 2) 汇编（必须 result=true）
java -cp "$SMALI_CP" RunSmali /tmp/revx /tmp/<批次>_classes.dex | tail -2

# 3) 构建（打 dex / 对齐 / 签名）
cd /sdcard/GLG/历史23 && bash toolchain/act/build_fast.sh <批次>

# 4) 装机（vivo 弹窗自动点按）
cp build_apk/dbg_signed77_v119_<批次>.apk /data/local/tmp/<批次>.apk
sh /sdcard/GLG/历史23/toolchain/autotap_install.sh /data/local/tmp/<批次>.apk /data/local/tmp/inst_<批次>.txt

# 5) 三对齐核验（apk md5 / dex md5 / Earth3=18510 / 字节数）
#    命令见 §6，结果必须与 build_apk 里的 apk 一致

# 6) 重置抓样基线 → 交用户实测 → 用户喊「抓」才读日志
SZ=$(stat -c %s '/sdcard/Android/data/age.of.history3.qiamxi.zhiri/files/airdbg_key.txt')
echo $SZ > /sdcard/GLG/历史23/r6s5/.capture_baseline

# 7) 抓样判读
bash /sdcard/GLG/历史23/toolchain/act/capture.sh <批次>_s1
#    样本 = tail -c +$((基线+1)) 日志文件

# 8) 落盘文档 + 推仓库
cd /sdcard/GLG/历史23 && bash toolchain/sync_and_push.sh '<批次>: 一句话说清改了什么>'
```

**铁律：验证由用户自己进游戏完成。** 不要主动 `am force-stop` + `monkey` 拉起游戏。

## 5. 铁律与血案（**必读**，每条都是真金白银）

1. **工具链硬上限 16 寄存器**；`.registers` **不得上调**（多个方法已满）。只能借"引用写 0 次"的死寄存器，并给证据。
2. **常量类型是 int**：`const/const/16/const/4/const/high16` 产出的值**不能**当 float 用（需 `intBitsToFloat` / `int-to-float`）。
3. **`java.lang.*` 的静态常量都是基本类型**：`Float.POSITIVE_INFINITY`、`MAX_VALUE`、`Integer.MAX_VALUE`… 用 `sget-object` 读**能过校验、必炸运行**（`NoSuchFieldError`）。要 +Inf 用 `Float.intBitsToFloat(0x7f800000)`。
4. **"逐字复原"会把当年的 bug 一起复原**：素材里的历史方法体**自带反极性**（本项目 `provinceHasAirport`/`hasMilitaryBuilding`/`strikeScore` 三件全反）。⇒ 逐字件必须**逐条验方向**，门禁必须查方向。
5. **极性对照表**（跳转助记易混）：
   `if-eqz`=等于0跳 ｜ `if-nez`=≠0跳 ｜ `if-ltz`=<0跳 ｜ `if-gez`=≥0跳 ｜ `if-lt a,b`=a<b跳 ｜ `if-ge a,b`=a≥b跳。
   **范围判断**：有效下标必须写成 `if-ltz idx` + **`if-ge idx, size`**（≥长度才跳过）。写 `if-lt` 会让**有效**下标被跳过 ⇒ 分支永不可达（r6c003 的坑）。
6. **分支/跳转目标必须成对核对**：改一条分支必须同时确认目标标签存在且语义未变。
7. **标签不得放方法尾部**；**invoke 与 move-result 必须紧贴**；`.catch` 必须紧贴 try 块尾。
8. **非 invoke 指令不能带花括号**：素材里的 `mul-float/2addr {v0, v2}` 会被汇编器拒绝 ⇒ 施工时过规范化器 `norm_smali()`。
9. **语句插入位置**：用锚点插入前先确认锚点在**正确的到达路径**上（否则会插成死码，或在 `.method` 与 `.registers` 之间插入 ⇒ 语法错）。
10. **`/sdcard` 是 fuse，不能当 git 仓库**（原子写被拒）；git 树必须在 Linux 侧。
11. **磁盘满的表现是"装机失败/会话异常"**，不是写文件报错。每批清 `/tmp/*_{work,aligned,signed}.apk`，归档只留最近 2–3 个。
12. **AI 隔离**：Phase A/B 只服务玩家。AI 智能线（`strikeTick_A1`/`a1*`/`a1b*`/`nP2*`）**不得改动**。
13. **锚点正则用 `\s*`**：smali 指令间普遍有空行。
14. 改完后 **grep 汇编输出必须是 `result=true`**（RunSmali 失败也可能返回 0）。

## 6. 判读字典（探针 → 人话）

| 探针 | 含义 | 期望 |
|---|---|---|
| `nAS` | 玩家 P 线**派发**次数 | ≥1 表示飞机真的起飞了 |
| `nAS type=2` / `type=3` | 攻击机打部队 / 轰炸机炸本土 | 两类都应有 |
| `nA4e k= a=0` | **老链**给玩家炸的次数 | 应为 **0**（若非 0 ⇒ 隔离被写坏） |
| `afp:row a=N` | 点机场**行**（下标 N） | 你点行就该出现 |
| `afp:Hi a=N` / `afp:Hm a=N` | 按键那一刻 `iActiveID` / `a1MemIdx` | 点行后应=行下标 |
| `afp:src a=XY` | 解析来源：**个位**=来源码（1=player空 2=instance空 3=当前省 4=list[0] 5=记忆命中 9=无列表） | 修好后**不应**常驻 3/4 |
| `afp:press ap=` | 被操作机场的 `provinceID` | 应随所点机场变化 |

**三对齐核验命令**：
```bash
P=$(cmd package path age.of.history3.qiamxi.zhiri | head -1 | sed 's/package://')
md5sum "$P" | cut -c1-32                      # APK_MD5
unzip -p "$P" classes.dex | md5sum | cut -c1-32 # DEX_MD5
unzip -l "$P" 'assets/map/Earth3/*' | tail -1   # Earth3 应为 18510
stat -c %s "$P"                                # 应为 738,377,701
```
