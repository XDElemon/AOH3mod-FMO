## 一、Bug1："战机使用武器 → 动画中断"（机炮/导弹场景均可见）

### 1.1 数据现场（机炮场景，745 号机，L11304853-11305237）

```
11304853 st=1 at=5711 pv=5713 an=16  du=3000   ← 新滑行段(5713→5711, 3秒)刚开始
11304863 st=1 at=5711 pv=5713 an=32  du=3000
11304864 nAC kill                               ← 武器结算（开火命中）
11305237 st=2 at=5711 pv=5713 an=48  du=3000   ← 进入交火态 → 贴图切"停靠位"
```

**机制**：交火（st2）一开，绘制切到"停靠位"（=省槽位），而飞机自己的滑行动画（5713→5711，3 秒段）只播了 **1.6%** 就被弃置——视觉上就是"一开火，动画被掐断、就地顿住/跳位"。此前该状态被隐藏（看不见），R4c159 让贴图可见后，这个"掐断"第一次以"中断"的形式被看见。

### 1.2 修复（R4c160-A）

- st2 的绘制改为**与 st1/st3 完全同一条动画插值**（`drawAirDivisionAsPlane` st2 → `:cond_27`）；
- `getAirSpriteX/Y` 把 st2 纳入插值分支 → 机炮特效起点/方向与可见贴图**同源同帧**。
- 效果：交战时飞机按自己应有的滑行继续跑（不再跳位/顿住），弹流从机头喷出并跟着走。

> 备注：被击落敌机的"瞬间归位回家"（Abort 保洁瞬移）是另一条**旧有刻意行为**，与本条无关；如需要平滑可另议。

## 二、Bug2："返航回头"（老 bug 复现）

### 2.1 数据现场（208 号机返航，L10548997-10623014）

```
10548628 fr_enter:fp=97 st=3                 ← 强制返航进入（进度仍是 97）
10549000 um_mvsw to=6342 pr=5712 fp=0.97     ← 第一个返航步进：直接“跳到家”（6342=机场省）
10549009 nFP jump last=0.97 cur=0.0          ← 进度这才被重置（晚了一拍）
10595445 步进 6342→6258                       ← 贴图从家“倒着飞回前线”一段（回头）
… 之后 6258→6328→6336→6330→6342 正常回家
```

### 2.2 根因（代码级）

- 返航用**反向插值**计算采样点：`采样百分比 = 100 - fp`（`moveDivisionAlongFlight` L2255）。
- `forceReturn()`（击杀后由 `trackTarget` 调用）**没有重置 `flightProgress`**（其他两条返航入口都会重置）。
- 于是首个采样用陈旧 fp≈0.97 → `100-97=3%` → 采样点落在**机场省** → 第一个逻辑步进直接"跳到家"；
- 下一拍 fp 被重置为 0 → 采样点又甩回前线 → 后续步进"从家往回走" → **贴图倒飞 = 回头**。

> 这正是老"返航往回跑"的真身（当年误判为"突进覆盖"，修错了对象）。

### 2.3 修复（R4c160-B）

- `forceReturn()` 在重置 `roundsInFlight` 的同一处补上 **`flightProgress=0`**（与另两条返航入口对齐）。
- 效果：返航从当前位置开始、单向前进，逐省回家；不再"先闪到家再往回跑"。
