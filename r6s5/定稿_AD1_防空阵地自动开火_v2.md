# 2. 实现（全部落在已有代码上）

| 步骤 | 位置 | 做法 |
|---|---|---|
| ① 求值 | 新 helper `airDefenseAt(int provinceID)I` | 返回该省**反导阵地数量**（＝发射点数量）；无则 0 |
| ② 射程 | 常量（可调） | 防空射程 = **300 px**（参考 ICBM `Weapon "SAM" 20000`；首版固定，后续接配置/代际） |
| ③ **开火** | `AirForceManager.update(I)V` 现有 AAA 段（**@11979–12100**）**追加** | 遍历 `activeMissions`：取 `civID ≠ 本国`、且其当前所在省（`airDivisionAtProvinceID`）在射程内的**敌方任务** → 对其 `aliveAircraft` 开火 |
| ④ 伤害 | 复用 `AirMission.applyAirDamage(mission, f)` 或直接扣 `AirUnit.hp` | `hp ≤ 0` → `isAlive=false`、`isShotDown=true` |
| ⑤ 反馈 | `dWrite` 探针 | `AD p=<省> tg=<missionID> shots=<n> hits=<n> down=<n>` |

**自动开火**：在 tick 内完成，不需要玩家选任务／点按钮。
**对 AI 生效**：`update(civID)` 对每个国家都会跑 ⇒ AI 的阵地同样开火。
**不消耗资源**：不扣金币、不减 `missilesLeft`。
