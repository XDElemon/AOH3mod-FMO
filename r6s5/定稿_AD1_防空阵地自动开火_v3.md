# 定稿 · AD-1 防空阵地自动开火（v3 · 只打在飞目标）

日期：2026-10-02 ｜ 状态：**待开工** ｜ 取代 v2

---

# 0. 口径（最终）

| 项 | 决定 |
|---|---|
| 谁防空 | **只有「反导阵地」开火**；雷达 / 中层反导雷达**只探测、不开火** |
| 开火 | **自动**（回合 tick 内完成，无需玩家操作） |
| **打击对象** | **只打"在飞"的敌机**（＝敌方任务的 `aliveAircraft`） |
| **停放飞机** | **不打**（用户裁定：停在机场的飞机不能打） |
| 资源 | **不消耗** |
| 对 AI | **生效** |
| 代际 / 摧毁 | **本版都不做** |

---

# 1. 旧机制的处置：**删除**

现有 `AirForceManager.update(I)V` @11986–12098 的 AAA 段（对"不在自己领土上的机场"里**停放**的飞机每回合 −1 hp）**整段删除**。

理由：它专打停放飞机（用户已否决）；且不打在飞目标。删除后由新逻辑接管，避免重复扣血。

---

# 2. 实现（最终）

| 步骤 | 位置 | 做法 |
|---|---|---|
| ① 求值 | 新 helper `airDefenseAt(int provinceID)I` | 返回该省**反导阵地数量**（＝发射点数） |
| ② 射程 | 常量 | **300 px**（首版固定） |
| ③ **开火** | `AirForceManager.update(I)V`（替换旧 AAA 段） | 遍历 `activeMissions`：取 `civID ≠ 本国` 且**当前所在省在射程内**的**敌方任务** → 对其 **`aliveAircraft`** 开火 |
| ④ 伤害 | 复用 | 扣 `AirUnit.hp`；`hp ≤ 0` → `isAlive=false`、`isShotDown=true` |
| ⑤ 反馈 | `dWrite` 探针 | `AD p=<省> tg=<missionID> shots=<n> hits=<n> down=<n>` |

**为什么这样天然满足"只打在飞"**：`aliveAircraft` 是任务里的飞机列表；停放飞机只存在于 `Airport.aircraft`，**不会被遍历到**。

# 3. 参数

| 参数 | 值 |
|---|---|
| 发射点 | 每座反导阵地 1 个 |
| 齐射 / 装填 | 每回合 1 发 |
| 命中率 | 0.5 |
| 命中伤害 | 目标 `maxHp` 的 50%（战斗机/截击机 maxHp 4.0 ⇒ 2 发击落；攻击机 6.0 ⇒ 2 发；轰炸机 8.0 ⇒ 3 发） |
| 射程 | 300 px（**待定：是否含邻省**） |
| 资源消耗 | 无 |

---

# 4. 不变量

1. 雷达 / 中层反导雷达 / 空军基地的现有行为**一律不动**。
2. 停放飞机**不受任何影响**（旧段删除后）。
3. 不新增存档字段。
4. 铁律：新逻辑写成独立小方法，主方法只留 1 行 invoke；插点前跑 `check_regtype.py`。

---

# 5. 验收（可证伪）

1. 敌机**在飞过**我方有反导阵地的省份时掉血 / 被击落（含轰炸机）；
2. 停在机场的飞机**不掉血**（与旧版行为的差别点）；
3. AI 的反导阵地同样打我方飞机；
4. `aircfg_diag.txt` 有 `AD …` 行；无新增崩溃；
5. 雷达视野与绘制无变化。
