# 1. 伤害模型（v4 变更点）

**旧**：命中扣 `maxHp × 50%` ⇒ 永远只是"削半血"，打不死满血飞机。
**新**：**每发固定伤害 D**，命中即扣 D，`hp ≤ 0` 即击落。

目标机型血量（实测 `AirUnit.applyTypeDefaults`）：

| 机型 | `maxHp` |
|---|---|
| 战斗机 / 截击机 | **4.0** |
| 攻击机 | **6.0** |
| 轰炸机 | **8.0** |

## 三个可选档（请你选一个）

| 方案 | 每发伤害 D | 击落所需命中数（战/攻/轰） | 手感 |
|---|---|---|---|
| **A 轻** | **2.0** | 2 / 3 / 4 | 需要时间积累，空袭代价中等 |
| **B 中（推荐）** | **3.0** | **2 / 2 / 3** | 防空有威慑但不至于一碰就掉 |
| **C 重** | **4.0** | **1 / 2 / 2** | 战斗机一炮即落，空袭风险很高 |

# 3. 实现（不变）

| 步骤 | 位置 |
|---|---|
| ① `airDefenseAt(provinceID)I`（新 helper） | 返回该省反导阵地数量 |
| ② 开火 | 替换 `AirForceManager.update(I)V` 的旧 AAA 段：遍历 `activeMissions` 中 `civID≠本国` 且位置在射程内的敌方任务 → 对 `aliveAircraft` 开火 |
| ③ 伤害 | 命中 ⇒ `unit.hp -= D`；`hp ≤ 0` ⇒ `isAlive=false`、`isShotDown=true` |
| ④ 反馈 | `dWrite`：`AD p=<省> tg=<mission> shots=<n> hits=<n> down=<n>` |

**铁律**：新逻辑写成独立小方法，主方法只留 1 行 invoke；插点前跑 `check_regtype.py`。
