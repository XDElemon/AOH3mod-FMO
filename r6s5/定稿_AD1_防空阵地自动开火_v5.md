# 1. 空位设计（本版关键）

两个**独立小方法**，签名已带上下文参数（将来接科技/代差时**只改方法体，不改调用点**）：

```smali
# 命中率：将来 = f(防空方代际, 来袭方代际, 科技加成)
.method public static adHitChance(II)F      # (defGen, tgtGen)
    # 本版：固定返回 0.5
.end method

# 每发伤害：将来 = f(防空方代际, 来袭方代际, 科技加成)
.method public static adDamagePerHit(II)F   # (defGen, tgtGen)
    # 本版：固定返回 3.0
.end method
```

- `defGen` / `tgtGen` 本版传 **0**（占位）。
- **代际来源待定**：科技系统就位前，可选 `AirUnit.typeID` 或未来的 `AirUnit.gen` 字段（B4）或科技解锁态（B7/B8）。**留注释标明**。
- 这样"命中率/伤害随科技与代差变动"将来只是**替换这两个方法体**。

# 2. 目标机型血量（实测，用于定固定伤害）

| 机型 | `maxHp` |
|---|---|
| 战斗机 / 截击机 | **4.0** |
| 攻击机 | **6.0** |
| 轰炸机 | **8.0** |

**本版固定伤害 D = 3.0** ⇒ 击落所需命中：战斗机 **2**、攻击机 **2**、轰炸机 **3**。

# 3. 实现（最终）

| 步骤 | 位置 | 做法 |
|---|---|---|
| ① 求值 | 新 helper `airDefenseAt(int provinceID)I` | 返回该省**反导阵地数量**（＝发射点数） |
| ② 开火 | 替换 `AirForceManager.update(I)V` 旧 AAA 段 | 遍历 `activeMissions`：`civID ≠ 本国` 且**位置在射程内**的敌方任务 → 对 `aliveAircraft` 逐个判定 |
| ③ 判定 | `adHitChance(0,0)` → 命中则 `adDamagePerHit(0,0)` | 命中：`unit.hp -= D`；`hp ≤ 0` ⇒ `isAlive=false`、`isShotDown=true` |
| ④ 反馈 | `dWrite` | `AD p=<省> tg=<mission> shots=<n> hits=<n> down=<n>` |

**发射点**：每座反导阵地 1 个，每回合 1 发。
**射程**：**300 px（默认覆盖本省 + 相邻省）**——如需改为"只本省"，一句话即可改。
**只打在飞**：遍历的是任务的 `aliveAircraft`；停放飞机在 `Airport.aircraft`，不会被扫到。
