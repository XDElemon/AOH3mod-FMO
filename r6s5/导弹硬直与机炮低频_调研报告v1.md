# "导弹后硬直"与"机炮低频" · 调研报告 v1

- 日期：2026-09-15（基线 R4c160，增量 `glg_inc160.bin`，109MB）
- 结论先行：① 导弹系统**不锁飞机**（代码级排除）；② 所谓"硬直" = **击杀后返航的"起步静止"**（下一跳提交被推迟到返航进度 fp≈37%，期间画面完全静止）；③ 机炮本场 0 次 = 导弹在合流前就歼灭了目标（结构现象）。

---

## 一、机炮为什么没怎么用（数据）

本场计数：`nGX fire = 0`、`nMS fire = 4`（4 发 4 中，dmg≈129/发，11 击杀全部来自导弹）。

- 机炮（airCombatTick）只在**双方接近到"同省交火"窗口**才触发；
- 导弹规则（同省/邻省直射、其余中心距≤100）在 **d=52~97** 就先手开火，且单发直接清掉 2~3 架 → 战斗没进入同省就结束；
- ⇒ 不是坏了，是"导弹抢戏"。若想让机炮多出现，需要动导弹调参（射程/威力/冷却/弹药数），属平衡拍板项。

## 二、"使用完导弹后硬直" —— 真身还原

### 2.1 先排除导弹系统本身（代码级）

- `update()` 每帧无条件执行 `moveDivisionAlongFlight()`（不按状态/照不照 `strikeKind` 门控）；
- 导弹只是一个"状态机+特效"：发射后 `strikeKind=1`，特效块沿直线飞（时长≈playSpeedTIME），命中在**游戏时钟**结算——全程飞机的动画钟 `an` 连续增长（四名射手实测发射/飞行/命中期间 `an` 均正常推进）。
- ⇒ 导弹系统没有任何"锁飞机"的代码。

### 2.2 真身：击杀 → 强制返航 → **起步静止**

射手2（329876780728222）实况：

```
6075281 nMS hit（导弹击杀）
6079551 fr_enter:fp=0 st=3          ← 返航开始（进度归零 ✓R4c160修复生效）
6080082~6120777   st=3 at=5714 ... fp=0→36  an=1989→4437(超满)  ← ★画面完全静止 40,700 行
6120777 um_mvsw to=6335 pr=5714 fp=0.37      ← 终于落第一跳（滑向6335）
6121300~6148260   又静止（fp 37→62）→ 第二跳（6335→6336）……
```

射手1/3/4 同构（静止段分别 ≈3.1万/3.5万/2.2万+行；射手1 后续还有 142k 行的超长静止）。

### 2.3 机制（代码级）

1. 返航的"下一跳"提交需要**采样线**（`source=机场→target=当前位置` 的插值点，按 `100-fp*100` 推进）跨入一个新省份；
2. 提交前有两道**"防弹跳守卫"**：`v8==pv` 或 `v8==pp` 一律跳过（防"回跳"用）——但返航线本来就是**沿着来路往回飞**，最先要越过的两省往往正是 `pv/pp` → **被守卫跳过** → 只能等采样线飘到更远的省（本次 fp≈37%）；
3. 同时返航进度倍率大（`RETURNING ×28`，R4c118/120 距离缩放），fp 爬得慢 → 静止段被放大到数万行（≈数秒级）。
4. ⇒ 表现：**"导弹打完敌人 → 飞机原地钉住一段 → 才开始一跳一跳返航"**。四场导弹击杀均复现。

## 三、修复选项（建议拍板）

| 方案 | 内容 | 效果 | 风险 |
|---|---|---|---|
| **F1（主推）** | 返航时放宽"防弹跳守卫"（仅对 RETURNING 不拦 `pv/pp`，只保留 `v8==at` 拦截） | 首跳在"第一次省份穿越"即提交，起步静止显著缩短；后续跳也变密 | 低（只动 st3 一处~12行；采样线单调推进，不会产生回跳） |
| F2（可选） | 返航进度倍率 ×28 → ×16 左右 | 所有等待等比缩短（整体返航更快） | 低（单常量；观感需复测） |
| F3（备选） | 首跳特判：进入返航且当前段满钟时，立即以"第一个跨越省"落一跳 | 专门消灭"起步静止" | 中（要插逻辑） |

> 建议先上 **F1** 单变量验证；若觉得整体仍慢再叠 F2。
> 机炮低频另有平衡项（导弹调参），不在本包动。
