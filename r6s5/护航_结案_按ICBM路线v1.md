# 护航 · 结案记录：按 ICBM 路线（A 方案，2026-09-17）

## 背景
- 用户二改：直接套 ICBM——"以后有了 B-2 这类隐身轰炸机，总不用护航"；ICBM 源文件验证该判断（见《ICBM护航设计_调研v1.md》补篇 v1.2：Gen5/6 隐身轰炸机＝被动隐身自保，全游戏无空军护航）。

## 决策
1. **护航议题结案**：不做伴随护航编队（原包2取消）；不做独立"扫荡层"开发（原包1取消——ICBM 无此自动化，我方既有"自动拦截派发＋游猎"即其对应物）。
2. **替代路线（ICBM 流）三件**：
   - a) 【可选小包】拦截机选靶"优先打大机"微调（ICBM 拦截机角色对位：专打轰炸/攻击类）；
   - b) 【可选后置】巡逻配额对齐（复活 `getPatrolQuota` 截2/战4/轰2/攻0 概念）；
   - c) 【核心】C2 档4 代际体系纳入"隐身轰炸机（B-2/B-21 式）"：5/6 代轰炸机提升 `Stealth` 值（现 0.15 → 5代≈0.5、6代≈0.7 待调）→ 借现有 `stealthMul` 管线（R4c139）自动更难被探测/拦截 → "不需要护航"。**零引擎改动，纯数据线**。
3. **旧"合并血池"护航**：保留现状不动（引擎原生行为，成本 0）；**B3 视觉/队形条目关案**（如未来想要多机图标再另行重启）。
4. 文档动作（已办）：设计v2 §七十九结案记录；§七十七 A6/B3 行改"❌关案"；专档刷新#12。
