- 日期：2026-09-17 凌晨（基线 R4c165g 工作树）
- 状态：调研完成，**待方案拍板后开工**；本版取代 v2（v2 的"挂钩点=trackTarget 两处 lost"已更新）
- 目标：A1 / ④B——**截击机 + 战斗机**击杀敌机后进入返航，**边返航边游猎**：按三层过滤找新目标，找到→转向接敌（每场1次）；找不到→原样返航；含油量 Tier1 删除。

## 一、机型覆盖核实（本轮新增 · 实锤）
- `AirMission.createIntercept`（AM:519）：`assignedAircraft += getAvailableAircraft(INTERCEPTOR) + getAvailableAircraft(FIGHTER)` → **INTERCEPT 任务天然混编两类机型**（或纯战机型）。
- 唯一调度点 `AirForceManager:3250`（dispatchAutoIntercept 内）：选机场时 **INTERCEPTOR 优先、FIGHTER 兜底**（pickIdleDivKey）；玩家/其他入口亦经此链。
- 战斗门（`airCombatTick` AM:3796 / `missileTick` AM:4157）均按**任务级 type==INTERCEPT**，与机型无关 ⇒ 战机与截击机同规则参战。
- 数据（AircraftTypes.json 现装）：截击 CombatRadius500 / Radar550；战斗 400 / 500 ⇒ 游猎半径（÷2）：**截击250 / 战斗200**，自动逐机型。
- 备注：`AIR_SUPERIORITY`（FIGHTER-only 工厂 `createAirSuperiority` AM:412）全树**无调用方**（死工厂），不在本轮范围；ATTACKER/BOMBER 不入 INTERCEPT 任务。

## 二、挂钩点（更新版 · 第四轮"边返航边游猎"适配）
- `update()`（AM:2986-3734）结构：updateAnimClock → 平滑移动（每帧）→ **throttlePass 门控（每 playSpeedTIME 拍放行一次）** → trackTarget → airCombatTick → missileTick → packed-switch(state.ordinal)：
  0=PLANNING(:pswitch_7f)｜1=EN_ROUTE(:pswitch_e6, um_r1)｜2=EXECUTING(:pswitch_14c, um_p2)｜3=RETURNING(:pswitch_1f4, um_p3)。
- RETURNING 块（3652-3733）：`um_p3` 探针 → roundsInFlight++ → consumeFuel → 未到距离→(全灭→ABORTED)return；到达→ fp≥0.98 或 30s watchdog → COMPLETED → returnAirDivisionHome → returnToBase（补弹 R4c136 ＋燃料重置）。
- **游猎钩子 = RETURNING 块内、consumeFuel 之后、到达门之前**（每拍尝试，天然继承节拍/暂停门/菜单门）。
- 击杀→返航仍走既有链：trackTarget 失联（`nTRK lost/gone`）→ forceReturn（保持不动）。

## 三、既有件复用清单（全实锤）
- `AirForceManager.aiRadarVision`（AFM:3400，private static → **改 public 一行**）：雷达网∪机场对目标的可见性（含 stealth 折算 R4c139；范围 300/600/2400 ÷ iMapScale；椭圆 calcInEllipse）。
- `AirMission.stealthMul`（AM:4604 public static）= 1-平均stealth；`PlayerFogOfWar.calcInEllipse`（:442 public static）＋`calcCosK`。
- `Game.getDistanceFromProvinceToProvince_Simpler(II)F`（L3 距离）；`Game.getProvince(I)`；`AFM.activeMissions`；`DiplomacyManager.isAtWar(II)Z`。
- 重锁模板：`tt_upd`（AM:2925-2941：source/target/calculateDistance/distanceToTarget）；切换航段用"新段初始化"（与起飞/返航切换块同款：fp=0、rounds=0、segAnim=segDur、animStart/Elapsed 重置、source=当前省、target=敌省）。
- 余弹门：`missilesLeft>0`（齐射=min(alive,left)；冷却 lastMissileHours 4h；**返航落地才补弹** → 返航中余弹=作战剩余，门有效）。

## 四、游猎流程（定稿草案）
- gates：type==INTERCEPT ∧ state==RETURNING ∧ huntUsed==0 ∧ alive>0 ∧ missilesLeft>0 ∧ HP门。
- 扫描：activeMissions 中 敌(civ≠我 ∧ isAtWar) ∧ 非我 ∧ state∉{PLANNING,COMPLETED,ABORTED}（含 RETURNING） ∧ alive>0 ∧ at≥0；
  - L2 = aiRadarVision(t,myCiv) ∨ 机载（椭圆：t位置对 我位置 ≤ maxRadarRange(alive)×stealthMul(t)）；
  - L3 = Simpler(我at, t.at) ≤ maxCombatRadius(alive)/2；
- 取最近 → 重锁 + 切 EN_ROUTE + huntUsed=1 + 探针 `nHT ok`；失败→继续返航（`nHT none` 低频）。
- 每场1次=成功计数；未成功可持续尝试至到达。**AI 天然同效**。

## 五、微决策（默认值，异议指出）
