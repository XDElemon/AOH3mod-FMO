# 一、本轮关键发现：**摧毁建筑的管线已经存在**

| 组件 | 位置 | 说明 |
|---|---|---|
| **拆除建筑** | `Province.destroyBuilding(II)V` **@9051** | 遍历 `Province.buildings` 找到匹配项 → **`BonusesManager.updateBuildingBonuses(provinceID, building, buildingID, -1)V`**（把该建筑的加成撤销）→ `list.remove(i)` → 更新 `iBuildingsSize` → `updateBuildingLimit()` |
| 建筑对象 | `ProvinceConstructedBuilding` | 仅 `b0/b1`（建筑种类 + 建筑ID）—— **没有耐久字段** |
| 拆建筑 UI | `InGame_Destroy.confirm()` | 玩家拆建筑入口；拆完会 `rebuildInGame_AirForce()` / `rebuildInGame_ProvinceInfo()` 刷新界面（**空军基地/雷达被拆后 UI 会同步**） |
| 存档 | `LoadSavedGameManager` @3933 | 建筑列表随存档读写 ⇒ 若加耐久字段，必须同步存档 |

⇒ **"空袭摧毁建筑"不需要发明新机制**：算出伤害 → 调 `destroyBuilding` 即可（加成会自动撤销）。
缺的只有三件：**建筑耐久、受损/修复状态、打击目标的选择**。

# 二、把防空与空袭统一成"空中战役"模型

```
        ┌────────────── 攻方 ──────────────┐        ┌──── 守方 ────┐
AirMission(空军师, 带 missiles/gunAmmo) ──飞向──► 目标省
        │ 空袭结算 airStrikeResolve(mission, provinceID, kind, amount)
        │      ├─ kind=POP       → applyPopDamage      （已有）
        │      ├─ kind=ARMY      → applyArmyDamage     （已有）
        │      ├─ kind=BUILDING  → 【新】建筑耐久扣减 → 归零则 destroyBuilding（已有管线）
        │      └─ kind=INFRA     → 【新】可选（铁路/经济）
        └──── 防空对抗 airDefenseAt(provinceID)
              ├─ 探测（RadarConfig：CanDetectAir / Precision / 代际射程）
              ├─ 开火（复用 missileCountForGen/RangeForGen + 命中率）
              └─ 结果：击落/驱离 ⇒ 本次 airStrikeResolve 的 amount 打折
```

**核心思想**：防空与空袭摧毁是**同一模型的两端** —— 防空不是独立玩法，而是"打击收益的折减器"。这样以后加"摧毁建筑"时，防空天然就能保护建筑。

# 三、要**现在**就铺好的 5 条后路（关键）

| # | 后路 | 内容 | 为什么现在铺 |
|---|---|---|---|
| **H1** | **统一打击入口** | 新方法 `airStrikeResolve(AirMission, int provinceID, int kind, float amount)V` —— 所有地面伤害都从这里出 | 以后加"建筑/基础设施"目标只改这一个方法 |
| **H2** | **建筑耐久与损害** | `ProvinceConstructedBuilding` 加 `hp:F / maxHp:F`（smali 加字段 + 存档读写）；新方法 `damageBuilding(provinceID, type, id, dmg)F` | 没有耐久就只能"一炸即毁"，太粗暴；有耐久才能梯次破坏与修复 |
| **H3** | **修复/重建** | 每回合 tick：受损建筑回血（可花金币加速）；归零建筑 → 需重建（复用 `addBuildingConstruction`） | AI 也要能修，否则被炸一次经济崩 |
| **H4** | **防空求值函数** | `airDefenseAt(provinceID)F`：= f(反导阵地数, 中层反导雷达数, 雷达精度, 代际) | **防空与"减伤"共用同一个函数**，避免两套算法 |
| **H5** | **战报与表现** | 复用 `AirMission.emitStrikeReport(Province,I)` + 我们的 `dWrite` 诊断通道；被摧毁建筑用现有 UI 刷新（`rebuildInGame_ProvinceInfo`） | 没有反馈玩家感知不到，也没法验收 |
