### 3. R4c144 原"突击跑位"公式复盘（失败版）

```
gunRunMs        = 交火tick时写入（间隔>2s重置）        ← 运行时钟
getAirRunPct    = (now-gunRunMs)/700ms → 0..100（1200ms窗口内）
getAirStrafeX/Y = 自身机位 + (敌机位-自身机位) × pct×85%   ← 向敌机滑动
getAirRunH      = calcHeading(敌机位-滑跑位)             ← 机头指敌
绘制点与gunFx起点均改用 strafe 坐标
```

**失败机理（6条，全部要避开）：**
1. **双读取点**：绘制与gunFx分两处取坐标，补丁期越改越散；
2. **依赖敌机实时位**：敌机跨省/状态切换时其坐标跳变 → 拉着我机瞬移（300~800px级）；
3. **窗口边缘回弹**：pct在1200ms窗口末尾回0 → 位置从"滑到一半"直接弹回（无包络）；
4. **反馈回存**（R4c155+）：spx/spy跨帧回存制造双推进/锯齿/回正角（已废弃，永久禁用此模式）；
5. **满钟/锚点**（R4c156/157）：段时钟预设与回退锚点不一致 → 首帧跳变；
6. **7轮补丁叠加**（R4c150~158）：每次只修表象，根结构未变 → 越修越多。

## 二、新设计铁律（写死，任何方案不得违反）

- **P1 单权威源**：一个 mission 的"显示位置"只允许一个只读计算函数产出；绘制与特效必须调用同一函数（同帧同值）。
- **P2 禁止跨帧回存**：绝不新增"上次位置/回存/记忆坐标"类字段来修跳变。
- **P3 连续函数**：位置对时间的函数必须在"进入/退出各阶段"两端连续（不能有窗口边缘回弹）。
- **P4 安全阀降级**：任何外部引用（敌机位等）缺失/超距/异常 → 降级到自身稳定锚点，绝不画错位。
- **P5 分层验收**：每层改动单独构建/装机/实战验证，绿了再叠下一层。

## 三、方案

### 方案A｜停靠可见（最小集）
- 内容：st2 追加一跳进入停靠绘制路径（`:cond_6b`），飞机停在自身省槽位；朝向用最后航向（dispHeading）或默认。
- 改动：PDA约 **2~3 处编辑**（+4行内）。
- 风险：**极低**（纯增绘制路径，零物理字段改动；敌我双方同时生效）。
- 观感：交战时飞机停在省槽位可见，曳光从机位喷出；不再"凭空冒子弹"。
- 验收：交火场景截图；nGX fire 窗口内弹流起点=槽位。

### 方案B｜A + 机头对准敌机（原地转向）
- 内容：停靠绘制时 `v1 = smoothHeading(calcHeading(敌机位-自身位))`；敌机缺失 → fallback dispHeading。
- 改动：约 **+40行**（1个简化版"找敌机+算方向"只读helper）。
- 风险：**低**（只影响贴图旋转，不碰位置；smoothHeading 为既有机制）。
- 观感：飞机原地调头锁定敌机扫射，"交战感"明显。
- 验收：截图观察机头指向；敌机击落后机头自然回落。

### 方案C｜B + 短半径扑进（正弦包络，无状态）
- 内容：位置 = 槽位 + 方向(敌机) × **正弦包络偏移**（幅度≤40px，周期≈1.4s循环；纯时间函数）。
  - 安全阀：敌机位缺失或距>200px → 偏移=0（原地不动）；偏移永不超过40px。
  - 进出场：正弦两端归零 → 与"到达/返航"节点只留≤40px一次收敛（叙事节点，可接受）。
- 改动：约 **+50~60行**（1个只读 helper；绘制与gunFx共用同一函数 → 满足 P1）。
- 风险：**中低**（首次引入"位置增强"，但无任何回存/反馈，数学上有界）。
- 观感：交战时飞机小半径"扑进-回位"循环扫射（贴近原"突击跑位"意图但幅度受控）。
- 验收：逐帧位置核算（有界、连续）；st2→st3边界SNAP=0；实机录屏。

### 方案D｜C + 交火视觉强化（纯特效层）
- 内容：
  1. **敌方弹流补画**（红色，从敌机位朝其目标方向）——现在完全缺失；
  2. 我方弹流方向改为"指向敌机"（只改特效方向，不改飞机）；
  3. 可选：命中火花/枪口闪光（小像素块脉冲）。
- 改动：约 **+40~70行**（FX层；不碰位置链）。
- 风险：**低-中**（特效循环遍历，注意性能与颜色复原）。
- 观感：双向对射、你来我往的"机炮战"完整呈现。
- 验收：截图对比左右双方弹流；帧率无感降。

### 备用E｜架构级：攻击航段主链化（暂不推荐）
- 把"扑进"做成动画时钟（sa/sd）的一部分（真实航段），最"物理正确"，但需动主链/新字段/长验证周期；仅当 C 仍不满意时再评估。
