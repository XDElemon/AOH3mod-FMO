# 机炮特效"从属式跟随" · 可行性论证 v1

- 日期：2026-09-15（基线 R4c143 / dex `43f9a17f…`）
- 用户定义的目标效果：**飞机按自己原有逻辑正常跑（停/走都行，不要求到达任何位置）；机炮特效是"挂件"，永远从属于飞机贴图——飞机在哪，弹流就从哪喷。**

## 一、结论（先行）

**可行，且是本项目有史以来难度最低的一次改动：1 处编辑（净 +6 行内），零新字段、零新坐标源、零反馈回存。**

关键发现：**"从属关系"在当前代码里已经天然成立**——机炮特效的起点函数与飞机贴图的坐标函数**是同一个**（`getAirSpriteX/Y`）。唯一的缺口只有一个：**st2（交火停靠）状态下飞机贴图没有绘制**，导致"特效有坐标可跟，但没有飞机可看"。

补上这一个缺口，全部开火场景即闭环。

## 二、逐场景核对（现状 → 缺口）

| 场景 | 飞机贴图 | 机炮特效起点 | 从属关系 | 需要做什么 |
|---|---|---|---|---|
| **st1 途中开火** | ✅ 在画（pv→at 滑行 lerp，移动中） | `getAirSpriteX/Y`＝同一个移动坐标 | ✅ **已经完全从属**（特效自动跟着移动中的飞机） | **什么都不用做**（"没跑到目的地也没关系"天然满足） |
| **st2 交火停靠** | ❌ **不画（状态过滤 skip）** ← 唯一缺口 | 坐标函数照常返回"省槽位" | ⚠️ 有坐标无贴图（弹流像从虚空喷出） | **补一跳：st2 → 停靠绘制路径** |

| 敌方视角 | ❌ 同样不画 | 敌方弹流本就无特效（与本次无关） | — | 顺带对称受益：补跳后敌方 st2 也可见 |

## 三、实现方案（精确到行）

**唯一修改点**：`ProvinceDrawArmy.drawAirDivisionAsPlane` 状态检查处（PDA:476-483）。

```
现状：
    const/4 v0, 0x3
    if-eq v3, v0, :cond_27      # st3 → 滑行绘制
    # R4c113: not EN_ROUTE/RETURNING -> skip
    goto :r4c113_ret            # 其它状态（含 st2）→ 不画

改为（R4c159）：
    const/4 v0, 0x3
    if-eq v3, v0, :cond_27      # st3 → 滑行绘制
    const/4 v0, 0x2
    if-eq v3, v0, :r4c159_st2   # st2 → 停靠绘制（新增）
    # R4c113: not EN_ROUTE/RETURNING -> skip
    goto :r4c113_ret
    :r4c159_st2
    iget v1, v2, ...->dispHeading:F   # 用最后航向旋转贴图（与弹流方向完全一致）
    goto :cond_6b               # 现有"停靠绘制"路径（久经考验）
```

- st2 绘制位置 = 调用方传入的**省槽位**（p1/p2 不动）＝ `getAirSpriteX/Y` 同值 → **贴图与弹流严格同点**；
- 贴图旋转 = `dispHeading`（最后平滑航向字段）＝ 弹流方向字段 → **同向**（真正的"从属"）。

## 四、可行性依据（逐项验证过的代码事实）

1. **"停靠绘制"路径（`:cond_6b`）本来就兼容 v2 非空**：
   该路径同时服务"(a) 无任务停靠"与"(b) st1/st3 正常绘制 fallthrough"两种情况——环、机型贴图（拦截/轰炸/攻击/战斗四型）、HP 环、血量文本、探针全部走通，直接复用零风险。
2. **数据链同源**（从属的技术本质）：
   - 贴图位置：`drawAirDivisionAsPlane` → 槽位（=调用方传参=同省同部队槽位）；
   - 特效起点：`drawAirGunFx`（PDA:8559）→ `getAirSpriteX/Y` → 同一槽位；
   - 特效方向：`drawAirGunFx`（PDA:8580）→ `dispHeading`；贴图旋转同样取 `dispHeading` → 同值。
3. **寄存器安全**：跳点处 v0/v3（状态判定用）、v1（旋转用，原本初始为0）均空闲可用；**无 `.registers` 变更**。
4. **零新增**：无新字段、无新函数、无新时钟、无桩、无条件缓存——与"回存/满钟/锚点"三类历史坑**零交集**。
5. **性能**：仅把"多状态过滤不再跳过 st2"，绘制调用本就每帧发生（省部队循环），开销≈0。

## 五、已知边界与残留（诚实标注）

1. **入/离场一次"槽位↔省中心"小收敛**：
   st1 滑行终点 = 省中心（`getAirDrawPosX`），st2 停靠位 = 省中心+该部队槽位偏移（`getArmyPosX`，含 `iShiftX/iShiftX_Scaled`）→ **到达瞬间与起飞瞬间各可能有一次数十像素级的瞬时对位**（量级=该部队槽位偏移；发生在"到达/起飞"叙事节点）。
   - 评级：可接受（历史问题都是 300~800px 级瞬移；此为 ≤数十px 且语义上就是"入场停稳/出发"）。
   - 若实测明显，后续可选打磨（把 st1/st3 的 LERP 端点或停靠基准统一到同一坐标口径）——**但不建议在本次一并动**（避免再次触碰主链）。
2. **敌方弹流特效仍缺失**（现状本就如此，与本次改动无关；如需要可另立小项补画）。
3. **弹流方向=飞机航向**（不是"枪口指向敌机"）——严格符合"从属"定义；若要"打完自动指向敌机"另议（此前方案B）。
