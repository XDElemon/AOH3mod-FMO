# 0. 一页摘要

**钢四科技系统 = 5 层结构**：

```
ledger 页签(4)  →  folder 分页(16)  →  tech 技术(478)  →  category 类别(115)
                                    ↘ 学说树（独立第二套：12 大学说 / 14 轨 / 13 组子学说）
                                    ↘ 配套四件套：研究槽 · 年份门槛 · 特殊项目 · MIO 军企
```

**游戏（AoH3）现状 = 1 棵树 / 99 节点 / 最多 2 前置 / 无年份门槛 / 无页签 / 无学说 / 无模块。**

⇒ 结论先说：**"骨架与节奏"可以高度对齐（纯资源改，不动 dex）；"页签 / 年份硬门槛 / 模块化 / 特殊项目"必须改码，且部分在游戏里没有对应机制，属"做不到或代价极大"。**

## 1.2 单条技术的完整字段（钢四能给什么）

`research_cost`（研究成本）· **`start_year`（年份门槛）** · `path { leads_to_tech, research_cost_coeff }`（后继与成本系数）· `categories[]`（类别，用于加成）· `enable_equipments`（解锁装备）· `enable_equipment_modules`（解锁模块）· `folder { name, position {x,y} }`（页签内坐标）· `allow / allow_branch`（可研究条件）· `on_research_complete`（完成后脚本效果）· `ai_will_do`（AI 倾向）· `special_project_specialization`（特殊项目专家化）· `sub_technologies`（子技术，如枪炮分级）· `xp` 相关（解锁/加速研究）。

## 1.3 category（115 个）

用途有三：**研究加成乘区**（国策/理念/科技共享给"某类别"加速）、**AI 权重**、**MIO 覆盖范围**（如 `mio_cat_all_light_fighter_and_modules`）。粒度极细：既有 `light_air/medium_air/heavy_air`，又有 `cat_air_engine / cat_air_guns / cat_air_bombs` 这类模块类别。

## 1.4 研究机制底层参数（`common/defines/00_defines.lua`）

| 参数 | 值 | 含义 |
|---|---|---|
| `BASE_RESEARCH_SLOTS` | 2 | 基础研究槽数（可增加） |
| `BASE_RESEARCH_POINTS_SAVED` | 30.0 | 每槽可囤的研究点 |
| **`BASE_YEAR_AHEAD_PENALTY_FACTOR`** | **2** | **提前研究惩罚系数**（早于 `start_year` 研究，成本翻倍级增加） |
| `MIN_RESEARCH_SPEED` | 0.1 | 研究速度下限 |
| `DEFAULT_XP_UNLOCK_RESEARCH_COST` / `BOOST` | 0 | 用经验直接解锁/加速研究 |
| `RESEARCH_DAYS_BETWEEN_WEIGHT_UPDATE` | 7 | AI 研究权重刷新周期（天） |
| `RESEARCH_*_DOCTRINE_NEED_GAIN_FACTOR` | 陆 0.15 / 海 0.05 / 空 0.07 | AI 对学说的需求系数 |
| `RESEARCH_WEIGHT_TRUNCATION_THRESHOLD` | 0.75 | AI 选择的随机截断 |

⇒ **"年份门槛 + 提前惩罚"是钢四节奏感的真正来源**，游戏侧**完全没有对应物**。

## 1.5 学说树（独立于 tech 的第二套系统）

- **folder（域）4 个**：`land` / `naval` / `air` / `special_forces`（后者需 AAT 或 NCNR）。
- **grand doctrine（大学说）12 个**：陆 4（机动战 / 优势火力 / 大决战计划 / 人海）、海 3、空 3、特种 2。
- **track（轨）14 条**：陆 4（步兵 / 战斗支援 / 装甲 / 作战）、海 4、**空 4（`fighter_aircraft` / `strike_aircraft` / `medium_aircraft` / `heavy_aircraft`）**、特种 2。
- **subdoctrine（子学说）13 个文件**：陆 4 组、空 4 组（各 6–7 条）、海 3 组、特种。
- **解锁货币是 XP，不是研究点**（`xp_cost = 100`，`xp_type = army`）；且有 **mastery（熟练度）**：按装备经验累积，`multiplier = 8.0`。
  - 例：空学说 `fighter_aircraft` 轨吃 `fighter / interceptor` 经验；`strike_aircraft` 轨吃 `cas / naval_bomber`；`medium_aircraft` 轨吃 `tactical_bomber / heavy_fighter / scout_plane`。

## 1.6 配套四件套（决定"体系感"的其余部分）

| 系统 | 位置 | 规模 | 作用 |
|---|---|---|---|
| 特殊项目 | `common/special_projects/`（projects 7 文件 + prototypes + specialization + project_tags）＋ `scientist_traits` | 7 组 | 科学家 + 原型机 + 专家化 |
| MIO 军工企业 | `common/military_industrial_organization/`（organizations 56 文件 + policies + ai_bonus_weights） | 56 | 企业升级、政策加成 |
| 技术共享 | `common/technology_sharing/` | 10 组 | 阵营/小组间共享研究 |
| 经验 XP | 陆/空/海/政治四类 | — | 学说解锁与部队改装 |

# 4. 四个可选方案（**请你选一个**）

## 选项 A｜结构骨架对齐（推荐起步）
把现有 99 节点**重排成"钢四式分带"**：横向＝年代列（沿用 0..41 时代轴），**纵向按类目分段**（步兵 / 支援 / 装甲 / 火炮 / 空军 / 海军 / 工业 / 电子 …），每段内保持单链推进 + 最多 2 前置；空军带同时接四型单位的 `RequiredTechID`（16 节点方案）。
- **代价**：纯资源（`Technologies.json`），不动 dex，可秒回滚。
- **批次估算**：3～4 批（先空军带验收 → 再工业/电子 → 再陆海）。
- **风险**：坐标手工排布易挤；加节点后 AI 权重需调。
- **像不像钢四**：布局像，机制像；**没有页签**（是单页分带）。

## 选项 B｜A + 学说模拟（"体系感"最划算的一步）
在 A 之上加**独立"学说带"**：用 12 条"大学说方向链"（机动战/优势火力/人海/大决战…）＋ 用节点的**全局加成字段**做效果（攻击/防御/战斗宽度/纪律/士气）＋ 用 `Repeatable` 节点模拟"熟练度/可叠加"。
- **可选**：是否让学说**互斥**（用前置链 + 唯一路径模拟）。
- **代价**：以纯资源为主；若要"互相排斥且能换"需少量改码。
- **批次估算**：2～3 批。
- **价值**：这是"以后各方各面都会受影响"的那一层 —— 学说一旦立起来，陆战/海战/空战/特种都能挂。

## 选项 C｜全体系仿制（页签 + 年份 + 模块）
A + B + **ledger 页签 UI** + **年份硬门槛/提前惩罚** + 装备模块/特殊项目/MIO 的替代实现。
- **代价**：需要改 UI（`InGame_TechnologyTree` 相关）+ 研究逻辑（可研究判定/成本计算）+ 单位系统（模块化本质要重做）。
- **批次估算**：10+ 批，且**存在做不到的部分**（per-unit 模块、MIO 语义）。
- **风险**：最高；建议**不作为首选**，而是"B 完成后逐项追加"。

## 选项 D｜保守试点（先只做两条带）
只做 **空军带 + 工业带**，验证"分带 + 单位解锁 + 图标"方法论，再决定是否扩到全树。
- **代价**：1～2 批，风险最低。
- **价值**：适合先看到"能对齐"的实感，再投入大工程。

1. **选哪个选项**：A / B / C / D？
2. **重排范围**：整棵树 99 节点全重排，还是先选定几条带？

7. **图标资产**：是否批量生产科技图标（当前全树共用 2 张）？按 99 节点还是只做新增节点？
