# C2 设计讨论 · 贴图路由（国别 → 四大美术组）v1

> 2026-10-01｜调研实证 + 用户口径（泛非→中/俄、日本→美、印度→交叉、东南亚待查）

## 一、调研硬事实
1. 游戏国家是**逐国 JSON**：`assets/game/civilizations/<tag>.json`，**共 3854 个**；字段只有 `Tag / iR,iG,iB / ReligionID / Wiki` ⇒ **没有大洲/区域字段**。
2. 但 **`Province` 有大洲与区域字段**（决策性）：
   - `private iContinentID:I`（大洲）
   - `private iGeoRegionID:I`（地理区域，比大洲细）
   - `private iCivRegionID:I`、`private iMapModeRegion:I`
   ⇒ **可用"国家首都所在省的区域"来路由**，不必给 3854 国逐个配表。

## 二、路由设计：三级（L1 → L2 → L3）
```
若 该文明在 L1 显式表  → 用它指定的美术组（并可指定具体型号家族）
否则若 其首都省的 iGeoRegionID/iContinentID 命中 L2 区域组 → 用区域默认组
否则 → L3 兜底（默认美系 / 或按 religion 再兜）
```
- **L1 显式表**（约 30–40 国，覆盖 mod 关注的列强与主要国家）：中、俄、美、欧（德法英意）、日、印…
- **L2 区域默认组**（覆盖 3800 余小国）：
  | 区域 | 美术组 | 依据 |
  |---|---|---|
  | 东亚（除中日） | 中 或 俄 | 朝鲜/蒙古 → 俄系或中系 |
  | **东南亚** | **交叉（美/俄/中）** | 见 §三 |
  | 南亚 | 印度→交叉；巴基斯坦→中；其余→俄/欧 | 历史军购 |
  | 中东 | 美/俄 对半（亲美君主国→美，其余→俄） | 历史军购 |
  | 非洲（凡非） | **中/俄**（北非偏俄，撒南偏中/欧） | 用户口径 |
  | 拉美 | 美（巴西/智利可欧） | 历史军购 |
  | 大洋洲 | 美/欧 | — |
- **L3 兜底**：默认美系（最中性）。

## 四、开局代际（用户问：开局是三代吧？）
- **是**：模组 2000 年开局 ⇒ **三代机为基本盘**（Su-27/J-8/F-14/F-15/F-16 一代人）；
- **四代机**（F-22 2005 服役、J-20 2011、Su-57 后期）⇒ **开局不该成建制**，走科技树解锁；
- **五/六代**（J-36/F-47 等）⇒ 纯科技树后期内容。
- 具体：开局各国空军**默认配 3 代图**；能造几代由科技树决定（用户已定用科技树解锁）。
