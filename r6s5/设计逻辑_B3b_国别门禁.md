# 设计逻辑 · B3b 国别门禁（r6d260）——11 项

> 2026-10-11｜《终序千禧》AI 空军 MOD｜类型：代码批（零资源改动）

## 1) 版本号 + 一句话定位
r6d260：给四国空军科技线**上锁**——每个国家**只能看到、只能研究**自己那条线（他国的在树里直接消失）。

## 2) 设计目标
- 玩家可见的问题：B3 之后四条线对全世界可见、任何国家都能研究别人的飞机（AI 也会）。
- 上层意图：**"区分国别"**闭环——内容（B3：谁有什么线）+ 上锁（B3b：谁只能碰哪条线）。用户明确定义："只能在指定国家看到指定国家的科技树，其他国家的看不到。"

## 3) 设计规则与判定顺序（人话）
判定链（对任一"科技 ID × 国家"）：
1. **若 科技 ID < 32** → 允许（旧科技，全世界照旧，不受本批影响）；
2. **若 科技 ID > 74** → 允许（将来新增的其它段，本批不管）；
3. **若 32 ≤ ID ≤ 74**（=四国空军块）→ 按段定"该科技属于哪国"：
 - 32–44→中｜45–54→美｜55–63→欧｜64–74→俄；
4. 该国的实际分组 = **既定路由表**（日/韩→美；德法英意→欧；印→俄；其余兜底俄——与美术、发放同一张表）；
5. **组相等 → 允许；不等 → 拒绝**。
生效面（两处，一处管"看得见"、一处管"能研究"）：
- **看得见**：科技树绘制时逐节点判——不允许 ⇒ **整个节点跳过**（按钮、连线都不生成）；
- **能研究**：可研究闸门 `getAvailableToResearch` 在原有条件（前置满足等）全部通过后**追加**本判定——不允许 ⇒ 返回"不可研究"。研究队列 / 选择界面 / AI 选科技全部自动跟随。

## 5) 状态与生命周期
- **无新实体、无持久化**：每次开关科技树/每次判定都即时计算（"科技 id + 国家"直达结果）。
- 生命周期：科技树打开 → 逐节点判定（跳过/绘制）→ 玩家操作走闸门 → 关闭即结束。存档零影响。

## 6) 边界与不变量
- 对齐：复用 **`AirForceManager.artGroupOf` 单一路由源**（门禁=美术=发放，永不分家）。
- 不修改：旧 32 节点行为、B3 资源、任何其它系统；不做存档改造。
- 约束：判定独立成方法（不内联）；两棵树同步；不新增资源。

## 7) 玩家可感知的表现
- 正常：树里**只出现自家块**（中国只看到中国空军；日本只看到美国空军…）；研究选择列表无他国；AI 正常研究自家线。
- 异常样子：全隐藏（判定永假）/全可见（判定没生效）/某国映射错位（报"哪国看到哪国"即可定位）。

## 8) 失败与回退
- 本批无"不出兵"类节流问题（不涉及空军出动）。
- 边缘：过渡期旧存档若已研他国科技 → 单位已解锁、节点被隐藏（看不到但已有）——已声明不处理。
- 回退：重装 `b3_v4`。

## 9) 验收标准（可证伪）
- 中国→仅中国块；日/韩→美块；德法→欧块；印→俄块；小国→俄块；旧树全在；研/队列/选择无他国；AI 正常；无崩溃。
- **已通过：用户"验收成功"（2026-10-11）。**
