## 1) 版本 + 定位
只改 `InGame_AirForceOptions$BtnMission`：**把"取机场"重写成永不哑（省反查不再被空列表短路）＋ 把按键全链的探针一次打全**（入口／机型／目标机场／翻转结果／收尾／失败原因）。

## 2) 设计目标
- 上一批（q）已定位：**点击确实进了这个类（`afp:ent`×24），但 `pickAirport()` 每次返回 null** ⇒ 按钮在 null 判据处静默返回。
- q 版的实现缺口：`pickAirport` **先取列表，列表为空就立刻 null**，之后才轮到"省反查"（而省反查根本不依赖列表）⇒ 只要那一刻列表取回空/null，按钮就永远哑。
- 本版目标：①**让取机场永不哑**（除"无玩家/无 AFM"）②把失败原因与执行进度全部记进日志。

## 3) 设计规则与判定顺序（新版 `pickAirport(I who)`）
```
if player==null → afp:n=(who*10+1) → null
if AFM==null    → afp:n=(who*10+2) → null
list = getAirportsForCiv(player.iCivID); size=(list==null?0:list.size())
① size>0 且 0<=iActiveID<size                 → list[iActiveID]
② selectedAirportProvinceID>=0 且反查非空      → 返回（src=2）
③ Game.iActiveProvince>=0 且反查非空           → 返回（src=3）
④ size>0                                       → list[0]（src=4）
全失败                                          → afp:n=(who*10+9) → null
成功且 who==1（按键侧）                          → afp:src=(who*10+src)
```
**关键更正**：`size<=0` **不再短路**——②③ 与列表无关，必须照试。

## 4) 参数与阈值表（探针读法）
| 探针 | 触发 | 读法 |
|---|---|---|
| `afp:ent` | 按键进入方法 | 没出现＝点击没进类 |
| `afp:mt` | 拿到机场后 | 0=自动巡逻键 ／ 1=自动打击键 |
| `afp:press ap=` | 拿到机场 | 实际作用的机场省号 |
| `afp:strike new=` | 打击键翻转后 | 0=开 ／ 1=关（证明翻转真的执行） |
| `afp:src` | 仅按键侧成功 | who*10+src（1=列表选中行 2=选中省 3=活动省 4=list[0]） |
| `afp:n` | 失败（任一侧） | who*10+原因（1 player空 2 AFM空 9 全失败） |
| `afp:` | `actionElement` 结果为 null | 与 `afp:n` 联读 |
| `afp:tgt fb=` | 显示侧兜底层 | 2/3/4 |
| `afp:done` | 执行到收尾（`rebuildInGame_AirForce`） | 没出现＝中途 return／抛异常 |

（who：**1=按键侧**，**2=显示侧**；成功来源探针只在按键侧记录，避免每帧刷日志）

## 7) 玩家可感知的表现
按一次「自动打击」⇒ 日志按序出现 `afp:ent` →（`afp:src`）→`afp:mt=1` → `afp:press ap=<省>` → `afp:strike new=` → `afp:done`；机场 dump 的 ` strike=` 翻转、按钮文本同步；随后战时智能线放行（`nA4d`→`nA4e k=0`）。

## 8) 失败与回退
- 若出现 `afp:n=11/12/19` ⇒ 直接给出 null 原因（player空／AFM空／全失败）；
- 若只有 `afp:ent` 而无后续 ⇒ 中途 return 或抛异常（异常会被 `Menu.actionElement` 的 catch 吞掉，看 logcat）；
- 装机异常 ⇒ 重装 r5c046q。
