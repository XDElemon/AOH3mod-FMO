## 1) 版本 + 一句话定位
把**玩家侧**「自动打击」从只有轰炸机（老线）扩成 **攻机 + 轰机两条线**，并**关掉老线玩家战时轰炸防双发**；AI 链一行不动。

## 2) 设计目标
- 可见问题：玩家侧**攻击机没有自动出击路径**（老线只派轰炸机）。
- 上层意图：复原 R4c192~R4c205 的玩家侧行为，但**不做 UI 面板、不做配置驱动**；总闸沿用现成的「自动打击」按钮。

## 3) 规则与判定顺序
### 3.1 派发层 `updateOffensivesP(civID)`
1. **关0 非玩家文明早退**（`Game.player==null` 或 `player.iCivID != civID` ⇒ return）
2. `getAirportsForCiv(civID)` → 逐机场
3. **总闸**：`airport.autoStrikeOff != 0`（开）⇒ 跳过本机场
4. 对 **ATTACKER**、**BOMBER** 各调一次 `tryStrikeForAirportP(ap, rnd, type)`
> 同一 `Random` 实例贯穿本 civ 的所有机场（对齐原档"每机场一次 rnd"）。

### 3.2 单机场单机型 `tryStrikeForAirportP`（七道关）
| # | 关 | 真值表 |
|---|---|---|
| ① | **文明门** | `player==null` ⇒ 跳过；`player.iCivID != airport.civID` ⇒ 跳过 |
| ② | **总闸** | `autoStrikeOff != 0`（开）⇒ 跳过 |
| ③ | **概率门 0.2f** | `rnd >= 0.2` ⇒ 跳过 |
| ④ | 空闲师 | `pickIdleDivKey(ap,type)==null` ⇒ 跳过 |
| ⑤ | 非巡逻中 | `hasActivePatrol(ap,divKey)==true` ⇒ 跳过 |
| ⑥ | 选靶 | `pickStrikeTargetP(ap,type) < 0` ⇒ 跳过 |
| ⑦ | 建任务 | 建成后 `assignedAircraft.isEmpty()` ⇒ 不入列；否则 `activeMissions.add` ＋ 探针 `nAS` |

### 3.3 选靶 `pickStrikeTargetP`（最近优先）
候选＝`getEnemyProvincesInRange(ap,type)`；逐省：
1. 文明门（public 方法自守）
2. **战争门**＝`DiplomacyManager.isAtWar(ap.civID, prov.getCivID())`（**禁用** `AFM.isAtWar(I)`）
3. **驻军门**（仅 ATTACKER）：`getArmySize() > 0`
4. **视野门**（仅 ATTACKER）：`getFogDrawArmy()==true`
5. **去重门**：`hasStrikeInFlightP(pid,type)==false`
6. **最近优先**：`provinceDistance(ap.civID→省, pid)` 取最小

### 3.4 老线闭合（防双发）`executeAIAssignmentForAirport`
在战时分支的 `p0War("nA4d")` 探针之后插入：
```
sget-object v3, Game->player
if-eqz v3, :phaseA_notplayer          # 无玩家 ⇒ 不短路
iget v3, v3, Player->iCivID:I
iget v2, p1, Airport->civID:I
if-eq v3, v2, :cond_a3                # 是玩家机场 ⇒ 短路到退出
:phaseA_notplayer
```
⇒ 只关**玩家文明的战时轰炸分支**；概率门(0x3dcccccd 0.1f)、和平巡逻分支、AI 派发全部保持原样。
