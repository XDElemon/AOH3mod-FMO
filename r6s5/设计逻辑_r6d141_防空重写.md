## 一、设计逻辑（11 项）

### 1) 版本号 + 一句话定位
**r6d141（v119 / 1.035-DEMO.1）** —— 把"防空阵地自动开火"（AD-1）**整类重写**：从"自己扣血、自己写死机标记"改成"走游戏自己的击落记账管线"。动的是 **空军防空系统**，不碰雷达/中层反导雷达/空袭/科技。

### 2) 设计目标（玩家可见的问题 + 上层意图）
- 可见问题：装上 r6d138–r6d140 后，防空要么不开火（r6d138 极性全反），要么开火也**打不出"真正的击落"**：飞机 hp 被扣光却仍留在任务编队与机场名册里（幽灵机），任务永不收尾。
- 上层意图：让"防空阵地 = 一座永远驻守的空军师"这条设定成立 —— 它能真的把飞机从天上打下来，且**打完的账目与游戏自己打下来的账目一致**（编队、机场、任务池 HP 都同步）。

### 3) 设计规则与判定顺序（若…则…）
```
每回合（AirForceManager.update(civ) → AirDefense.tickSafe(civ)）
 ① 若本国的省 id < 0 或 ≥ 省份总数 → 跳过该省
 ② 若该省"反导阵地数" ≤ 0 → 本省本回合不开火
 ③ 若该省"射程内的合格敌任务数" ≤ 0 → 不开火、不写日志
 ④ 否则发射 N 发（N = 本省反导阵地数，每座阵地 1 发）
    第 s 发的靶 = 合格敌任务列表里的第 (s mod 合格数) 个（轮转，不重复偏心）
 ⑤ 每发单独判定命中：若 rand < 0.5 → 命中；否则未命中
 ⑥ 命中 → 对该任务施加 3.0 点伤害（伤害池倾泻：从编队第 1 架起扣，溢出打下一架）
 ⑦ 若被扣飞机的 hp ≤ 0 → 立刻"记落"：出 aliveAircraft、进 lostAircraft、出机场名册
 ⑧ 若有飞机被记落 → 重算任务 HP 池（recalcPool）
 ⑨ 每省每回合写一行探针（阵地数/目标数/发射/命中/击落）

判定优先级：省合法性 > 有阵地 > 有目标 > 命中 > 伤害 > 记账
```
关键子判定：
- "合格敌任务" = 非空 **且** 不是本国的 **且** 编队里还有飞机 **且** 在射程内（三个条件全真才算）。
- "在射程内" = 该任务当前所在省与自己同省（必中），**或**两省中心距离 ≤ 300px（含等号）。
- 未部署的任务（`airDivisionAtProvinceID = -1`）永远不算目标。

### 4) 参数与阈值表
| 名称 | 当前值 | 单位 | 含义 | 调大/调小 |
|---|---|---|---|---|
| 射程 | 300 | px（省中心距） | 阵地能打到多远的省 | 大=覆盖更多省、更易触发 |
| 命中率 | 0.5 | 概率/发 | 每发命中概率（空位） | 只改 `adHitChance` |
| 每发伤害 | 3.0 | HP | 命中后扣多少（空位） | 只改 `adDamagePerHit` |
| 发射数 | = 阵地数 | 发/回合/省 | 每座阵地 1 发 | 由建筑数量决定 |
| 命中判据 | rand **<** 命中率 | — | 相等算未命中 | — |
| 击落判据 | hp **≤** 0 | HP | 等于 0 算击落 | — |
| 机型血量 | 战/截 4.0、攻 6.0、轰 8.0 | HP | 实测 | — |

### 5) 状态与生命周期
`反导阵地（省建筑）` → 计数器 → 每回合每省一次开火 → 每发一个靶任务 → 命中后扣血 → `hp≤0` 时"记落"（编队出 / 损失列表进 / 机场名册出）→ `recalcPool` 重算任务血池 → **任务收尾交给游戏自己**：编队空了以后，游戏原有的 `allAircraftLost()`（在它的 `update()`/返航路径里）会把任务收掉、飞机回基地流程走完。

### 6) 边界与不变量（对齐/不改/必须成立）
**对齐**：`AirMission.recordLoss` / `recalcPool` 是游戏自己的公开方法，账目口径与游戏空战完全一致；伤害池模型复刻游戏 `applyAirDamage`（从编队头扣、溢出顺延）。
**不修改**：雷达与中层反导雷达（只探测不开火）；停放飞机（不在任何任务里）；资源（防空不耗弹不耗钱）；对 AI 与玩家一视同仁（无分支）。
**必须成立**：不写 `isAlive/isShotDown/isInFlight`（游戏战斗全程不写这三个，只有构造/存档/resetRound 碰）；所有 `getProvince` 调用前先判 `0 ≤ id < 省份总数`（该 API 内部是裸 `List.get`，越界直接抛）；列表一律索引循环，禁用迭代器（记落会改列表）。

### 7) 玩家可感知的表现
- 正常：敌机飞进有我方反导阵地的省（或 300px 内），会**逐回合掉血**；打光最后一架时，该任务从空情里消失、飞机数从机场名册里减少（不再留幽灵）。
- 数值：每次命中固定 -3.0 HP；命中率 50% ⇒ 单回合可能不中（正常）。
- 日志（`aircfg_diag.txt`）：`nAD p=<省> n=<阵地数> t=<目标数> s=<发射> h=<命中> k=<击落>`；`nADT c=<国家>` 每回合自证；异常才有 `nADX <类型>`。
- 异常：若出现 `nADX`、或击落后机场名册仍有该机、或编队里出现 hp≤0 的飞机 → 不通过。

### 8) 失败与回退（哪些不出兵是正常的）
| 情况 | 判定 |
|---|---|
| 本国没有"射程内有敌机"的省 | 正常：只会有 `nADT`，没有 `nAD` |
| 有 `nAD` 但 `h=0` | 正常：50% 命中率 |
| 目标为友军任务 / 空编队任务 / 未部署任务 | 正常：不出兵 |
| `AAA_BUILDING_ID < 0`（本 mod 没这个建筑） | 正常：全不开火 |
| 出现 `nADX` | 异常（已由兜底吃掉，不会崩游戏）；看异常类型 |
| 崩溃/闪退 | 属异常，立即抓 `logcat -b crash` + `aircfg_diag.txt` |

### 9) 验收标准（可证伪）
1. 进游戏过 1–2 回合 ⇒ `aircfg_diag.txt` 里有 `nADT c=…`（≥1 条）。
2. 让我方飞机飞进**敌方有反导阵地**的省 ⇒ 出现 `nAD p=…` 且 `t ≥ 1`、`s = n`。
3. 连续几回合 ⇒ 目标掉血；击落时该机同时在任务编队与机场名册里消失。
4. 停在机场（未出击）的飞机 hp 全程不变。
5. 点军队 / 开菜单**不闪退**。
6. 看到 `nADX` ⇒ 不通过，把该行发我。

### 10) 变更清单摘要（相对 r6d140）
- 删：旧 `pickAlive`、旧 `fireAtMission`（任选机 + 无记账）、`dKey` 通道探针（会被 500ms 节流/被 debug 闸闸住）。
- 增：`eligible`（合格目标）、`countTargets`、`pickTarget`（轮转选靶）、`applyMdDamage`（伤害池 + 记账）、`rng`（静态随机源）、3 个探针方法（`logT/logX/logAD`，走 `dWrite`）。
- 改：`tick` 加"省 id 上界"守卫；`fireProvince` 改为"轮转选靶 + 记账"；`tickSafe` 的兜底从 `Exception` 提升为 **`Throwable`**。
- 不变：`adHitChance` / `adDamagePerHit` 空位签名；`AirForceManager` 里那 1 行调用；命中率/伤害数值。

### 11) 风险与待办
- 风险：命中率 50%，单回合可能 0 命中（正常）；`applyMdDamage` 里的"记落未生效则前进一格"是防死循环的保险，属正常分支。
- 待办：命中率/伤害接科技与代差（空位已留）→ 代际升级 → 空袭摧毁建筑 → 防空×空袭联动 → 导弹动画（A 曳光弹 / B 追踪弹，未选）。
- 观察项：`AirDbgLog` 遗留高频探针（`RBM_DRAWN`/`dAF_IN` 各 7 万行/局，单局 65MB）后续单独清理。

## 二、本批"跑模拟器"的实情（重要）

本机**没有可跑 AoH3 的 Android 模拟器**（游戏是 Android 原生 + libGDX，本机也无 ARM/x86 虚拟化可用）。所以本批的"模拟器"是**行为级仿真器**：
`r6s5/ad_sim_v6.py`（Python，逐条复刻同一判定链，模型类名与游戏类一一对应），**14 组用例全过**，含边界与负样本：
- 基本命中/不命中；命中率边界（0.5 算不中、0.4999 算中）
- 击落记账三件套（出编队 / 进损失 / 出机场）、溢出伤害顺延
- 最后一架被打掉 ⇒ 编队空（游戏自会收尾）
- 射程边界 300px 打得到 / 301px 打不到
- 未部署不打、友军不打、空编队不打、无阵地不打、建筑未定义不打
- 非法省 id 不抛异常；多阵地轮转选靶；多回合累积击落；AI 国打我方飞机
