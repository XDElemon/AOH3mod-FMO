## 1) 版本号 + 一句话定位

**r6d169** —— 防空工程重启的第一步：把 `AirDefense` 的判定链以**只读诊断**的形式放回游戏**每回合必经的全局入口**，只数数、不开火。动的是**空军防空系统的观测层**，不改任何战斗/伤害/记账行为。

## 2) 设计目标

- **玩家可见的问题**：上一轮 AD-1 装了以后，防空"从来不参与"（`nAD` 零行），看不出是**没建筑**、**没目标**、**打不到**，还是**国家根本没被处理**。
- **上层意图**：在恢复开火之前，先把"防空为什么不动"这件事**用数据钉死**；并且用"零行为改动"的版本做对照——若装上这个版本也出现任何异常，就一定不是防空代码引起的。

## 3) 设计规则与判定顺序（若…则…）

每回合（`GameThread_Turns` → `AirForceManager.updateAll()` → 注入的 1 行）：

```
① 自证：若 boot 标志为 0 → 置 1 并写一行 nABOOT（证明类加载 / 探针活着）
② 计数器归零（cap/skip/tA/tR/tM/pA/pR/pM）
③ 任务盘点 mline：若任务池存在 → 数出
     all=任务数；alive=其中"编队里还有飞机"的；dep=其中"已部署(airDivisionAtProvinceID≥0)"的；noDep=alive-dep
④ 省份扫描 pline：对每个省
     若 省份总数 ≤0 → 跳到 ⑤
     若 建筑 ID 未定义(<0) → 该类建筑计数记 0（不查表）
     否则 cnt() 统计该省的 反导阵地 / 雷达 / 中层反导雷达 数量
     累加全局总数与"有此建筑的省数"
     若 本省反导阵地数 >0 → 调 aline() 出一行明细
⑤ 全局行 gline：写 nADG（省数 + 三类建筑总数 + 有各类建筑的省数）
⑥ 截断行 trunc：若 被截断行数>0 → 写 nADTRUNC
```

`aline()`（单省明细）：

```
若 已写行数 ≥ 40 → 被截断行数 +1，返回（不写）
已写行数 +1
A = 该省主人国的机场数（getAirportsForCiv(civ).size()）
inR = inR(省, 省主人) —— 见下
写 nADA（t/c/p/aaa/A/inR）
```

`inR()`（射程内合格敌任务数）：

```
n = 0；取本省 id、省主人 civ、省中心 (px,py)
对 任务池 每个任务 m：
   若 live(m) 为假（无编队 / 编队为空）→ 跳过
   若 m.airDivisionAtProvinceID < 0 → 跳过（未部署）
   若 m.civID == 本省主人 → 跳过（自己人不打）
   若 m.所在省 == 本省 → n++（同省必中），继续
   若 m.所在省 ≥ 省份总数 → 跳过（防越界）
   取 m 所在省中心，若 (dx²+dy²) ≤ 300² → n++
返回 n
```

**判定优先级**：任务存在性 > 有活飞机 > 已部署 > 敌我 > 同省 > 距离 ≤300px。

## 5) 状态与生命周期

`AirDefDiag` 的静态计数器（cap/skip/tA/tR/tM/pA/pR/pM）**每回合开头归零**，回合内累加，回合末由 `gline/trunc` 出账；`boot` 一旦置 1 永不复位（保证"只写一次自证行"）。**没有任何游戏实体被创建、修改或回收**——本批不产生游戏状态。

## 6) 边界与不变量

- **对齐**：与 AD-1 规格（v6 定稿 §1）**同一套判定口径**（同省必中 + 300px 省中心距 + 只有"已部署且有活飞机"的敌任务算目标），这样两边数字可直接对比。
- **不修改**：`AirDefense`（仍在 `r6s5/ad_disabled/` 留档）；旧 AAA 段（停在敌境机场的飞机每 tick −1hp）；雷达/中层雷达逻辑；UI/渲染/存档；`AirForceManager.updateAll` 的 `.registers 4` 与既有控制流。
- **必须成立**：只读（不 `iput/sput` 任何游戏字段）；所有 `Game.getProvince(id)` 前判 `0 ≤ id < iProvincesSize`；`getInstance()` / `activeMissions` / `buildings` / `aliveAircraft` 全部判空；`scanAll` 用 `catch Throwable` 兜底，绝不外抛。

## 9) 验收标准（可证伪）

**通过**（看日志）：进游戏过 2–3 回合后，`aircfg_diag.txt` 里
1. 有 `nABOOT v=r6d169`（≥1 行）；
2. 有 `nADM`（≥1 行）且 `all>0`；
3. 有 `nADG`（≥1 行）；
4. **没有** `nADX`。

**诊断成功**（看数字，钉死根因）：

| 看到什么 | 结论 |
|---|---|
| `nADG aaa=0` | 反导阵地建筑**没被识别**（建筑 ID/名称不匹配） |
| `nADG aaa>0` 且 `nADM dep=0` | 全世界没有"已部署且有活飞机"的任务 ⇒ **目标口径 P1** |
| `nADM dep>0` 但所有 `nADA inR=0` | ⇒ **射程/部署判定 P2** |
| `nADA` 里 `A=0`（该国无机场） | ⇒ **P3：该国 `update(civID)` 永不调用** |

**不通过**：无 `nABOOT`；或有 `nADX`；或 2–3 回合后 `nADM/nADG` 一行都没有。
