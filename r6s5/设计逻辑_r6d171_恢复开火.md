## 1) 版本号 + 一句话定位

**r6d171** —— 防空从"只读诊断"进入"**真的开火**"：把留档的 r6d142 版记账伤害链放回游戏，并补上**每回合只结算一次的守卫**与**全局省份入口**（不再按国家）。动的是**空军防空系统**，不改空袭/雷达/建筑/科技。

## 2) 设计目标

- **玩家可见的问题**：防空阵地摆在那儿从不参与拦截。
- **上层意图**：让"反导阵地 = 一座常驻防空单位"成立——敌机飞进射程会被逐回合扣血，打光编队则从任务与机场名册里真正消失（不留幽灵机）。

## 3) 设计规则与判定顺序（若…则…）

```
每回合（AirForceManager.updateAll() 尾部，紧贴 return-void 之前）
  AirDefense.tickTurn():
     ① 若 本回合已结算过（TURN_ID == lastTurn）→ 返回【守卫】
     ② 否则 记录 lastTurn = TURN_ID
     ③ try { tickAll() } catch(Throwable) → 写 nADX（绝不外抛）

  tickAll():                       【全局：遍历所有省份，不看国家有没有机场】
     对每个 provinceID = 0 .. iProvincesSize-1:
        省为空 → 跳过
        nad = airDefenseAt(provinceID)  （= 该省反导阵地数量；建筑 ID 未定义则为 0）
        nad ≤ 0 → 跳过
        否则 → fireProvince(该省主人civID, provinceID, nad)

  fireProvince(civID, pid, nad):
     k = countTargets(civID, 省)   （合格敌任务数）
     k ≤ 0 → 不开火（也不写日志）
     s = 0 .. nad-1:
         靶 = pickTarget(civID, 省, s mod k)     （轮转选靶）
         若 rand() < 0.5 → applyMdDamage(靶, 3.0)，累计命中/击落
     写 nAD p=… n=nad t=k s=nad h=命中 k=击落
```

`eligible(任务, civID, 省)` 三条件全真：**敌方**（`任务.civID != civID`）+ **编队还有飞机** + **在射程内**（同省必中，或两省中心距 ≤ 300px）。
`applyMdDamage`：从 `aliveAircraft[0]` 起按"伤害池倾泻"扣血；`hp ≤ 0` → `recordLoss`（出编队/进损失/出机场）+ `recalcPool`。

## 5) 状态与生命周期

`反导阵地（省建筑）` → 每回合全局扫描计数 → 每省 1 轮开火 → 每发选一个合格敌任务 → 扣血 → `hp≤0` ⇒ 走游戏自己的 `recordLoss`+`recalcPool` 记账 → **任务收尾交给游戏**（编队空后 `allAircraftLost()` 收）。
`lastTurn` 生命周期：每回合被写成当前 `TURN_ID`；读档/新局后 `TURN_ID` 变化 ⇒ 首次必定结算一次。

## 6) 边界与不变量

- **对齐**：伤害口径与游戏 `applyAirDamage`（private，只复刻不调用）一致；击落账目与游戏空战同一套（`recordLoss`/`recalcPool`）。
- **不修改**：`AirDefDiag`（只读诊断，仍在 `updateAll` 开头跑，读"开火前"状态）；`AirForceManager.update(I)V` 里既有的旧 AAA 段（停在敌境机场的飞机每 tick −1hp）保持不动；留档类的旧入口 `tick(I)`/`tickSafe(I)` 保留但不挂载；雷达/中层雷达仍只探测；UI/渲染/存档/资源全不碰。
- **必须成立**：不写 `isAlive`/`isShotDown`/`isInFlight`；`Game.getProvince` 前判界；列表一律索引循环（`recordLoss` 会改列表）；`tickTurn` 用 `catch Throwable` 兜底；`.registers 4`（`updateAll`）未改。

## 7) 玩家可感知的表现

- **正常**：敌机进入我方反导阵地射程后**逐回合掉血**；命中/击落写进 `aircfg_diag.txt` 的 `nAD` 行；打光最后一架时该任务从空情消失、机场名册同步减少。
- **数值**：每发 −3.0 HP，命中率 50% ⇒ 单回合可能 0 命中（正常）。
- **异常**：`nADX`（内部异常，被兜住不会崩）；`nAD` 每回合出现 2 次（守卫失效 ⇒ 伤害翻倍）；击落后机场名册仍能查到该机。

## 8) 失败与回退

| 情况 | 判定 |

## 9) 验收标准（可证伪）

**通过**：玩 2–3 回合后日志里
1. 出现 `nAD p=… n=… t=… s=… h=… k=…`（≥1 行）；
2. **`nADT` 行数 ≈ 回合数**（不是 2×）——守卫生效；
3. 拿 `nADA`（同回合、同省）对照：`inR>0` 的回合应能看到 `h>0` 或 `k>0`；
4. **无** `nADX`、无闪退；停在机场未出击的飞机 hp 不变。

**不通过**：`nAD` 一直 0 行却有 `inR>0`；或每回合 2 次开火；或出现 `nADX`。
