## 1) 版本号 + 一句话定位
**r6d173** —— ① 给防空诊断 `nADA` 增加"**最近目标距离 `d=`**"与"**900px 宽域计数 `w=`**"两列；② 把 `AirPosProbe` 里 **10 个带对象参数的探针一次性加判空**，根治"平时哑火、新路径触发就崩"的一整类回归。

## 2) 设计目标
- 上一轮抓样满屏 `inR=0`，**无法判断**"周围根本没敌机"还是"敌机只是超出 300px" ⇒ 加 `d=`/`w=` 使"差多远"可读；
- `pap` 崩过一次暴露了探针通病 ⇒ **不再一个一个修**，一次性加固全部探针（用户要求"一次性加完"）。

## 3) 设计规则与判定顺序（若…则…）
```
每回合（AirDefDiag.scanAll，只读）:
  aline（每个有阵地的省）:
     ... 原有 t/c/p/aaa/A/inR ...
     packed = nearX(省, 省主人)          ← 新增
     d = packed % 100000
     w = packed / 100000
     输出 " d=<最近合格敌任务距离px> w=<900px 内合格敌任务数>"

nearX(省, civ):
  对任务池每个任务 m（索引循环）:
     live(m) 假 → 跳过
     m.airDivisionAtProvinceID < 0 → 跳过
     m.civID == 省主人 → 跳过（友军）
     同省 → d² = 0，直接累计
     否则 → 取 m 所在省中心，d² = dx²+dy²（越界/空省 → 跳过）
     若 d² ≤ 900² → w++
     若 d² < 当前最小 → 更新最小
  返回 w*100000 + isq(最小d²)          （isq = 向上取整平方根；无目标 ⇒ 哨兵 -1 ⇒ isq 返回 0）
探针（AirPosProbe）：任意对象参数为 null ⇒ 立即 return-void（不写日志、不崩游戏）
```

## 4) 参数与阈值表
| 名称 | 值 | 含义 |
|---|---|---|
| 开火射程 | **300px**（未变） | 用户确认"300 就够了" |
| 宽域窗口 | 900px（`0xC5C10`） | 仅诊断用：看"差多远" |
| 打包基数 | 100000（`0x186A0`） | `w*100000 + d` |
| 哨兵 | `-1`（v11 初值） | 表示"还没有目标"，避免与"同省 d=0"混淆 |

## 5) 状态与生命周期
诊断侧无状态；`nADA` 每回合每阵地省一行。探针加固只减少"参数为 null 时的日志行"，不改变任何生命周期。

## 6) 边界与不变量
- **对齐**：`nearX` 的合格口径与开火 `AirDefense.eligible` 逐条一致（live + 已部署 + 敌方 + 射程）；
- **不修改**：开火参数与逻辑、`AirForceManager` 注入点、`AirMission`（pap 已摘）、任何游戏字段（诊断只读）；
- **必须成立**：`.registers 14`（aline）下 p0..p3 = v10..v13；`nADA` 旧列全在；探针守卫只加不改。

## 7) 玩家可感知的表现
手感与 r6d172 完全一致（诊断列不影响游戏）。日志里 `nADA` 行形如：
`nADA t=7 c=73 p=6258 aaa=1 A=0 inR=0 d=820 w=1`（⇒ 有敌机但在 820px 外，300px 够不着）

## 8) 失败与回退
| 情况 | 判定 |
|---|---|
| 缺 `d=`/`w=` | 装配/门禁问题 ⇒ 回退 r6d172 |

## 9) 验收标准（可证伪）
1. `nADA` 出现 `d=` 与 `w=`；旧列（t/c/p/aaa/A/inR）齐备；
2. 出现 **`w>0 且 inR=0`** 的行 ⇒ 证明"有敌机但超射程"（本次诊断目的）；
3. `nAD`（开火）行数与 `inR` 的相关性不变；**无 `nADX`、无闪退**。

## 10) 变更清单摘要
- `AirDefDiag.smali`：+`isq(I)I`、+`nearX(Laoc/…/Province;I)I`；`aline` 加 `d=`/`w=` 两列，`.registers 12→14`；**修正 `inR` 敌我极性**（`if-ne`→`if-eq`）。
- `AirPosProbe.smali`：10 个方法共 **15 处**判空守卫（`uaw2/takeoff/adp/pap/fkr/tkr/artD/pcg/aif/posD`）。

- `check_r6d169.py` 的 P4 断言同步更新为"`if-eq` 才是对的"。

## 11) 风险与待办
- 风险：`d` 为 0 同时表示"同省有敌机"或"周围无敌机"，需用 `w` 区分（`w=0` ⇒ 无；`w>0` ⇒ 有）。
- 待办：AD-2（雷达参与开火 + 代际弹数与射程）｜AD-3（统一打击入口 + 建筑耐久）｜可见效果（已确认可后置）。
