## 1) 一句话定位
**r6d174** —— 修掉 AD-1 判定链里的三个极性反写，让"反导阵地只打**射程内的敌方**飞机"这条规则第一次真正成立。

## 2) 设计目标
玩家可见问题：防空阵地"看得见、不工作"。上层意图：让 r6d171 恢复的开火链**打对人、打对距离**。

## 3) 设计规则与判定顺序（修正后）
```
countTargets(civID, 省):
  对任务池每个任务 m:
    eligible(m, civID, 省) 为真 → 计数
eligible(m, civID, 省):
  ① m != null
  ② m.civID != civID            （敌方；== 则跳过）
  ③ m.aliveAircraft != null 且 size > 0
  ④ inRange(m, 省)
inRange(m, 省):
  ① apid = m.airDivisionAtProvinceID ≥ 0（已部署）
  ② apid == 省 id ⇒ 真（同省必中）
  ③ apid < 省份总数、省对象非空
  ④ (dx²+dy²) > 300² ⇒ 假；否则真
```

## 4) 参数与阈值
射程 300px（`0x15f90`）｜命中率 0.5｜伤害 3.0｜每阵地 1 发/回合｜仅反导阵地开火。**本批只改判据，不改任何数值。**

## 5) 状态与生命周期

## 6) 边界与不变量
- **不修改**：`tickTurn/tickAll`、`applyMdDamage` 的记账链（`recordLoss`/`recalcPool`）、诊断类 `AirDefDiag`、`AirForceManager` 注入点；

## 7) 玩家可感知的表现
- 正常：敌机进入某反导阵地 300px 内（含同省）⇒ 每回合被扣血（-3.0/发），50% 命中；打光编队则任务收尾、机场名册同步。
- **变化（相对 r6d171）**：以前是"只打友军、且要超 300px"，现在才是"只打敌机、且必须在 300px 内"。

## 9) 验收标准（可证伪）
1. 出现 `nAD p=… t=… h=…`（开火行）；
2. **同一回合**内 `nADA` 的 `inR>0` ⇒ 应能看到该省的 `nAD` 行（诊断与开火口径一致）；
