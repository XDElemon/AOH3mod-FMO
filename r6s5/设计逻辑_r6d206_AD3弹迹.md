## 1) 版本号 + 一句话定位
本版给防空加**可见性**：把飞机导弹那套“飞行弹迹”机制照抄给防空，让“阵地开火→导弹飞向目标→到达结算”在**地图上看得见**（尾迹黄色、弹头沿用原色）。

## 2) 设计目标（玩家可见的问题 / 上层意图）
- 玩家可见问题：防空开火**完全看不见**（只有数值变化与日志）。
- 上层意图：既然已把“飞行时间”做成真的（r6d203），就要让它在**视觉上成立**；且不要新造美术资产（没有专用贴图），直接复用既有机制。

## 3) 设计规则与判定顺序（若…则…）
绘制侧（`ProvinceDrawArmy.drawAdMissileFx`，每个 mission 每帧调一次，调用点紧随飞机导弹特效）
1. 若 `mission == null` → 返回。
2. 若 `adFxSrc < 0`（没有在途弹）→ 返回。
3. 若 `adFlyHours <= 0`（未在途）→ 返回。
4. 若 `Game.mapScale == null` → 返回。
5. 若该 mission 不在任何省（`airDivisionAtProvinceID < 0`）或省对象为空 → 返回。
6. **【迷雾门】若目标省 `fogDrawArmy == true`（在迷雾里）→ 返回（不画）**。
7. 源坐标 = `getAirDrawPosX/Y(adFxSrc, scale) + 20`；目标坐标 = 该 mission 的 sprite，退化到所在省中心；任一为负 → 返回。
8. 屏幕坐标 → 地图坐标（`÷scale − MapCoords.pos`）后交给 `adFxStep(mission,x1,y1,x2,y2)` 推进。
9. 若 `adFxInit == 1` → `adFxDrawTrail(batch, mission)` 画尾迹（3×3 `Images.pix`，黄色 tint）。

状态侧
- 发射：`AirDefense.fireProvince` 写 `adFxSrc = p1（阵地省 id）` → `scheduleHit` 置 `adFxInit=0`、`adFlyHours=1`。
- 推进：`adFxStep` 第一帧自初始化（沿源→目标按帧差推进），`adFxInit` 变 1 后开始画尾迹。
- 到达：`tickHits` 结算时清 `adFlyHours=0 / adFxInit=0 / adFxSrc=-1` ⇒ 弹迹消失。

## 5) 状态与生命周期
`adFxSrc/adFxInit/adFlyHours` 挂在**被打击的 mission** 上（与飞机导弹的 `msFx*` 完全隔离，互不覆盖）；尾迹坐标缓存 `adFxTX/adFxTY[16]`、容量 `adFxTH`、计数 `adFxTN` 由拷贝体自行维护。

## 6) 边界与不变量
- **不修改**飞机导弹特效（`msFx*` 与方法体原样保留）；帧计时静态字段 `msFxPrevMs/msFxFrameDtMs` 与 `msFxFrameDt()` 为**共用**，故意复用。
- 弹头绘制不在本批方法内 ⇒ “弹头颜色不变”是结构保证，不是约定。
- 迷雾判定用**原版字段** `Province.fogDrawArmy`（= `PlayerFogOfWar.setFogOfWar` 的落点）⇒ 不新造可见性规则。

## 7) 玩家可感知的表现
- 正常：你的防空阵地开火后，地图上出现**一条黄色弹迹**从阵地飞向被攻击的飞机，持续到结算回合；到达后消失。
- 异常：弹迹不出现（查：目标省是否在迷雾里 / 是否真有在途弹 / 是否 adFxSrc<0）；或弹迹乱飞（坐标口径问题）。

## 8) 失败与回退
- 不出弹迹的**正常**原因：目标省处于迷雾（C 口径）；该省无在途弹；mission 无省。
- 回退：`AirMission/AirDefense/ProvinceDrawArmy.smali.pre_r6d206`。

## 9) 验收标准（可证伪）
- 通过：开火后**看得到黄色弹迹**（阵地→飞机），到达回合后消失；弹头仍是原色；不闪退。
- 不通过：完全看不到弹迹（且确认目标不在迷雾、确有在途弹）；或弹迹位置错乱；或闪退。
