## 1. 版本号 + 一句话定位

**r6d255**：把**原版空空导弹（A2A）**从"时间驱动（到点结算）+ 时间插值动画"统一为**纯追踪动画 + 接触驱动伤害**（与 AD 同机制）；并引入**「乙」离屏兜底**与**速度「科技钩子」**（为即将开工的钢四科技系统预留单点）。

## 2. 设计目标

- **玩家可见的问题**：原版空空弹三宗罪——①**半路出现**（首帧按时间比例插值定位）②贴近目标 8px 就"停止绘制"（看得到摸不着）③**伤害与视觉解耦**（没碰到也会命中；碰到了还要等时钟）。
- **上层意图**：所有"打会移动单位"的导弹**统一一个机制**（AD 已验收在前，A2A 跟上）；速度预留科技单点。

## 3. 设计规则与判定顺序（人话）

**发射侧（未改，逐条判定）：**
1. 若已有弹在飞（`strikeKind==1`）→ 不发射；
2. 若任务非 `INTERCEPT` / 状态 ∉ {`EN_ROUTE`,`EXECUTING`} / 不在空中 → 不发射；
3. 弹药惰性初始化（2 发/机）；打完记 `dry`（strikeKind=2）；
4. 冷却 ≥ **4 游戏小时**；
5. 目标 = 敌方任务（相邻省 或 两省中心距 ≤100px；拦截机优先非对地目标）；
6. 发射：扣弹、记 `lastMissileHours`、`strikeKind=1`、记目标 ID、`msFlyHours=4..16h`（**如今仅作兜底时钟**）。

**在飞侧（本批重写）：**
7. **每帧（可见路径）**：首帧置于**载机位置** → 每帧朝目标**当前位置**纯追踪（速度 = `msSpd() ÷ (playSpeedTIME÷HOURS_PER_TURN) × 帧长`，实时读倍率）→ **距离 ≤ 本帧步长即接触**：结算 + 清场 + 消失；
8. **每 tick（业务路径）**：
   - a. 目标失效（不在了/无活机）→ `nMS lost` → 清场（**无伤害**）；
   - b. `now < 到期+12h` → 等待；
   - c. `now ≥ 到期+48h` → **兜底结算**（`nMS fb`）；
   - d. `[12h,48h)`：动画"近 10 秒在步进"→ 继续追；从未/久未步进（离屏）→ 兜底结算（`nMS fb`）。
9. 清场后回空闲；4h 冷却后下一发。

**伤害口径（未改）**：`Σ(射手存活机 airAttack) × 2.0 × 40/(40+目标均防)` → `applyAirDamage`（池倾泻）。

## 5. 状态与生命周期

- `strikeKind`：0 空闲 / 1 在飞 / 2 打空（语义不变）；
- `msFxInit`：0 未初始化 / 1 飞行 / 2 **终态**（新增防御语义：防同帧再绘制）；
- `msFxStepMs`（**新增运行字段**）：最近一次动画步进时间戳（真实毫秒），仅用于"是否在步进"；**不入存档白名单**。
- 生命周期：空闲 → 发射 →（在飞：**接触 / 丢失 / 兜底** 三选一）→ 清场 → 空闲。

## 6. 边界与不变量

- 伤害公式与 `applyAirDamage` 调用**一字不差**；
- 发射/冷却/弹药/目标选择**未动**；
- **AD 一行未动**；存档白名单不含任何弹迹字段（纯运行时），读档 = 未步进（若在飞会按离屏处理，而现状读档本就丢在途）；
- 爆炸半径：**4 类文件**（DexDiff 实核：AirMission / ProvinceDrawArmy / AirDefense / AirDefDiag，5522 类无丢失）。

## 7. 玩家可感知的表现

- **正常**：红蓝小方块**从载机出发**、恒速追着目标飞、**触碰瞬间结算并消失**；切速度档同步快慢；尾迹白色（保持原版）。
- **异常（不通过）**：半路凭空出现 / 追上后停住不动等时钟 / 接触后不消失 / 闪退。

## 8. 失败与回退

- 目标被击落/降落 → **无伤害**（`nMS lost`）；
- 离屏 AI 战场 → 到期+宽限**兜底**（`nMS fb`），保 AI 平衡；
- 菜单暂停 → 不步进（恢复后继续）；
- 灾难（VerifyError 等）→ 回退 **r6d254** 归档。

## 9. 验收标准（可证伪）

**看**：①从载机出发 ②空中恒速追踪、随机动转向 ③触碰即结算即消失。
**探针**：`nMS hit` 与接触同刻；可见战斗**不应**出现 `nMS fb`；`nMS lost` 仅当目标先死；无"卡死"（`strikeKind` 长期=1）。
**回归**：发射节奏（4h）、弹药数、拦截机偏好大体不变。

## 10. 变更清单摘要（规则级）

- A2A 推进：时间插值+冻结 → **纯追踪+接触**；
