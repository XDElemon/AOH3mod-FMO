# 设计逻辑 · r6d319（2026-10-14）· 多发校准（打开后 3 连发收敛）
> 类型：**修 bug（时机补强）**｜依据 r6d318 铁证：`939 nDFR mx=6040`（收敛成功）→ `974 nUSC mx=30258`（被"事后某步"重算大）；点页签=第二次收敛可压住并稳定。

## 1) 版本号 + 定位
r6d319：把"打开后一发收敛"升级为"**3 连发**"（第 3 帧 / 约 0.5s / 约 1.5s 各一发，2s 收兵）——用第二次/第三次收敛压住"事后重算者"，直到与手动点页签等效且稳定。

## 2) 设计目标
- 玩家可见：首次进入（不点页签）→ 右缘贴合内容。
- 过程：允许最初 ~1.5 秒内有一次自动收紧（3 发中的后两发）。

## 3) 设计规则与判定顺序（人话）
- setVisible(true)：sNeedFilter=true，sFilterCd=2。
- scWatch 每帧：cd−1；命中 `cd==0 / -30 / -90` → 执行 `applyTopFilter(sTopCat ?: "all")` 并记 `nDFR mx=`；命中 `cd==-120` → 清除请求。
- 判读（若仍异常）：若三发 nDFR 均为 6040/4540 等小值，而随后 nUSC 变 30258 ⇒ 重算者仍在最后一次之后出手，需按 nUSC 时序继续追。

## 4) 参数与阈值表
| 名称 | 值 | 说明 | 调整影响 |
|---|---|---|---|
| 发次点 | 0 / −30 / −90 | 帧计数（≈60fps：3帧/0.5s/1.5s） | 调密/调远可再压 |
| 收兵点 | −120 | ≈2s | 之后不再自动校准 |

## 5) 状态与生命周期
sNeedFilter/sFilterCd 由每次打开复位；2s 内消费完，长期零开销。

## 6) 边界与不变量
- 与手动点页签完全同方法（applyTopFilter）；仅增加触发次数；
- 不动其它任何逻辑；nUSC 取证保留。

## 7) 玩家可感知
- 正常：打开后瞬间（或 1~2 秒内）右缘收紧一次；此后稳定。

## 8) 失败与回退
- 门禁（inline PASS）+三件套+八件套过（Δ=0）。
- 回退：r6d318。

## 9) 验收标准（可证伪）
1. 全新第一次开树 → **等待 1~2 秒** → 右滑到右极限应贴内容（连续试 2 次开树）；
2. 若 2 秒后仍远：抓 `nDFR`（应有 3 条）与 `nUSC`（时序）→ 定位重算者。

## 10) 变更清单摘要
- Tree：scWatch 校准块改为 3 连发（0/−30/−90），−120 收兵；其余同 r6d318。

## 11) 风险与待办
- 风险：若"重算者"为周期性，可能仍复发；届时按 nUSC 追出根因做根治（而非再加发）。
- 待办：根治/收口清死代码。
