## 1) 版本号 + 一句话定位

**r6t002**：动的是"主菜单渲染层"——主菜单从「原版左侧面板」改为「TNO 三图块（框图+三图+底座+三按钮）」，三按钮沿用原版动作（新游戏/编辑器/退出）。

## 2) 设计目标（玩家可见的问题 → 上层意图）

- 问题：打开游戏主菜单仍是原版界面，TNO 移植没有生效。
- 意图：让 TNO 定制素材真正出现在主菜单上；三图可换、按钮可用；原版其余系统不受影响。

## 3) 设计规则与判定顺序（按先后顺序）

1. **进入主菜单**：`MenuManager` 重建 `new MainMenu()` → 构造器末尾调用 `TnoBlock.populate(menuElements)`：
   - 先 `clear()` 清空旧菜单元素列表（原版 20+ 个按钮/图标/文本自此不再绘制）；
   - 再按索引 0/1/2 加入三枚 `TnoButton`（文案＝语言键 NewGame / Editor / ExitGame）。
2. **每帧绘制**（`MainMenu.draw`）：
   - 先画：淡入遮罩 → 背景图 → 渐变 → 火花（保留原背景体系）；
   - 然后调用 `TnoBlock.draw`（本批新增）：
     ① **框图** `tno_frame` 等比缩放到块宽 W1、水平居中、底边与底座上缘相接；
     ② **三张图** `tno_pic1/2/3` 按锁定窗位（相对框图 1981×793：19/64/619/705、676/64/623/705、1339/64/620/705）等比贴合，直接叠在框上（覆盖示例照片）；
     ③ **底座横条** `tv_button_edge` 铺满块宽、贴屏幕底部；
   - 最后 `goto :tno_skip_panel` → **跳过原左侧面板框/渐变绘制**（原"菜单盒"不再画）；
   - `super.draw` 绘制元素 → 三枚按钮叠加在底座条上（按钮绘制顺序在块之后）。
3. **按钮判定（TnoButton）**：
   - 底色：若 `isActive` 真 → 高亮图；否则若 `isHovered` → 高亮图；否则常态图（两组图＝button_edge / button_h_edge，整片横向拉伸）。
   - 点击：mode=0 → `View.SCENARIOS` + `setOrderOfMenu_Scenarios()`（新游戏流程）；mode=1 → `clearProvinceBorder()` + `View.EDITOR`（编辑器）；mode=2 → `Dialog EXIT_GAME`（退出确认）。
4. **自证**：populate 执行一次写一行 `nTNO2 v=r6t002 block=1` 到 `files/aircfg_diag.txt`（dWrite 免节流）。

## 5) 状态与生命周期

- **实体**：三枚 `TnoButton`（MenuElement）。随主菜单实例创建；菜单重建即重建；无静态状态。
- **TnoBlock**：全静态工具类，无实例、无业务状态（唯一副作用＝一行自证日志）。
- **推进**：构造（populate 建按钮）→ 每帧（draw 画块 + 元素画按钮）→ 点击（actionElement 跳转）→ 回收（菜单替换时随列表丢弃）。

## 6) 边界与不变量（明确对齐/不动的东西）

- **不动**：素材文件（r6t001 入库 7 图）、`InitGame`/`Images`、菜单调度（View/MenuManager/Dialog）、背景图/渐变/火花、屏幕度量体系（全部读 CFG 运行期值）。
- **不再绘制**（本批有意）：原左侧面板的全部元素（继续游戏/战役/载入/设置/社交图标/版本号/制作名单）——它们是"原版开始界面"的一部分，本次被替换掉。如后续要回加部分元素，改 `populate` 即可。
- **不变量**：三按钮文案/动作=原版同款；块内三图坐标=锁定窗位；一切坐标均从 CFG 计算（换机自适应）。
