## 1) 版本号 + 一句话定位

**r6t003**：动的是"按钮渲染层"——三枚 TNO 按钮的背景从「整条 9px 切片横向拉伸」改为「**边缘区按原尺寸绘制（不拉伸）+ 中间纯填充区拉伸 + 右端镜像端头**」的三片式画法。

## 2) 设计目标（玩家可见的问题 → 上层意图）

- 问题：按钮贴图看起来是"素材被粗暴拉伸"的色块（蓝半段+白半段+左侧透明渐入）。
- 意图：按钮呈现为设计过的横条——边缘像素**严格按用户提供的素材原始像素**呈现、只有纯色填充区承受拉伸（拉纯色视觉上等于没拉伸）。

## 3) 设计规则与判定顺序（若…则…）

1. **选素材套**：若 `isActive` 真 → `_h`（点击态）套；否则若 `isHovered` → `_h` 套；否则 → 常态套。（与游戏 Base Button 的 active/hover/normal 判定同序）
2. **绘制（从左到右三片，全部用同一基准 y）**：
   - ① 左缘 `tno_btn_l(_h)`：**原尺寸 6px×36 画在 x**（像素 100% 来自素材，未缩放）；
   - ② 中段 `tno_btn_m(_h)`：**3px×36 横向拉伸到 (按钮宽−12)**（该区是纯浅色填充，拉伸不可见）；
   - ③ 右缘 `tno_btn_r(_h)`：**原尺寸 6px×36 画在 x+宽−6**（= 左缘的逐像素镜像，游戏惯例）。
3. **配色**：绘制前 setColor(WHITE)，绘制后还原 WHITE。
4. 素材分片来源（由你提供的 9×36 两态切片裁切，无改色）：
   - 左缘/右缘 = cols0–5（含1px透明边距+4px蓝光+1px过渡），右缘=左缘镜像；
   - 中段 = cols6–8（纯填充：dce5ec/dbe4ec/dbe4ec；点击态 dbe1e7/dce2e7/dce2e7）。

## 5) 状态与生命周期

- 每帧：`TnoButton.drawButtonBG`（元素绘制链内）→ 选套→算 3 个坐标→画 3 片；无静态状态。
- 素材：6 张切割图（`tno_btn_{l,m,r}`+`_h`）随包常驻；注册于 InitGame.loadImages_1（含自证 `nTNO1 v=r6t003 assets=13`）。
- 旧的整条素材（button_edge/button_h_edge）仍保留在包内与字段中，但**绘制不再使用**（回退方便）。

## 6) 边界与不变量（不动的东西）

- 不动：按钮几何（位置/宽363/高36/三等分）、三种点击动作（新游戏/编辑器/退出）、底座条、三图块、背景体系、菜单调度。
- 不变量：边缘像素不拉伸；拉伸只作用于纯色填充区；所有素材像素来源=用户提供文件（仅裁切）。

## 7) 玩家可感知的表现

- 正常：按钮 = 白色横条 + 两端蓝色光边（原像素）+ 上下深蓝细线；悬停/点击=浅色套（_h）。
- 异常：若某片缺失会显为空缺（注册名/文件缺失）；若边缘仍显"被拉"=放错套（自查素材 md5）。
