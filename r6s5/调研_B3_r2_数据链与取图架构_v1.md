## 1) 资源文件与格式
**1.1 科技树 `game/technologies/Technologies.json`**
- 现状 32 节点（B1B2 后）：ID0=ModernTechFoundation(root,col26,row2,cost250)，其余 1..31。
- 字段：ID / Name / ImageID / TreeColumn / TreeRow / RequiredTech / RequiredTech2 / ResearchCost / Repeatable / AI /（可选 UnlocksAccessToTheSea、BattleWidth、UnitsAttack、UnitsDefense…）。
- 现空军相关节点：1 EarlyFighter(col27)｜4 Fighter(col29)｜30 Bomber(col30)｜24 FutureFighter(col38)。

**1.2 单位 `game/units/*.json`**（Units.json 索引 ID7-10=四型空军）
- 现状：四型各 1 条（UnitLevel0、img66-69、req0=根）。
- 字段：Name / ImageID / UnitLevel / Attack / Defense / MovementSpeed / AttackRange / SiegeProgress / **RequiredTechID（单值 int）** / Cost / MaintenanceCost / RecruitmentTime。

**1.3 图库 `game/units/unitsImages/`**（H/XH/XXH 三档 + numOfImages=134）
- **图号 70…133 = 64 张机型图**；权威映射（r6d126/MANIFEST.txt）：`图号 = 70 + (代-3)*16 + 组*4 + 机型`；组序 中0/欧1/俄2/美3；型序 战0/截1/攻2/轰3。66-69=现通用四型图。

**1.4 本地化** `game/languages/Bundle*.properties`×3：`键 = 值`（如 `AirFighter = Fighter`）。

## 2) 运行时机制（smali 证据）
- 加载：`ArmyManager.loadArmies()` 逐文件解析 → `lArmy[type][record]`；`TechnologyTree` 维护 `lTechnology`、`lTechUnlocksUnits/Buildings/Laws`。
- 注册：`TechnologyTree.buildTechUnlocks_Units()`：单位 `RequiredTechID≥0` → `lTechUnlocksUnits[req].add(Unit(type,record))`。
- 研究后：`Civilization.unlockedUnits`（+`unitsBest`）更新；各处用 `getTechResearched(I)Z` 判定。
- 选档：`Civilization`(~18377)遍历 unlockedUnits 按 **UnitLevel 取最大**（严格大于、保留先出现者）；`ArmyManager.getBestUnitLevel`(~640)按记录索引从高往低找"已研究 req"。
- 可研究闸门：`Civilization.getAvailableToResearch(I)` @8257（唯一、5 调用方）→ B3b 注入点。
- 科技显示名：`TechnologyTree.buildTechnologiesNames()`@520：先本地化原名；**若"解锁单位"非空 → Name := 首个解锁单位的 Name**（法律/建筑同理）。⇒ 模型节点树中显示名＝其首个解锁单位记录名（R3 命名策略项）。
