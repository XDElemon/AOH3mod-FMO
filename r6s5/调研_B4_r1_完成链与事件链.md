# 调研 · B4 R1：研究完成链 + 事件运行链（全量）

> 2026-10-11｜只读勘察。目标：实现"研究完某节点 → 触发一次事件"（M13 完成后效果）。

## 1) 研究完成的唯一收口点
- `Civilization.addResearchProgress(IF)V`（@3611）：若该 tech 在 `lResearching` 中 → 累加进度；
- **`进度 >= getResearchCost(techID, civID)` ⇒ `addTechnology(techID, false)`**（精确锚点：`invoke-virtual {p0, p1, v1}, ...addTechnology(IZ)V` + 后跟 `.line 2079`，全文件唯一）。
- 另一处 `addTechnology(i, true)`（@5709，loadScenario=true）是"重放已研科技"（开局/读档），**不是完成** ⇒ 钩子只挂 addResearchProgress。
- 进度增长统一来自 GameThread（AI/玩家同链）⇒ 一处钩子覆盖全部完成场景。

## 2) 事件系统运行链（原生）
- 驱动器：`GameThread_Events.run()` 每回合 → `EventsManager.runEvents(turnID)`（原生事件扫描，分片）+ `runEvents_Global` + `Player.updateEvents()`（过期处理）。
- 扫描条件：`civ.provinces>0 && (!only_once || !civ变量) && possible_to_run && event.runTriggers(civ)` → 通过后：
 - **玩家**：`player.addActiveEvent(0, 事件索引, 0)` + `rfEvent.format(event,civ)` + SimpleTask（UI 弹窗：`rebuildInGame_Right` + 音效 + `rebuildInGame_Event(event,0,idx)`）；
 - **AI**：按选项 `ai` 权重随机自选 → 执行结果。
- 结算：`EventsManager.takeEventDecision(civID, eventType, eventID, optionID)` → 给该 civ 记事件变量 + `EventOption.executeOutcome(civ)`。
- 玩家点击：`InGame_Event$1.actionElement` → `removeActiveEvent(type,id)` → `takeEventDecision(...)` → 关菜单。
- 过期：`Player.updateEvents()` 到 `EVENT_TIME_TO_RESPOND=274` 回合仍未决策 → `takeEventDecision(...,optionID=0)`。
- **无需触发条件的事件不会自动跑**：扫描前检查 `possible_to_run`，我们的事件设 `false` 即可"只由钩子点火"。

## 3) 结论
- 钩子（完成时）+ 预置事件（手工点火）＝完整可行；点火三件套：`rfEvent.format` + `player.addActiveEvent(0,idx,0)` + SimpleTask 弹窗（镜像 `EventsManager$1`）。
