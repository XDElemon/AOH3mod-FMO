## 1) 事件文件格式（game/events/common/<name>.txt）
样例 `advisors_research_breakthrough.txt` 实录：
```
id=J_abre
title=xxx.t          # 语言键（运行时由 rfEvent.format 解析为正文）
desc=xxx.d
mission_desc=xxx.m
image=44.png         # events/images/H/44.png（已存在，直接复用）
show_in_missions=true
only_once=true
trigger_and / next_and / <条件> / next_and / random_chance=27.5 / trigger_and_end
option_btn / name=<语言键> / ai=10 / bonus_duration=10 / bonus_research_points=5.0 / option_end
```
- **注册**：文件名加入 `game/events/list_common.txt`（分号分隔；追加到末尾即可，索引=列表位置）。
- 可用事件级键：`id/title/desc/image/popUp/only_once/possible_to_run/important/music_file/run_in_background/show_in_missions/super_event`。
- 选项效果键（实测存在）：`bonus_duration` + `bonus_research_points` / `bonus_monthly_legacy` / `bonus_research` / `gold` / `research` 等 60+ bonus_*。
- **文本解析时机**：`rfEvent.format(event,civ)` 把 title/desc/选项名从"语言键"解析成正文（只在真正触发时调用）⇒ 手工点火前必须调用；**且只调一次**（解析后再次调用可能被当成未知键——本批用格式一次标志规避）。
- 触发器结构：`trigger_and|or(_not)` + `next_*` 分隔 + `trigger_*_end`；条件类 235 个，含 `civ_unlocked_technologies_over` 等——**无"某某科技已研究"专用触发器** ⇒ 纯资源做不到"指定节点"，故本批走钩子。

## 2) UI 弹窗链（镜像用）
`EventsManager$1.update()` 三件事 = 本批 Task 类蓝本：
1) `menuManager.rebuildInGame_Right()` + `soundsManager.playSound(EVENT_INFO)`；
2) `event.popUp && !menuManager.getVisibleInGame_Event()` → `menuManager.rebuildInGame_Event(event,0,idx)` + `playSound(EVENT)`。
- 菜单静态字段 `InGame_Event.eventType/eventID` 由 rebuild 写入；点击结算走 `takeEventDecision`。
- `Player.addActiveEvent(type,id,turns)` 有去重（同 type+id 已激活则不重复加）；点击时 `removeActiveEvent` 解锁去重。
