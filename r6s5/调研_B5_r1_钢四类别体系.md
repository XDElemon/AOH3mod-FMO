# 调研 · B5 R1（钢四侧）：folder（顶部类别）与 categories（类别标签）
> 2026-10-12｜只读勘察（本机 v1.19.2 原版文件）。

## 1) 钢四的『顶部类别』= folder（科技树的页/页签）
- 每个科技定义里自带：
```
folder = {
name = air_techs_folder
position = { x = 1 y = 6 }
}
```
- 页签本体在 `interface/countrytechtreeview.gui`：
  - 每页一块 containerType（名字形如 `xxx_folder`），内部逐个科技卡片；
  - `folder_tabs`(y=7) 里是一排按钮：infantry_folder_tab / support_folder_tab / armour_folder_tab / artillery_folder_tab / naval_folder_tab / mtgnavalfolder_tab / mtgnavalsupportfolder_tab / air_techs_folder_tab / bba_air_techs_folder_tab / electronics_folder_tab …；每个按钮 quadTextureSprite = GFX_xxx_tab（图形另有 .gfx 定义）。
- 页名清单（gui 里实际出现的 folder）：infantry / support / armour(+nsb) / artillery / naval(+mtg×2) / air(+bba) / industry / electronics。
- 显示名（本地化 `localisation/english/research_l_english.yml` 等）：
  - infantry_folder: “Infantry”；air_techs_folder: “Air”；electronics_folder: “Engineering”；
  - 另有 xxx_folder_desc（悬浮描述）。

## 2) 钢四的『类别标签』= categories（语义标签，可多个）
- 科技定义里：`categories = { air_equipment  transport_planes_cat }`。
- 标签全集在 `common/technology_tags/00_technology.txt` 的 technology_categories 表：
  - 装备类：light_air / medium_air / heavy_air / armor / cat_light_armor… / artillery / cat_anti_tank / cat_anti_air / naval_air / infantry_weapons / motorized_equipment / naval_equipment / rocketry / nuclear / industry / electronics / air_equipment / support_tech / para_tech / engineers_tech…（80+ 项）
  - 学说/树类：land_doctrine / air_doctrine / naval_doctrine / fleet_in_being_tree / strategic_destruction_tree / computing_tech / radar_tech / encryption_tech…
- 作用：给学说/加成/条件判断做筛选键（不在树 UI 里直接画出来）。

## 3) 对 B5 的启示（供设计）
- 钢四模型可拆两层：**folder（展示页/顶部标签，每个科技恰 1 个）** ＋ **categories（语义标签，可多个）**；
- 我们的 B5 先落『语义标签层』最稳：每节点 1 个主类别（key）＋（可选）子标签；
- 『顶部页签 UI』在 AoH3 里没有原生底座（单页画布），需要自绘——建议列为 B5 的第二段或后续批（由用户拍板）。
