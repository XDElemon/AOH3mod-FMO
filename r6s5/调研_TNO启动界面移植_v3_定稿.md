## §5 验收标准（可证伪）

1. 装机启动不闪退；新增类/字段过三件静态（check_params / regtype / castorder）。
2. 主菜单出现「三图块 + 底座横条 + 三按钮」；三按钮可点击：分别进入 [AoH3 新游戏流程] / 编辑器 / 退出。
3. 图片尺寸/位置符合 TNO 比例（中央块宽＝屏宽/2.2）；无异常拉伸。
4. 原主菜单其余功能不受影响（NewGame/Load/Continue 等仍可用）。
5. 无新崩溃、无资源加载失败（IllegalStateException 类）。
   （二期：加载画面出现进度条/双 logo/提示语。）
