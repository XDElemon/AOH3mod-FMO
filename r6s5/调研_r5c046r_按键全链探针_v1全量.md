## 2. 为什么会"同函数两结果"——现有实现的缺口
q 批的 `pickAirport()` 结构是：**先取列表 ⇒ 列表 null/空 就立刻返回 null**，之后才轮到省反查：

```
if player==null → null     ← 出口1
if AFM==null    → null     ← 出口2
list = getAirportsForCiv(civID)
if list==null   → null     ← 出口3
if size<=0      → null     ← 出口4      ★ 只在这之后才尝试 ②③省反查
① iActiveID… ② selectedAirportProvinceID… ③ Game.iActiveProvince… ④ list[0]
```
⇒ **只要按键那一刻"列表取回来是空/null"，就永远不会走 ②③（省反查根本不依赖列表）** ⇒ 返回 null ⇒ 按钮哑。
⇒ 且 q 批没有"失败原因"探针，无法区分 4 个出口 ⇒ 本批必须补。
