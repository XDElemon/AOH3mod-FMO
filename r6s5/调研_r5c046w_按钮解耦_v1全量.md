## 二、机制（F5 引入的互斥）
```
r5c046t F5 的门（现状）：
  mode == PATROL ? ── 是 ─→ 战时⇒return-void（★不轰炸）／和平⇒继续（巡逻）
                   └─ 否 ─→ 战时⇒继续（轰炸）／和平⇒return-void（不巡逻）
```
⇒ 只要「自动巡逻」显示"开"（`mode=PATROL`），**玩家的轰炸机在战时被门挡死**；而「自动打击」开关（`autoStrikeOff`）此时形同虚设。
⇒ 这正是用户"轰炸机完全不去"的直接原因（他们按过巡逻键，且巡逻键是常开的）。
