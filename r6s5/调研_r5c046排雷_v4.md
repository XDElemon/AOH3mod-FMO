| `if-gtz` | **>0 跳** | — | — |
| `if-lez` | **<=0 跳** | — | — |
| `if-eq` | **相等跳**（对象引用/整数） | `AFM:7062 if-eq p0, v1, :st_ret` | `civID==玩家civ` ⇒ 跳过（玩家不跑智能线） |
| `if-ne` | **不等跳** | `AFM:2958 if-ne v3, v4, :p0_disp` | `civID != 玩家civ` ⇒ 派发（线 L 对 AI 生效） |

## 三、🔴 R1：视野门方向（本轮最重要的雷）

**两条线的实际谓词**（逐字取证，`/tmp/w3a/smali` 与 `20260921` 历史快照**一致**，非新近改坏）：

```
# a1Scan（战略轰炸线）AFM:6380-6411
getFogDrawArmy() -> v13
if-eqz v13, :sc_sel        # fog == false(可见) => 跳去"用旧值"，不写记忆
a1HasMil(pid) -> 6 或 4    # fog == true(不可见) 时才写记忆
:sc_sel
a1Known[pid] & 0x2 ; if-eqz => 跳过   # 必须"记录过有军建"

# a1bPick（攻击机线）AFM:6707-6735
getFogDrawArmy() -> v10
if-eqz v10, :bp_invis      # fog == false(可见) => 走 :bp_invis（不盖时间戳）
（不可见分支才是）a1Gsee[pid] = 当前小时   # 只有 fog == true 才盖戳
... 之后要求戳有效且新鲜(≤6回合)
```
- `getFogDrawArmy()` 语义已双向确认：**true ＝该省当前"玩家看不见"**（我们自己的 `a1bDispatch:6883-6893`
  就是按这个语义把 `a1bBlind` 置 1 的；setter 由 `PlayerFogOfWar` 多处写入）。
- ⇒ **净效果：AI 只打"当前看不见"的省**；一个**看得见的军建省**因记忆字节=0 而被永久跳过
  （`a1Known` 初始为 0，`0 & 0x2 == 0` ⇒ `:sc_in_next`）。
- 这个方向**不是本轮改坏的**（09-21 快照同码），但会**直接压制**你想要的"军事建筑优先/经济人口排序"——
  候选池会缩到"玩家视野外的省"。

**三个可选方向（请拍板）**
| 选项 | 内容 | 影响 |
|---|---|---|
| **A. 保持现状** | 只能打不可见省（记忆驱动） | 尊重现有设计；但"军建省"未必在池内，AI 出击可能很稀 |
| **B.（建议）改成"可见即刷新"** | 把 `a1Scan` 的 `if-eqz` 改 `if-nez`（`a1bPick` 的盖戳分支同向调整）⇒ 可见省也能进候选池，fog 只影响"是否用旧情报" | 改动各 1 条指令；候选池覆盖航程内全部已知敌省；`nP2mil` 才有机会真的出现 |
| **C. 彻底去掉视野门** | 把 fog 判据从"候选资格"降级为"仅记忆新鲜度"（不可见省不刷新但不清空） | 最激进，AI 最"全知"，但你可能不想（涉及"AI 作弊感"） |

> 注：`a1bScan`／`a1bPick` 侧不受 `a1Scan` 数组问题影响，但同样受"只能在不可见省盖戳"的限制。

## 六、验收与门禁（排雷版）
1. **写码前**：每条新增/修改的分支，先在报告里写出"真值表"（输入→应跳/不应跳）。
2. **汇编后**：arity → 八件套 → ㉔ → **㉘（新增 invoke 必核目标类声明，先跑负样本）**。
3. **装机后**：启动自检（crash=0）→ 抓样看 5 个探针：
   `nP2dif`（档位）/`nP2frq`（每回合新增数）/`nP2cap`（K 拦）/`nP2mil`（军建档命中，历史恒 0）/`nP2s`（候选与选中档）。
4. **可证伪硬指标**：
   - `nP2mil` 出现 `mil=1`；
   - `nP2frq` 在传奇难度的新增数 **>** 非常简单难度；
   - 玩家手动点省出击照常；AI 和平期巡逻不归零；
   - 无闪退。
