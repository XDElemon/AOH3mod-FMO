# 调研 · r6d022（第三方/盟友的导弹·机炮·轰炸动画可见）

> 需求（用户口径）：**只要在雷达圈内（＝玩家能看到、迷雾外），不管是谁打谁，动画都要看得见**。
> 现状：作为玩家、且对方**与玩家交战**时能看到；**盟友与第三方互殴看不到**。

## 第一轮：全量调研（这些动画是怎么被画出来的）
1. **动画本体**（都在 `aoc/kingdoms/lukasz/map/province/ProvinceDrawArmy.smali`）：
   - `drawAirGunFx(SpriteBatch, AirMission)` @2989 —— **机炮动画**；内部还按 `MissionType.STRATEGIC_BOMBING`（@3004）分支 ⇒ **轰炸动画也在这**。
   - `drawAirMissileFx(SpriteBatch, AirMission)` @3251 —— **导弹动画**（尾迹 `msFxDrawTrail` @8690、步进 `msFxStep` @8837、轨迹点 `msFxTrailAdd` @9088）。
   - 特效状态**挂在任务对象上**（`AirMission.msFxX/Y/VX/VY/TX/TY/TH/TN/tgtAt/Init/Spd` 等 @107-131）⇒ 任何文明的任务都能持有特效状态（玩家能看到敌方导弹即为证）。
2. **绘制入口（唯一）**：`ProvinceDrawArmy` 某绘制函数 @2102-2104：
   ```
   for mission in AFM.activeMissions:
        if (myOrDetectedMission(mission))      ← 唯一的可见性闸
              drawAirGunFx(batch, mission)     ← 机炮 + 轰炸
              drawAirMissileFx(batch, mission) ← 导弹
   ```
   另有一处 @3809 也用 `myOrDetectedMission`；@2310 用 `isMyMission` 只画一条 `drawLinePts`（我方专属线段，**不属于本次需求**）。
3. **可见性闸 `myOrDetectedMission(mission)` @9244**：
   ```
   若 isMyMission(mission)                        → 可见（我的）
   或 airDetSeen 包含 mission.missionID           → 可见（被"探测"到的）
   或 mission.targetProvinceID 属于玩家           → 可见（打到我头上）
   否则不可见
   ```
4. **`airDetSeen` 谁写入**：`PlayerFogOfWar.detectEnemyMissions()`（每 500ms 一次，AA_Game→每帧调用）。

## 第二轮：拓展调研（为什么盟友/第三方看不见）
`detectEnemyMissions()` 的判定链（读全 459 行）：
```
遍历 AFM.activeMissions：
  ① aliveAircraft 非空
  ② mission.civID != player.iCivID           （自己的任务跳过：本来就会画）
  ③ ★ isAtWar(mission.civID, player.iCivID) 必须为真，否则【整条任务丢弃】   ← 元凶
  ④ state ∈ {EN_ROUTE, EXECUTING}
  ⑤ 位置有效（curAirRealX/Y ≥ 0）
  ⑥ 覆盖判定（二选一命中即算"看得见"）：
        (a) 雷达省：radarProvinces 里【属于玩家】的省 → 取该省雷达半径（长波 0x960=2400 / 雷达 0x258=600 / 默认 0x12c=300）÷ mapScale → calcInEllipse 椭圆内
        (b) 玩家机场圈：allAirports 里【属于玩家】的机场 → 距离² ≤ radarRange²
  :goto_16c
       airDetSeen.add(mission.missionID)         ← 视觉依赖
       AirForceManager.dispatchAutoIntercept(mission)   ← ★玩法动作（玩家拦截机起飞）
```
⇒ 第③条把**盟友/中立/第三方**的任务在探测阶段就丢了 ⇒ 永远不进 `airDetSeen` ⇒ 永远不画。
⇒ 但第⑥条（雷达圈/机场圈）本身**与阵营无关**，只是"玩家看不看得见"⇒ 放宽第③条即得需求效果。

**红线（不可越界）**：
- `dispatchAutoIntercept` 是**玩法**：放宽后若不收窄，玩家的自动拦截会去追盟友/第三方的飞机（连带的 chaser 记录、`hasActiveChaser`、任务逻辑都会变味）⇒ **必须给它单独加"与玩家交战"守卫**。
- 不改：`isMyMission` 那处线段绘制、AI 的出击/拦截逻辑、玩家链、AI 造机、探针闸（保持静默）。
