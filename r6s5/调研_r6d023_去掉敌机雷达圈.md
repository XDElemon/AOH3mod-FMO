# 调研 · r6d023（去掉"敌军飞机身上那个雷达圈"）

> 用户口径：动画要保留（r6d022 已实现），但**敌军飞机不要再显示那个雷达圈**。

## 第一轮：全量调研（那个圈是谁画的）
- `ProvinceDrawArmy.drawAircraftRadar(SpriteBatch)` @3771：
  - 遍历 `AFM.activeMissions`，可见性闸 = `myOrDetectedMission(mission)` @3809（**与动画共用同一闸**）
  - 取出任务的 `sourceAirport.provinceID / targetProvinceID / airDivisionAtProvinceID`，算出飞机当前所在省的绘制坐标
  - 画该省的**雷达覆盖填充**：`calcRadarRy(Province,I)` + `Images.radarFill` + `Image.draw(batch,x,y,w,h)` @172-202
  ⇒ 这就是"飞机身上那个圈"。
- **动画**（导弹/机炮/轰炸）在**另一个方法**的循环里 @2102-2104（`drawAirGunFx` + `drawAirMissileFx`），同样用 `myOrDetectedMission` 闸，但**是独立的调用点**。
- ⇒ **两处可以分开处理**：动画保留"我的 ∪ 已探测"，圈只保留"我的"。

## 第二轮：拓展调研（为什么现在才冒出来）
- r6d022 之前：只有"与玩家交战"的任务会进 `airDetSeen` ⇒ 圈只在敌机身上偶尔出现（玩家没太注意）。
- r6d022 之后：任何在雷达/机场圈内的任务都进 `airDetSeen` ⇒ 圈大面积出现在**非我方飞机**身上。
- 影响面：`drawAircraftRadar` 只画视觉，**不参与任何玩法** ⇒ 改成 `isMyMission` 无玩法副作用。
- 不变量：动画链路（@2102）**不得**一起被改掉，否则回到"看不到敌机动画"。
- 寄存器/结构：本次只替换一条 `invoke-static` 的**目标方法名**（同签名 `(AirMission)Z`），寄存器与调用约定完全不变 ⇒ 零结构风险。

## 第三轮：定稿（可施工）
### ① 唯一锚点（逐字，含 `:cond_14` 与 `sourceAirport` 上下文）
```
    invoke-static {v2}, Laoc/kingdoms/lukasz/map/province/ProvinceDrawArmy;->myOrDetectedMission(Laoc/kingdoms/lukasz/map/battles/AirMission;)Z

    move-result v1

    if-eqz v1, :cond_14

    iget-object v3, v2, Laoc/kingdoms/lukasz/map/battles/AirMission;->sourceAirport:Laoc/kingdoms/lukasz/map/battles/Airport;
```
命中数必须 = 1（动画那处是 `if-eqz v2, :cond_c` + `drawAirGunFx`，上下文不同 ⇒ 不会误伤）。

### ② 真值表 / 极性
| 判定 | 语义 | 写反会怎样 |
|---|---|---|
| `myOrDetectedMission` → **`isMyMission`** | 圈只画我方飞机；敌机/盟友/第三方不画圈 | 保持 `myOrDetectedMission` ⇒ 圈依旧挂在敌机上（症状不消失） |
| 动画处（@2102）保持 `myOrDetectedMission` | 敌机动画仍可见 | 若一起改成 `isMyMission` ⇒ **回到"看不见敌机动画"**（用户已验收的功能被破坏） |

### ③ 寄存器分配表
| 位置 | 方法 `.registers` | 本次借用 | 说明 |
|---|---|---|---|
| `drawAircraftRadar` | 17 | 无 | 只改调用目标名，寄存器分配不变 |

### ④ 失败模式与回退
- 锚点命中数 ≠1 ⇒ 中止不改（避免误伤动画那处）。
- 回滚：`cp ProvinceDrawArmy.smali.pre_r6d023 ProvinceDrawArmy.smali` 重汇编重建。

### ⑤ 验收标准（可证伪）
- 门禁 **81** 全过（含 3 负样本）。
- 实战：我的飞机 ⇒ **仍有**雷达圈；敌机/盟友/第三方 ⇒ **没有**圈，但**动画照旧可见**。

### ⑥ 门禁与负样本
- 81-1 `drawAircraftRadar` 内的闸必须是 `isMyMission`
- 81-2 动画调用点（`drawAirGunFx`/`drawAirMissileFx`）的闸必须仍是 `myOrDetectedMission`
- 81-3 `radarFill` 绘制链仍在（我方保留圈）
- 负样本：①把 81-1 改回 ⇒ 红；②把动画闸改成 `isMyMission` ⇒ 红；③删掉 `radarFill` ⇒ 红。
