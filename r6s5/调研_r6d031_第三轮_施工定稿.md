# 调研 · r6d031 第三轮（全量拓展调研·**施工定稿**）

> 前三轮汇总后的可施工版本。**只有读完本轮才能开工**（铁律）。所有锚点必须在施工脚本里 `assert count == 1`（实测命中次数）。

## 1. 本批目标（一句话）

在 **`RealTimeSim.updateFrame()`** 上装 3 个**零参数探针**，回答三问：**本帧处理了几条 / 在哪一条断掉 / 断在什么异常**。

## 2. 探针定稿（全部放在 `AirDbgLog`，独立成方法·只读·免节流）

| 方法 | 签名 | 行为 | 寄存器分配 | 类型纪律 |
|---|---|---|---|---|
| `rtTick()` | `()V` | `rtN++`；**不做任何 I/O** | `.registers 2`：v0=int 抄 static | 全 int |
| `rtFrame()` | `()V` | 每 ≥1s 一次：`dWrite("RTF n=<rtN>")`，随后 `rtN=0` | `.registers 6`：v0=StringBuilder，v2=int(rtN)，v3=String 常量 | **String 走 v3，int 走 v2**，`append(I)` 传 v2 |
| `rtCatch(Throwable)` | `(Ljava/lang/Throwable;)V` | `dWrite("RTCATCH n=<rtN> ex=<toString>")`，随后 `rtN=0` | `.registers 8`：v0=StringBuilder，v1=Throwable，v2=int(rtN)，v3=String | `invoke-virtual {v1}, Ljava/lang/Object;->toString()` → `move-result-object v3`（**v3 才是 String**） |

新增静态字段：`rtN:I`（计数）、`rtLastMs:J`（节流）。

## 4. 真值表（判读 · 决定下一步方向）

| 观察 | 判定 | 下一批动作 |
|---|---|---|
| `RTF n ≈ 任务总数` | 本帧全处理完 ⇒ **不是中断** | 转向"上限/节流"或"移动步进本身卡住" |
| `RTF n < 总数` **且出现 `RTCATCH`** | **异常中断 → 饿死**（主嫌疑 H-A） | 修法：给 A 链加**逐条 try/catch**（单条异常不影响其它）＋修 `dedupAirhqDivision` 抛点 |
| `RTF n < 总数` **且无 `RTCATCH`** | 遍历提前结束（列表为空/状态门）⇒ **上限或分派问题** | 查上限常量与 `EN_ROUTE/RETURNING` 门 |
| 有 `RTCATCH` 但 `n` 很大 | 末尾偶发异常 | 低优先，记入待办 |

## 5. 门禁 91（≥4 断言 + 3 负样本）

- **91-1**：`rtTick` 存在且体内**无** `dWrite/dKey/File*`（纯计数）。
- **91-2**：`rtFrame/rtCatch` 走 `dWrite`（**不是** `dKey`，避免 500ms 节流吞行）。
- **91-3**：类型纪律 —— `rtCatch` 内 String 追加恒走 `v3`、`append(I)` 恒走 `v2`；`append(Ljava/lang/String;)` **不得**引用 v1/v2/v4。
- **91-4**：三个锚点各命中 **1** 次；`rtTick` 在 `dedupAirhqDivision` **之前**、`rtCatch` 在 `:catch_5e` **之内**、`rtFrame` 在 `:cond_59` **之前**；`RealTimeSim` 原有指令**未变**（插入前后 diff 只增 3 行 invoke）。
- **负样本**：①`rtCatch` 用 v1 做 String 追加 ⇒ 91-3 红；②把 `rtTick` 移到循环外 ⇒ 91-4 红；③`rtFrame` 改走 `dKey` ⇒ 91-2 红。

## 6. 失败模式与回滚

- 回滚点：`RealTimeSim.smali.pre_r6d031`、`AirDbgLog.smali.pre_r6d031`。
