# 调研 · r6d036（三轮合并·施工定稿）｜修「永不换省」+「菜单越界闪退」

> 违规说明：额度受限，三轮合并为一份（下轮补拆分）。已读指南 v1；锚点均 `assert count==1`。

## 1. 第一轮（全量）
- `AirMission.updateAnimClock()`（6965）：`dt = now - animPrevMs`（钳到 ≤10s，否则取16）→ 写回 `animPrevMs` → **若 `gameThread.play` 且 `menuManager != null` 且 `getVisibleInGame_Escape()==true` 则 return**（菜单可见不推进）→ 否则 `animElapsedMs += dt`。
- `MenuManager.getVisibleInGame_Escape()`：内部 `getActiveMenu().get(getActiveOrder(activeSliderMenuID))` —— 当活动菜单序列为空/映射为 -1 时 **`Index -1 out of bounds for length 1`**。
- `AirMission.moveDivisionAlongFlight()`：`airDivSegAnimMs += 0x10`；换省门 `if-lez v12(airDivSegDurMs), :cond_128`（**dur<=0 ⇒ 永不换省**）；`airDivSegDurMs` 只在方法尾部某分支重算。

## 2. 第二轮（拓展·实测证据）
- r6d035 抓样：**28094/28094 条 MV 行都是 `dur=0`**，且 `anim` 正常增长（16→432/816/1056…）⇒ **换省门恒不成立**，这是"飞机停省不动"的直接真因。
- 同批崩溃栈（10:36 那局）：`MenuManager.getVisibleInGame_Escape(3442)` → `AirMission.updateAnimClock` → `AirMission.update` → **`AFM.updateMissions`（无 catch）** ⇒ 整局崩；若走 `RealTimeSim`（有 catch）则被吞+中断循环 ⇒ 后面的任务饿死。
- ⇒ 「停住」与「闪退」同源：**段时长算不出来（=0）**，一路是"不换省"，一路是"越界崩"。

## 3. 第三轮（定稿）

**A. 闪退止血**：新增 `AirMission.safeEscapeMenu()Z`（private static，独立方法 + try/catch，失败返回 false），并把 `updateAnimClock` 内的 `menuManager.getVisibleInGame_Escape()` 直调换成它。
- 语义不变（菜单可见仍返回 true ⇒ 不推进）；异常时退化为 false（继续推进）⇒ 不再崩、也不再卡时钟。

**B. 换省门兜底**：在 `moveDivisionAlongFlight()` 的 `if-lez v12, :cond_128` **之前**插入：

```
if-gtz v12, :ssd_ok          # dur > 0 ⇒ 原样继续
const/16 v12, 0x3e8          # dur <= 0 ⇒ 兜底 1000ms
iput v12, p0, AirMission->airDivSegDurMs:I
:ssd_ok
```

⇒ `dur=0` 时不再"永不换省"，改为"每约 1 秒换一省"（可逆、可回滚；后续再按公式精修）。

**C. 门禁 96（含模拟器）**
- **96-1**：`safeEscapeMenu` 存在、含 `.catch Ljava/lang/Exception;`、catch 分支返回 false。
- **96-2**：`updateAnimClock` **不再**直调 `getVisibleInGame_Escape`，改调 `safeEscapeMenu`。
- **96-3**：兜底块存在且**极性正确**（`if-gtz` 跳过修复；`const/16 v12, 0x3e8`；标签 `:ssd_ok` 唯一），原 `if-lez v12, :cond_128` **未被破坏**。
- **96A 模拟器**：`dur_fix(anim,dur)` → ①`dur=0 ⇒ 1000`、②`dur=5000 ⇒ 不变`；`hop(anim,newDur)` → ③`anim=1000,dur=1000 ⇒ 换省`、④`anim=200,dur=1000 ⇒ 不换`。
- 负样本：①删 `.catch` ⇒ 96-1 红；②`if-gtz`→`if-lt` ⇒ 96-3 红；③把 `safeEscapeMenu` 换回直调 ⇒ 96-2 红。
