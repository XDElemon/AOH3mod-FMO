# 调研 · r6d046 第一轮（全量）：招募面板「行」是怎么生成的

> 目标：让「陆军部队」面板里不再出现飞机行（B-2，显示层）。
> 前提：r6d045 已交付「B 拦截」（`Civilization.recruitArmy` 入口闸，玩家/AI 点了也招不出）—— 用户已验收。

## 1. 链路（入口→出口）

## 2. 关键实体
| 实体 | 事实 |
|---|---|
| 行按钮类 | `Laoc/kingdoms/lukasz/menu_element/button/ButtonUnit3_3`（`.super MenuElement`） |
| 行按钮持有的兵种 id | `public unitTypeID:I` —— 构造器第 **147 行** `iput p1, p0, ...->unitTypeID:I` 写入 |
| 行按钮的绘制入口 | `public final draw(Lcom/badlogic/gdx/graphics/g2d/SpriteBatch;IIZZ)V`（第 2212 行） |

## 3. 第一轮结论
- 「行是否出现」= 该 `ButtonUnit3_3` 实例**是否被绘制**；
- 航空行与普通行的**唯一区别**就是 `unitTypeID`（7/8/9/10 现已由 `isAirUnitID` 前缀判定覆盖，未来 `AirXxx_T3` 自动生效）；
- ⇒ **最低风险切入口 = `ButtonUnit3_3.draw()` 首行早退**（单点、不跨分支、不动任何循环）。
