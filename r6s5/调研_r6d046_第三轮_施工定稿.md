## 3. 真值表与极性
| 条件 | `isAirUnitButton` | `draw()` 行为 |
|---|---|---|
| `unitTypeID` = 7/8/9/10（`AirInterceptor/Fighter/Bomber/Attacker`） | true | **`return-void`（不绘制）** |
| 未来新飞机 `AirFighter_T3` 等（File 前缀 `Air`） | true | 同上（自动覆盖，规则化） |

## 4. 门禁 106（≥4 断言 + 3 负样本 + 未来机型模拟器）
1. `AirDbgLog` 含 `isAirUnitButton(Laoc/kingdoms/lukasz/menu_element/button/ButtonUnit3_3;)Z` 且 `.registers 2`；
2. `ButtonUnit3_3.draw` 为 `.registers 7`，且 `draw` 内出现上述 `invoke-static`；
3. **紧邻性**：`invoke-static` 的下一行（忽略空行）必须是 `move-result v0`（r6d039 血案专查）；
4. 顺序完整：`if-eqz v0, :b2_ok` → `return-void` → `:b2_ok`；
5. 负样本：① 去掉 `move-result v0` ⇒ 断言3 必红；② `.registers` 回退 6 ⇒ 断言2 必红；③ helper 签名类型写错 ⇒ 断言1 必红；
6. 模拟器：对 `AirInterceptor, AirFighter, AirBomber, AirAttacker, AirFighter_T3, AirXxx, Warior, Canon` 模拟前缀判定，期望 `true×6 / false×2`。
