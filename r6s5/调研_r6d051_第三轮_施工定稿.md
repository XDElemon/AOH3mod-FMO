### C. `AirMission` 新增 `tickInvars()V`（同类的**新方法**，因此可调 private）
```

   · state != PLANNING              ⇒ ABORTED + returnAirDivisionHome() + ivLog(1)
   · state == PLANNING 且 (assignedAircraft 空 / size==0) ⇒ 同上
   · state == PLANNING 且 还有飞机   ⇒ 不干预（等它自己起飞）

   ⇒ state=COMPLETED + returnAirDivisionHome() + returnToBase() + ivLog(3)
```
