## 1. 编辑点（3 处）

### A. `AirDbgLog` 新增 `ivLog(I)V` + 字段 `ivN:I`
节流语义：`ivN < 60` ⇒ 记录；否则返回。（`if-ge v0, v1, :iv_out` = 超限即跳出）

### B. `AirMission` 新增 `tickInvars()V`（同类新方法，可调 private）
```
R1 若 airhqDivision == null:
     · st == PLANNING(0) 且 (assignedAircraft==null 或 size==0) ⇒ ABORTED + returnAirDivisionHome() + ivLog(1)
     · st != PLANNING                                        ⇒ 同上
     · st == PLANNING 且 还有飞机                              ⇒ 不干预（等它自己起飞）
R2 若 st == EN_ROUTE(1) 且 targetProvinceID>=0 且 airhqDivision!=null 且 at == targetProvinceID
     ⇒ placeAirDivision(target) + st = EXECUTING + ivLog(2)
R3 若 st == RETURNING(3) 且 sourceAirport!=null 且 at == sourceAirport.provinceID
     ⇒ st = COMPLETED + returnAirDivisionHome() + returnToBase() + ivLog(3)
```

### C. `AirMission.update()` 入口：在 r6d050 探针调用**之后**插 `invoke-virtual {p0}, ...tickInvars()V`
（入口两条调用都不带 `move-result`；探针先记原始状态，再让不变量修正。）
