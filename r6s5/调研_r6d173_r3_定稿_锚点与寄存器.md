## 2. 真值表（本批新增判定）

### 2.1 `nearX` 的作用域（哪些任务算"合格"）——与开火口径逐条一致
| 条件 | 判定 |
|---|---|
| `live(任务)` 为假（无编队/编队空） | **不算** |
| `airDivisionAtProvinceID < 0`（未部署） | **不算** |
| `任务.civID == 省主人`（友军/自己） | **不算** |
| `airDivisionAtProvinceID >= iProvincesSize` | **不算**（防越界） |
| `Game.getProvince(apid) == null` | **不算** |
| `apid == 本省 id` | 距离 = **0** |
| 否则 | 距离 = `ceil(sqrt(dx²+dy²))` |

### 2.2 打包与解包
| 量 | 计算 | 说明 |
|---|---|---|
| 宽域计数 `w` | `d² ≤ 900² (0xC5C10)` 时 +1 | 900px 窗口 |
| 最近距离 `d` | `min(d²)` ⇒ `isq(min_d²)` | `isq(n)` = 最小 i 使 `i*i >= n`（`n=0 ⇒ 0`） |
| 打包 | `packed = w * 100000 + d`（`0x186A0`） | `d` 上限 99999 足够（本图省中心距 < 2000px） |
| 解包 | `d = packed % 100000`；`w = packed / 100000` | 用 `rem-int` / `div-int` |

### 2.3 关键极性（必须写对）
| 意图 | 写法 |
|---|---|
| 第一次命中目标（`best` 尚未设置） | `if-nez v11, :setb`（v11==0 ⇒ 跳到赋值） |
| 更近才替换 | `if-le v12, v11, :next`（新的 ≥ 当前 ⇒ 跳过） |
| 宽域计数：超出 900² 才不数 | `if-gt v12, v13, :nw` |
| 同省 ⇒ 距离 0 | `if-eq v8, v4, :same0`（**相等才跳**） |
| 敌方判定 | `if-ne v12, v5, :next`（!= 省主人 ⇒ 继续） |
| 探针守卫 | `if-nez pK, :g173_…` + `return-void` + `:g173_…`（参数为 null ⇒ 直接返回） |

## 4. 门禁（`check_r6d173.py`）＋负样本

**结构/语义断言**
- S1：`AirDefDiag.smali` 中 `isq`/`nearX` 各 **1** 个定义；`nearX` 内含 `const/4 v10, 0x0`（w 初值）与 `const/4 v11, 0x0`（best 初值）。
- S2：`aline` 内出现 `"d"` 与 `"w"` 两个 kv（`const-string v7, "d"` / `"w"` 各 ≥1），且 `div-int`/`rem-int` 均存在（打包解包齐备）。
- S3：`aline` 的 `.registers` = **14**，且 `if-lt v0, v1, :cond_write` 仍在（上限判据未被带坏，r6d170 语义）。
- S4：`AirPosProbe` 中 **10 个**目标方法各自含对应参数的守卫（逐条：`uaw2`/`takeoff`/`adp`/`pap`/`fkr`/`tkr`/`artD`/`pcg`/`aif`/`posD`）。
- S5：`safeUpd` 原有守卫仍在（`if-nez p0, :end`）。
- S6：`AirDefDiag`、`AirPosProbe` 均**不含** `dKey`、`java/nio/file`；`AirDefDiag` 无对游戏字段的 `iput/sput`。
- S7：`AirMission` 里 `pap` 调用仍为 **0**（r6d172 不能被带坏）；`AirForceManager` 里 `tickTurn`/`scanAll` 各 **1**。

**极性断言**：见 §2.3 逐条（`if-nez`/`if-le`/`if-gt`/`if-eq`/`if-ne` 全部成对）。

**负样本（必须变红）**：N1 删 `"d"` 列；N2 把 `if-le v12, v11, :next` 反转成 `if-ge`（距离取最远）；N3 把守卫 `if-nez pK` 反转成 `if-eqz pK`；N4 删 `fkr` 的守卫；N5 把 `if-eq v8, v4, :same0` 反转（同省不再算 0）。

**行为级模拟器**：`sim_near.py` —— **解释执行真实 smali 的 `nearX` 控制流**（对 `Game/AirForceManager/List/AirMission/Province/live/isq` 用假值表打桩），断言：
给定"省中心(100,100)+ 3 个敌任务(相距 0/500/1500px)" ⇒ `d=0`、`w=2`；给定"无敌任务" ⇒ `d=0`、`w=0`；并把 `if-le` 反转后必须失败。
