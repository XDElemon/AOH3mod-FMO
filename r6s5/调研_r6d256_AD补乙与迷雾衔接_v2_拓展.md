## §1 出入迷雾衔接（本批核心设计要求，用户 2026-10-08 补充）

### 1.1 定义
- **可见** ＝ `myOrDetectedMission(target)==true`（己方 / 曾侦测 / 打我方省）⇒ `adFxStep` 每帧步进，`adFxStepMs` 刷新。
- **迷雾内** ＝ 上述为假 ⇒ `drawAdMissileFx`/`adFxStep` 不被调用 ⇒ `adFxStepMs` 停更（冻结）。
- 注意：绘制**无视口裁剪**——屏幕外但可见的弹迹照常步进；兜底只对"迷雾内"生效。

### 1.2 入迷雾（有动画 → 无动画）
| 项 | 行为 |
|---|---|
| 画面 | 弹迹（尾迹+弹头）**整条消失**（下一帧不再绘制；无残留、无半截） |
| 状态 | `adFxX/Y`、`adFxTN/TH/TX/TY`、`adFxInit`、`adFxTgtX/Y` **全部冻结保留** |
| 计时 | `adFxStepMs` 停更（这就是"进雾"的指纹） |
| 接管 | `tickHits`（每回合）按 §1.4 时间轴接手 |

### 1.3 出迷雾（无动画 → 有动画）——四种子场景
| # | 前置 | 出雾后行为 | 依据 |
|---|---|---|---|
| A | 曾步进（`adFxInit==1`），未到期/宽限内 | **从冻结位置继续纯追踪**（不重首帧、不清尾迹）→ 到达接触结算 | `adFxStep` 首帧块只在 `adFxInit==0` 触发 |
| B | 曾步进，due 已过但"近 10 秒有步进"（刚恢复绘制） | **不被兜底抢**——继续追、接触结算 | 判定链 (e)：delta<10s → 等 |
| C | 从未步进（发射后一直迷雾） | 首帧从**发射阵地源点**开始（`adFxInit==0` → 置源点+清尾迹）→ 追 | `adFxStep` 首帧块；符合"从阵地出发"视觉语义 |
| D | 已被兜底结算（`adFxSrc==-1`） | **无弹迹**（伤害已落地，不出现"幽灵弹"） | 绘制守卫 `adFxSrc>=0` |

### 1.4 时间轴（每发在途弹的兜底裁决，与 A2A 同构）
```
now < adHitAt            → 等（未到期）
adHitAt ≤ now < +12h     → 等（宽限：给"再出迷雾"的机会）
[+12h, +48h) ：
   从未步进(adFxStepMs≤0) → 兜底结算
   delta ≥ 10s（久未步进）→ 兜底结算
   delta < 10s（近10s在步进=其实可见）→ 等接触   ★"出雾在追"不被抢
now ≥ +48h               → 兜底结算（硬上限，防卡死；即使正在步进）
```
- 兜底结算＝复用原版口径：`applyMdDamage(adHitDmg)` + 清场 + `nADK fb=1` 日志。
- "最近 10 秒"用**墙钟**（currentTimeMillis）；到期用**游戏小时**（`adHitAt`）。两者混用是设计（照抄 A2A）。

### 1.5 衔接的视觉自证路径（不新增探针）
- 入雾：弹迹消失 ← 现有绘制路径（`myOrDetectedMission` 闸）保证；
- 出雾恢复：现有 tag=90 探针（入口活跃首帧：`adFxSrc>=0 && adFxTN==0`）会在"窗口首次绘制"打点——场景 A 不触发（TN 非0）、场景 C 触发；
- 兜底：新 `nADK fb=1` 行。

## §2 边界场景穷举（+ 期望行为）

| # | 场景 | 期望行为 | 备注 |
|---|---|---|---|
| B1 | 目标任务从 activeMissions 移除 | 伤害随任务消亡（无独立日志） | 与 A2A 的 `nMS lost` 不同——AD 无任务移除钩子，本批不加（挂账）；不放"幽灵伤害" |
| B2 | 目标活机全灭但任务仍在 | `applyMdDamage` 循环空转 → k=0，安全清场 | 不做特判 |
| B3 | 读档 | 弹迹/在途伤害丢失（白名单不含）| 存量特性，不回归 |
| B4 | 暂停/Esc 菜单 | 双方停摆（`adFxStep` 守卫 + 回合线程停） | 无竞争窗口 |
| B5 | 同回合内"接触先于 tickHits" | `adHitDmg=0` → tickHits 跳过 | 防双结算第一闸 |
| B6 | 多弹叠加（同目标多次命中） | `adHitDmg` 合并，一次结算 | 沿用 scheduleHit"保留最早" |
| B7 | 时钟回拨/异常（delta<0） | 视为"近期步进"→等；巨 delta（stepMs=0）→兜底 | long 运算无溢出（千年尺度） |
| B8 | `adHitDmg>0` 但 `adHitAt==0`（异常态） | 被判定为"早已到期"→ 按链兜底（自愈） | 正常运行不会出现 |
| B9 | 弹迹在"差一点接触"时入雾 | 冻结位置；出雾从冻结点继续→接触 | 场景 A |
| B10 | 目标先飞出迷雾再入雾（反复横跳） | 每次出雾→步进刷新时间戳→持续"等"；最终入雾超时才兜底 | 10s 阈值抗抖动 |

## §3 施工扰动分析（对既有系统的"爆炸半径"）

| 改动 | 爆炸半径 | 成本/风险 |
|---|---|---|
| `tickHits` 空桩→全逻辑 | 唯一调用方 tickTurn（每回合1次）；扫 activeMissions O(n) | 可忽略；不再有死代码 |
| `AirMission` 新增 1 字段 | 序列化白名单不含 ⇒ 零存档成本；类大小 +8B | 可忽略 |
| `adFxStep` +1 时间戳写 | 每可见帧 1×currentTimeMillis + 1×iput-wide | 可忽略 |
| `adFxStep` 常量→`adSpd()` | 值等价（67.5）；新增 1 个调用点（CheckSig Δ=+1） | 需声明 delta_allow |
| `nABOOT` 升版 | 自证串 | 常规 |

**CheckSig Δ 预期 = +1**（仅 `adSpd()` 调用点；tickHits 重写净 0：getInstance/applyMdDamage/dWrite 数量对称）。
**DexDiff 预期**：恰好 4 类被改（AirDefense / AirMission / ProvinceDrawArmy / AirDefDiag），无类丢失。

## §4 血案与教训（施工时逐条对照）

1. **r6d161（VerifyError）**：插入块必须在 `check-cast` 之后、且寄存器类型纪律（对象寄存器终身不沾数值写）。
   → 本批：新 tickHits 内对象寄存器＝v1/v2/v5/v10/v11，数值＝v0/v3/v4/v6/v7/v8/v9/v12-v15；**v11 双重身份？** 注意：日志段 v11 只做 String（对象），**数值换算用 v7**（float→int），保证 v11 不沾数值。
2. **r6d241b（regfix）**："对象寄存器终身不沾数值"→ 新代码 v10/v11 全程对象（SB/String）。
3. **r6d255（模拟器抓极性错误的先例）**：判定链必须"真实 smali 解释 + 反转敏感性"，不能只信文本门禁。
   → 本批：sim_r6d256.py 覆盖 C1-C9，N1-N3 突变必须变红。
4. **世界书极性表勘误**：`if-gtz` 条目与 Dalvik 标准不符（v1 §9），本批全部用标准语义（`if-gez`=≥0跳、`if-lez`=≤0跳、`if-gtz`=>0跳）。
