# 调研 · r6d262 R1：空军建造界面显示链（全量）

> 2026-10-11｜只读勘察。目标：让"研究到哪代 → 空军建造界面的机型名/图 同步"。

## 1) 界面本体
- 菜单类：`InGame_AirForceOptions`（空军司令部→某机场的机型面板；构造器 ~1900 行）。
- 构造器按 **4 个机型区块**依次搭建（每区块 ~224 行）：顺序 =【战斗机/轰炸机/攻击机/截击机】。
- 每区块组件（实测）：
 | 组件 | 调用 | 说明 |
 |---|---|---|
 | 飞机图 `Icon` | `airImgForTypeP(imgType)` | imgType 约定：**0战/1截/2攻/3轰** |
 | 槽位框 `Icon(airsSlot)` | — | 纯装饰 |
 | **型号字条** `Text_Static` | `airNameForTypeP(nameType)` | x=左缘（v13+3）、y=v14+0x46 —— **即用户说的"空军栏左侧那行普通文本"** |
 | `BtnSelect` | 构造参数含 `airNameForTypeP(nameType)`（按钮标题） | 选择机型/查看 |
 | `BtnBuild` | 构造参数含 `airNameForTypeP(nameType)`；点击→`Airport.startBuild(AirType)` | 建造；悬停用 `AircraftDataManager.types[]` 战斗参数 |
- nameType 约定：**0攻/1轰/2战/3截**（r6d125 铁律）。
- 区块实测配对（图,名）：(0,2)(3,1)(2,0)(1,3) —— 与两套约定换算 `nameType=(imgType+2)&3` 完全一致。

## 2) 现状实现（为什么"没同步"）
- `airImgForTypeP(I)`：`pickAirImage(gen=3 固定, 玩家组, imgType)` —— **代固定 3**（源码注释"暂固定 3（B3e 再接 AirUnit.gen）"）。
- `airNameForTypeP(I)`：**写死的 (组,型)→名字 表**（CN: Q-5/H-6/SU-27/J-8 …）。- ⇒ 图与名都不随研究变化（用户以为"贴图已同步"，实际两边都是占位）。

## 3) 结论
- 修复点=**只改两个取数函数**（`airNameForTypeP`/`airImgForTypeP` 顶部插入"动态取数，未命中回退旧逻辑"）⇒ 图、字条、两个按钮文字**全部 12+4 处调用点自动同步**，无需改 UI 类。
