# 调研 · r6d265 R1：编制不换代 & 地图飞机贴图（全量）

> 2026-10-11｜起因：用户——①"升级到歼20，但造出来的编制还是歼11"；②"地图上的飞机贴图改了吗，没改的话也一起改"。

## 1) "编制"链（空军师=ArmyDivision）——根因实锤
- 机场同步：`AirForceManager.syncAirDivisionForType` 为每（机场,机型）建/更新一个 **ArmyDivision**（省上的"空军师/编制"），其军团 = `ArmyRegiment(uID, aID)`。
- **uID = 机型序号(ordinal)+7**（Units.json：7=截击/8=战斗/9=轰炸/10=攻击）；
- **aID（记录号）被写死 0**：创建路径 `ArmyRegiment(uID, 0)`、更新路径只改 uID/num 从不改 aID。
- ⇒ 军团永远指向该机型**第 0 条记录**（最老那一代的外观/名字/等级）= "造出来还是歼11"。
- 记录体系：`lArmy[类型].get(记录号)` = `Data_Army`（含 Name/UnitLevel/ImageID…）；`civ.unitsBest` = 每类型"已解锁最高等级记录"（(unitID=类型, armyID=记录)）。

## 2) 地图飞机贴图（全点位）
| 点位 | 现状 | 活性 |
|---|---|---|
| 机场上飞机图标（drawAirForce 内） | **写死 `airG3_CN_*`（永远中国·三代）**，环色按机场国 | 活 |
| 移动/选中编队小图（drawAirDivisionAsPlane→airImgForKey→**airImgForCiv**） | 固定"代=3"（B3e 注释处） | 活 |
| 飞行任务标记（drawAirMissionFlyingPlane） | 固定 `Images->airFighter`（原版小飞机） | 活 |
| 省驻留编队（drawAirDivisions） | 方法被 stub（`return true`），不动 | 死 |
- 类型序实锤：AirType=[INT,FTR,BMR,ATK]=0..3；图标型序=0战/1截/2攻/3轰 ⇒ **imgType = ordinal^1**。

## 3) 结论
- 两案都能"纯换引用"修好：①编制：同步时把 aID 设为 `civ.unitsBest` 里该类型最佳记录的 armyID；②地图：4 处写死/固定换成 **按（国,型）的已研究最高代取图**（复用 AirModelTables.bestIdx/genOf + pickAirImage）。
