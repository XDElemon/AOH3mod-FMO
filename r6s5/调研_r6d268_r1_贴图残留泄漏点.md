# 调研 · r6d268 R1：贴图"又变 J20"的残留泄漏点（全量）

> 2026-10-12｜起因：用户实测——编制稳定后"贴图又会变成 J20 的"。

## 1) 残余泄漏链（r6d266 只把"单位链"接给了有数据的场景，回退仍是国最佳）
| 场景 | 现路径 | 结果 |
|---|---|---|
| **静止/选中编队 sprite**（无任务在飞，mission=null） | `airImgForKey`：单位链失败 → 旧回退 `airImgForCiv(国,型)` | **国最佳=J20** ← 用户所见 |
| 机场图标（列表末架无章/异常） | `airImgForAirportOrd`：只看"末架" | 误回退国最佳 |
| 飞行标记（任务飞机列表为空但编制存在） | `airImgForMission`：空列表 → 国最佳 | 同上 |

## 2) 正确语义（延续用户裁定）
- 任何"有编制/飞机"的场景，贴图必须按**编制记录/飞机机型**取；
- 只有"连记录都查不到"才允许回退国最佳（兜底观感）。

## 3) 关键数据链（本次实测确认）
- key 格式 = `airhq_<civ>_<prov>[_<type>_<index>]`（`airhqKey4` 生成；type=1&index=1 时后两段省略）；
- `getKeyCiv(key)` 已有；**`getKeyProv` 本批新增**（同款解析，取第 3 段）；
- key→省→`Province.getArmyKeyID(key)`→`ArmyDivision`→`lArmyRegiment[0]`→(`uID`=型 7..10, `aID`=记录号)→记录→图号→代→图；
- 统一核心：`airImgForRec(civ, uID, aID)`（含全部越界守卫；图标型由 uID 推出 `(uID-7)^1`）。
