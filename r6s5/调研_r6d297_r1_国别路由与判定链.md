```
techID <  32  → 允许（基础科技）
techID >  74  → 允许（保险）
32..44 → 组0   45..54 → 组3   55..63 → 组1   64..74 → 组2
v1 = 该组号；v2 = AirForceManager.artGroupOf(civID)

```
