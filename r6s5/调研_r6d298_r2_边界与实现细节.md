# 调研 · r6d298 R2：边界与实现细节
## 位置钳制
- 用现成公开 API：`getMenuPosX()`（读现状）→ `setMenuPosX(p)`（钳+写目标）→ `getNewMenuPosX()`（读目标）→ 若目标被打回（≠原值）→ `setMenuPosX(getPosX())` 回到最左。
- **不引入任何 |平移| 尺寸类量**（守 r6d294 铁律）；只设位置。
- updateMenuPosX 内部自带 try/catch；任何异常被它吞掉，不会崩。
- 首开/重建时同样走 relayoutDone ⇒ 一并生效；in-range 时**零改动**（不打扰已有浏览位置）。

## 选项保持
- 新 static 字段 `sTopCatLast`（String，进程级）。
- `addTopTabs`：有值用之，否则 "land"。分支 `if-eqz v1,:ts_land`（NULL=0 跳 → 用 land）。
- `applyTopFilter`：`sput-object p1` 落盘（每次点击/首开都会更新）。
- 换国/新局：static 仍在，属可接受（打开即用上次栏）。
