# 调研 R3 · 全屏布局改造（r6d300）——施工定稿

> 依据：`调研_全屏布局_v1.md`（R1）+ `调研_r6d300_r2_边界与实现细节.md`（R2）。
> 目标：标题贴屏顶、按钮带居中、科技区直落屏底；全尺寸自适应。

## 用户参数
- A：按钮带→科技内容 间隙 **20px**（用户定）。
- B：按钮带宽度公式 **默认不变**。
- 按钮带上下：上 2*PADDING（12，沿用现有风格），高 BUTTON_HEIGHT。

## 最终几何（运行时量）
| 量 | 公式 | 60/6/60 例（1080P） |
|---|---|---|
| 菜单 y | titleH | 60 |
| 菜单/底板可视高 | GAME_HEIGHT − titleH | 1020 |
| 标题栏 | [0, titleH] | 0–60 |
| 按钮带 | [titleH+2P, +BUTTON_HEIGHT] | 72–132 |
| 科技内容顶 | titleH + 2P + BUTTON_HEIGHT + 20 | 152 |
| 底板高 | max(内容底, 可视高) | 1020（底=1080） |
| 页签 rel y | 2P（不变） | 12 |

## 编辑清单（单文件 InGame_TechnologyTree.smali）
- **E1** initMenu y：`sget GAME_HEIGHT/div2/div v10,2/sub` ⇒ `move v3, v14`
- **E2** `min→move-result v10` 后插：`sget v10,GAME_HEIGHT` + `sub-int/2addr v10, v14`
- **E3** Empty 前插：`max(v0,v10)→v3`；Empty 高参 `v0→v3`
- **E4** 节点：`add-int/lit8 v19, v0, 0xf` 后插 2P+BUTTON_HEIGHT+0x5 → `add-int/2addr v19, v0`
- **E5** cyOf 尾部：同上算术 → `add-int/2addr v2, v0`（在 return 前）
- 不动：pinTopTabs、relayout*、isInView 保底、连线重建、重建路径（自动重走 ctor）。

## 寄存器审计
- E1: v3（dest）、v14（活到 1052，已验证无写）。E2: v10、v14。E3: v0,v10→v3（其后再被清空重用，既有 int→float 顺序不变）。E4: v0、v2（=TreeRow，其后 4 行内被重写为 techID，无读）；v19=节点 y。E5: v0,v1（cyOf 尾部空闲）、v2=中心 y。
- 新指令均为 int 族，无对象/数值混用（跑 regtype_gate 复核）。

## 失败模式与回退
- 锚点计数≠1 ⇒ 补丁拒绝写盘（全量先验后统一写）。
- 若贴顶被资源条覆盖（z 层意外）⇒ 回退 r6d299 或把 y 改为 topStatsH（一行）。
- 双树 `.pre_r6d300` 备份；归档 r6d299 保留。

## 验收（可证伪）
1. 肉眼：标题上沿=屏顶；三按钮位于标题下、科技上方的空带；科技画布/边框直落屏底。
2. 探针：`nTTG2 o=(0,60)`、`t0.y≈72`、`nTTG h=1020`。
3. 功能回归：切栏即显、点科技留栏、点击页签正常（r6d295-299 行为不回退）。
4. 门禁：check_r6d300（S1–S7 + N1–N4 反转必红）；sim_layout_r6d300（多机型不变量 + 变异敏感性）。
