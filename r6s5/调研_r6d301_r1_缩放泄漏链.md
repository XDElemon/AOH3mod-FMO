# 调研 R1 · r6d301 缩放泄漏（科技树打开时仍能缩放地图）
> 2026-10-13｜只读调研（全部来自现行 smali）

## 症状
科技树打开时，双指捏合仍能缩放地图；缩放触发大面积重算 ⇒ 卡顿。

## 输入链（实测）
- 双指：`AA_Game$1.touchDragged`（检测到第 2 指）→ `Touch.actionMove(IIII)` → `MapTouchManager.actionMove(IIII)`
  - 守卫1：`Game.mapCoords.disableMovingMap`
  - 守卫2：**`Game.mapScale.getEnableScaling()`** ← 单一总闸
  - 通过后：`startScaleTheMap` / `scaleTheMap`
- 单指拖拽：`actionMove(III)` → `actionMoveMap`（另受 `MapTouchManager.disableMovingMap` 守卫）
- 滚轮/键盘/按钮：`MapScale.scrollScale`（守卫含 main menu / new game / load list / legacies / selectMode——**无科技树**；移动端无此路径）

## 结论
双指缩放被 `getEnableScaling()` 单闸控制 ⇒ **树可见期间临时关断该闸即可冻结缩放**；关闭时还原。
- 不动 `MapTouchManager` / `MapScale` 本体，只在科技树的 `setVisible(Z)` 里"借闸还闸"。
