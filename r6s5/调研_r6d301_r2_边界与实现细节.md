# 调研 R2 · r6d301 边界与实现细节

## 打开/关闭落点
- `MenuManager.setVisibleInGame_TechnologyTree(Z)` → 对 **树实例** 与 **EMPTY 伴生菜单** 调 `Menu.setVisible`。
- 树类已有 `setVisible(Z)` override（保存 lTime）⇒ 直接在此挂钩，覆盖"打开/关闭/重建后设置可见"全部路径。
- 重建（点科技）：新实例；锁标记用 **静态字段** `sScalingLocked`，跨实例有效。

## 寄存器审计（setVisible）
- 现状 `.registers 4`：v0/v1 可用；v2=this、v3=p1。
- 方案：显隐两分支**各自 return**（不合并），规避 ART 类型合并冲突；只用 v0/v1。
- 调用效果：`getEnableScaling()` 结果入 v1；`setEnableScaling(v1)`。

## 状态机（幂等）
- 打开：当前=true → 记锁 + 关断；当前=false → 不动（勿覆盖用户偏好）。
- 关闭：锁标记=true → 还原 true + 清锁；否则不动。
- 重复打开/关闭、开→关→开 全部幂等（模拟器 A–E 覆盖）。

## 边界
- 退出游戏时若树未关：本会话禁用保持，重启后恢复（可接受，登记为已知边界）。
- 滚轮路径未覆盖（移动端无滚轮）；不扩展范围。
