# 调研 R1 · r6d302 FBO 省份绘制开启（A 方案）
> 2026-10-13｜只读调研（基于 r6d301 现行代码）

## 一、完整链路（实锤）
1. **拦截点**（默认地图模式）：`MapModeManager$1.draw` / `$31.draw` 都**在每帧 draw 时实时读** `SettingsManager.FBO_PROVINCES`：
   - true → `ProvinceDraw.drawProvinces_Standard_FBO(sb)`
   - false → `ProvinceDraw.drawProvinces_Standard_InGame(sb)`
   ⇒ 改标志即可切换，无需重建委托。
2. **FBO 变体** → `drawProvinces_Standard_LandProvinces_FBO(sb)`（管理器）：
   - 缓存在且位置未变 → 跳过（由渲染第二趟 blit 缓存）；
   - 位置变了 → 释放旧缓存 + 本帧直绘；
   - 无缓存 → `updateFBO()` 计帧；连续静止 ≥ `FBO_NUM_TO_GENERATE_PB(=14)` 帧 → 重建（`new FrameBuffer(RGBA8888,W,H)`→begin→直绘进 FBO→end→取色纹理）。
3. **blit 消费**：`RendererGame$3/$4.drawWithoutScale_Provinces`：`FBO_PROVINCES && texture!=null && inGame && MODE_DEFAULT` → `drawPBG`。
4. **失效钩子**：`redrawnProvinces()`（fog/易主/Formable/ColorPicker/省份变动）、`airFadeFBOForce()`（选中态变化释放）都已接好。

## 二、"没开"的完整禁用链
- `assets/game/gameValues/GameValues.json` → `MOBILE_DISABLE_FBO: true`；
- `GameValues.updateSettingsFBO()`：`!isDesktop() && MOBILE_DISABLE_FBO` ⇒ 把两个标志置 false；
- `SettingsManager` 构造器默认两标志 = **false**（v4=0；v5=1 用于其它默认真值）；
- 唯一置 true 的现有入口是设置界面的开关（移动端在 `MOBILE_DISABLE_FBO=true` 时连行都不显示）。
⇒ 三步都放开：资源置 false、默认值置 true、其余链路原样即可工作。

## 三、A 方案落点
1. **资源**：`MOBILE_DISABLE_FBO: false`（注入 APK，`build_with_assets.sh`）。
2. **smali**：`SettingsManager` 构造器把 `FBO_PROVINCES` 默认改 true（仅此一个标志）。
3. **探针**：`GameValues.updateSettingsFBO()` 末尾加一次 `nFBO p=? n=?` 诊断（验收自证；单独 try/catch 方法）。
