# 调研 R2 · r6d302 边界与实现细节

## 锚点/寄存器审计
- `SettingsManager` 构造器：`iput-boolean v4, …FBO_PROVINCES:Z`（唯一）；此时 **v5=1 且自 202 行后无写入**（204/266/274/282 均为读用）⇒ 直接改 v5。`FBO_PROVINCE_NAMES` 一行保持 v4（本批不开）。
- `GameValues.updateSettingsFBO`（文件**末尾方法**）：
  - 插入点：`:cond_15` 与 `return-void` 之间（两分支汇合处）加 `invoke-static r6d302_logFBO`；
  - 新方法体 `.registers 4`，StringBuilder 拼 `nFBO p=? n=?` → `AirDbgLog.dWrite(String)`，整段 try/catch（`exceptionStack`），异常不影响游戏。
- 资源管道：`build_with_assets.sh <批次> <暂存目录> [模板apk] [新dex]`；暂存目录内路径与 APK 内一致（`assets/game/gameValues/GameValues.json`）；脚本会做"暂存 1:1 注入校验"。
- 基线：r6d301 APK 内该 JSON `md5 f42c0fe7…`（size 1064）；以 **APK 内文件为底**改一行，保证风格零漂移。

## 风险
- 移动 GPU 兼容未知（官方为何禁用未公开）：已保留一键回退（r6d301）。
- 内存：2318×1080 RGBA ≈10MB/份；静止 14 帧后重建一次，首帧代价可感知为轻微顿挫（一次性）。
- 本批只开 `FBO_PROVINCES`；`FBO_PROVINCE_NAMES` 维持 false（后续如需另批）。
- 设置界面：资源放开后会出现 FBO 开关行（可手动切换，属预期）。

## 验收
- 静态：门禁 `check_r6d302`（S1–S4 + N1–N4）。
- 构建后：**从最终 APK 内抽**该 JSON 复核 `MOBILE_DISABLE_FBO: false`（资源类改动铁律）。
- 运行时：`aircfg_diag.txt` 出现 `nFBO p=1 n=0`（p=省份 FBO 已开、n=地名 FBO 未开）。
- 体感：拖动/静止时更流畅；画面（配色/雾/选中）无异样；无闪退。
- 异常：回退归档 r6d301。
