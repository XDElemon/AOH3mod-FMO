## 二、第三轮：定稿（锚点 / 真值表 / 寄存器）

| A2 | `AirForceManager.smali` | `cfgFix` 的 `ai_w_bomber` 写回之后插入 `load_swap_ms` 解析 + 钳位 `[0,60000]` |

### 2. 判定顺序（人话）
每帧加载页绘制时调用一次 `loadingRotateTick()`：
1. 若 `dgLoadSwapMs <= 0` ⇒ **关闭**（不换）。
2. 若 `lastSwapMs == 0` ⇒ 只记录当前时刻（本次不换）⇒ 保证"第一张图展示满 T"。
3. 若 `now - lastSwapMs < dgLoadSwapMs` ⇒ 等待。
4. 否则 ⇒ 记录 `lastSwapMs = now` ⇒ 调 `loadBackground()`（dispose 旧图 → 换新随机图 → 重算尺寸）。

### 3. 参数与阈值表
| 名称 | 值 | 含义 | 调大 | 调小 |
|---|---|---|---|---|
| `load_swap_ms`（配置键） | 3000（默认） | 加载页换图间隔(ms) | 换图更慢、更省 | 换图更快、更卡 |
| 钳位范围 | `[0, 60000]` | 0=完全关闭 | — | — |
| 图片规格 | 1920×1080 RGBA ⇒ 纹理 ≈8 MB | 单张显存 | — | — |

### 4. 寄存器分配（新方法 `.registers 8`）
| 寄存器 | 类型 | 用途 |
|---|---|---|
| v0 | int | `dgLoadSwapMs` / `cmp-long` 结果 |
| v2/v3 | long | `now` / `elapsed` |
| v4/v5 | long | 0 / `lastSwapMs` |
| v6/v7 | int→long | `dgLoadSwapMs` 经 `int-to-long`（**不参与 invoke**，无血案2 风险）|
- 调用点 `invoke-static {}` **不占寄存器**；`loadBackground` 无参无返回。
- 方法独立成方法 ⇒ 主流程只加 1 行。

### 5. 失败模式与回退
| 现象 | 判定 |
|---|---|
| 配置 `load_swap_ms:0` ⇒ 一张都不换 | **正常**（关闭语义）|
| 每 3 秒换图时短暂卡顿（PNG 解码 + 上传约百毫秒）| 预期代价；可调大 `load_swap_ms` |
| `loadBackground` 抛异常 | 若发生则整帧绘制中断（与本作既有行为一致）；**不做 try/catch**（避免掩盖问题，且原函数本就在加载路径被直接调用）|
| 加载 <3 秒结束 | 只看到 1 张 ⇒ 正常（可把间隔调到 1500 观察）|

### 6. 验收标准（可证伪）
进加载场景并**停留 >6 秒**（如加载大地图）：
- 通过：加载页背景**每约 3 秒换一张**，且新图与上一张不同；
- 对照：`load_swap_ms:0` 时**全程不换**；
- 反向核验：`aircfg_diag.txt` 的 `CFGT3 … fswap=3000`。

### 7. 门禁设计（121+，真解释器）
真值表：`swapMs=0`⇒不换；`lastSwapMs=0`⇒只初始化；`elapsed<T`⇒不换；`elapsed=T`/`>T`⇒换一次且更新 `lastSwapMs`；连续两次刻度⇒各换一次（间隔有效）。
负样本（必须被判失败）：把 `if-lez`→`if-ltz`（关闭语义失效）、把 `if-lt`→`if-ge`（间隔反向）、删掉 `lastSwapMs==0` 初始化分支（首张图立即被换）。

### 8. 本版不做（明确不修改）
- 不做主菜单背景轮换（HOI4 是共用池，我们已有 `loadBackground` 共用；主动轮换留待下一批）。
- 不做"新图优先 N 次启动"与"缩略图 `_small`"机制。
- 不动 `numberOfImages.txt`（保持 30，无换行）与图片资源。
