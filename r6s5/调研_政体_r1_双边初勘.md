# 调研 · 政体系统 R1：双边初勘（AoH3 现状 / HOI4 对象）
> 2026-10-12｜起因：用户指示「把政体系统改成和钢丝的一样」。此为第一轮只读勘察。

## 一、AOH3 侧（已有底座，比预想的多）
- **意识形态 = 政府表**：`CFG.FILE_IDEOLOGIES_LIST = Governments.json`，`IdeologiesManager` @9588 从 `game/Governments.json` 加载（即 20 条政体记录）。
- **每国一个意识形态 id**：`Civilization.iIdeologyID` + `getIdeologyID()I`；消费面（部分）：`EventTrigger_CivGovernmentIs` / `CivTag_GovernmentIs(Not)`、`AI_Laws`、`AI_Manager`、`AI_Build`、`AI_PeaceTreaty`…（待全量）。
- **切换机制已存在**：`IdeologiesManager.changeGovernmentType(IIZ)Z`（改政体）、`canChangeToIdeology(I)List`（可改成哪些）、`canBeAdded(II)Z`（可用性）、`getHoverIdeology` / `getMenuElements`（UI 数据）。
- **Ideology 字段（摘要）**：GOV_GROUP_ID、Extra_Tag、CITY_STATE、Color[F]、AdvisorCost、AdministrationBuildingsCost、ArmyMaintenance、BuildingSlot、ConstructionCost/Time、CoreCost、DevelopInfrastructureCost、EconomyBuildingsCost、GeneralAttack/Defense/Cost、IncreaseManpowerCost、IncreaseTaxEfficiencyCost、MaxManpower、MaxNumberOfLoans、ReligionCost、TaxEfficiency、AI_* 家族…（还有更多待列全）。
- **已有 UI/部件**：Court → ChangeGovernmentReligion（`InGame_ChangeIdeology{,2}`）；4 类顾问（advisorAdministration/Economy/Technology/Military）+ `InGame_AdvisorRecruit`；稳定度 `civStability`（GameValues.GameValue_CivStability）。
- **待查**：canChangeToIdeology 的规则链（费用/冷却/前置）、GOV_GROUP_ID 语义、宗教更改联动（ReligionCost）、AI 改政体频度、Laws 与政体的联动。

## 二、HOI4 侧（政治系统对象清单）
- ** ideologies**：democratic / communism / fascism / neutrality 四大；每大含 `types`（子意识形态）、color、`rules`（可否造傀儡/派志愿军/强制执行政府…）、war_impact_on_world_tension、modifiers、faction_modifiers、ai_* 字段（`common/ideologies/00_ideologies.txt` 实证）。
- **政治点（PP）**：defines 实证 `POLITICAL_POWER_LOWER_CAP=-500`、`UPPER_CAP=2000`、`BASE_POLITICAL_POWER_INCREASE=2`（每周基础产出）。
- **法案 = ideas**：`law = yes` + `use_list_view = yes` 分组（如 `mobilization_laws`），条目录含 cost / removal_cost / level / available / modifier / on_add（`common/ideas/_manpower.txt` 实证）。
- **选举 / 政党支持率 / 稳定度与战争支持**：待定位（elections 在 history/scripted effects 一带；stability/war_support 在 on_actions/defines）。

## 三、设计方向（初步，供后轮展开）
分层（钢四式）：**意识形态（底层：规则+政党）→ 政体（政府形式，现有 20 条可直接映射）→ 法案（Laws，AoH3 已有）→ 顾问（已有 4 类）→ 政治点/稳定度（civStability 已有）**。
我们已具备大部底座 ⇒ 钢四化的侵入点多为「复用 + 扩展」（政党支持率、选举周期、政治点货币、法案与政体联动）。

## 四、下一步
- R2：AOH3 深挖 changeGovernmentType / canChangeToIdeology 规则链 + Laws/AI；HOI4 深挖 elections/parties/stability/war support 数据结构。
- 产出『政体机制菜单』（参照科技 M1–M16 模式）供用户勾选范围。
