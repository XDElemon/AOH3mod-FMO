# 调研 · 政体 R2：选举/法案定位 + 换政体规则链（阶段小结）
> 2026-10-12｜只读勘察（钢4 + AOH3），承接 R1。

## 一、HOI4 侧新取证
1) **选举（elections）定位成功**：
   - `events/ElectionEvents.txt`（选举事件链）；`common/scripted_triggers/Elections_scripted_triggers.txt`（选举触发器）；
   - `election_frequency` 由决策/国策等效果设置（样本：BRA/NORDIC/YUG 决策、多国国策里都能看到 `election_frequency = 48` 等）；
   - 图像资源：`gfx/event_pictures/*election*`。
2) **法案（laws）**：共 3 个主文件带 `law = yes`：`common/ideas/_manpower.txt`（征兵线）、`common/ideas/_economic.txt`（经济线）、`common/ideas/spain_republic.txt`；条目录含 cost / removal_cost / level / available / modifier / on_add（R1 已摘）。
3) **稳定度/战争支持 defines（好用的数值）**：
   - `DEFAULT_STABILITY = 0.5`、`DEFAULT_WAR_SUPPORT = 0.5`；`WEEKLY_STABILITY_GAIN = 0`、`WEEKLY_WAR_SUPPORT_GAIN = 0`；
   - `BASE_STABILITY_WAR_FACTOR = -0.2`、`BASE_STABILITY_PARTY_POPULARITY_FACTOR = 0.15`；战争：进攻 −0.2 / 防守 +0.2；`MIN/MAX_STABILITY = 0/1`。

## 二、AOH3 侧新取证（继 R2 核查）
1) **换政体规则链（changeGovernmentType）**：同款→拒；非 free：金币≥成本 且 Legacy≥成本；科技门（值≥0 才查，现行全 -1）。
2) **特殊旗标的消费面（均非玩家门）**：
   - `CITY_STATE`：AI_Government（省数超阈值时改城邦）＋ RevolutionManager；
   - `MUST_BE_CHANGED`：AI_Government（超期强制改）；
   - `REVOLUTIONISTS`：IdeologiesManager.canChangeToIdeology（组内选择逻辑）、AI_Government、RevolutionManager；
   - `ReligionCost`：GameValue 字段 + EventOutcome_BonusReligionCost（事件加成）。⇒ 对玩家常规换政体不构成阻塞。
