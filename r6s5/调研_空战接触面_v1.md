# 调研 · 空战"接触面"：为什么巡逻/截击机遇敌不交战（第一轮）v1

> 触发问题（用户）：战斗机 / 截击机**巡逻时不会打敌方飞机**，即使看到也**直接穿过去**。
> 本文件＝**第一轮（全量）调研**，只读代码、不动任何补丁。基准树：`/tmp/w3a/smali`（与 r6d077 装机同源）。

---

## 一、一句话结论（可证伪）

**空战引擎是有的，但"谁能打谁"被两道门卡死：**
1. **只有 `INTERCEPT`（截击）任务会进入空战 tick** —— 巡逻（`PATROL`）任务**根本不参与空战**；
2. 即使进了 tick，**目标白名单只有 `STRATEGIC_BOMBING`（战略轰炸）与 `ATTACK_ARMY`（对地打击）** ——
 ⇒ **战斗机/截击机之间（巡逻/截击任务本身）永远是"不可攻击目标"**，所以只会**互相穿过去**。

## 二、证据链（行号＝当前树）

### 门槛①：只有 INTERCEPT 进空战
`AirMission.airCombatTick()`（AirMission.smali:640）
```
 iget-object v0, p0, ->type: MissionType sget-object v1, ->MissionType;->INTERCEPT
 if-ne v0, v1, :cond_194      # ← type != INTERCEPT ⇒ 直接跳走（本方法结束）
```
进入后还需三条件：`state ∈ {EN_ROUTE, EXECUTING}`（649–666）、`airDivisionAtProvinceID > 0`（672）、
**小时级冷却** `(TURN_ID*24 + HOUR) - gunLastHours >= HOURS_PER_TURN`（673–687）。
⇒ **每任务每回合最多交战一次**；PATROL 一条都进不来。

### 门槛②：目标白名单只有"轰炸/对地"两类
同方法内候选筛选（AirMission.smali:800–812）
```
 sget-object v5, ->MissionType;->STRATEGIC_BOMBING
 if-eq v1, v5, :cond_9b        # 是战略轰炸 ⇒ 选中
 sget-object v5, ->MissionType;->ATTACK_ARMY
 if-eq v1, v5, :cond_9b        # 是对地打击 ⇒ 选中
 goto :goto_9d                 # 其它类型（PATROL / INTERCEPT / …）⇒ 跳过，继续找
```
⇒ **敌方"战斗机/截击机"（PATROL / INTERCEPT 任务）不在可攻击集合内**。

### 关键旁证
- `updateAIAutoIntercept` 内部**没有**任务类型过滤（grep `MissionType;->` 无命中）⇒ 敌方任何类型的任务都可能被**派截击**；
- 但**派出去的截击任务**自己进 `airCombatTick` 后，**只能打轰炸/对地** ⇒ 对敌方战斗机依旧"打不着"。
- `createSweep`（扫荡）只被调用 1 次（AFM:6089），`createAirSuperiority`（制空）**在树里无调用方**（疑似死代码）。

## 三、症状 ↔ 原因对应表

| 玩家看到的现象 | 对应原因 |
|---|---|
| 战斗机巡逻时，敌机从旁边飞过、不交战 | **门槛①**：PATROL 无空战 tick |
| 就算我方派了截击，遇到敌方战斗机也不打、互相穿过 | **门槛②**：目标白名单只有轰炸/对地 |
| 轰炸机/对地机被我方截击时会挨打（若看得见且能飞到） | 白名单命中 ⇒ 属现有设计内行为 |
| 每回合最多打一次 | `gunLastHours` 与 `HOURS_PER_TURN` 冷却 |

## 四、三个可选改法（供拍板，第二轮再钉锚点）

| 方案 | 内容 | 改动面 | 风险 |
|---|---|---|---|
| **A（最小）** | 把目标白名单扩到"含敌方 PATROL / INTERCEPT"（战斗机互殴） | 1 处：`airCombatTick` 白名单段加两个 `if-eq` 分支 | 低（但只解决"截击打不到战斗机"） |
| **B（对症）** | 让 **巡逻任务也能进入空战**：门①由 `type == INTERCEPT` 放宽为 `type ∈ {INTERCEPT, PATROL}`（并补巡逻态的省匹配条件） | 1–2 处，需补"巡逻在哪个省算接触"的判定 | 中（可能在自家领空乱打／性能） |
| **C（最贴原设计）** | **自动升格**：巡逻中的战斗机若在同一省"看见"敌机（复用 `aiRadarVision` + `dispachAutoIntercept` 同款判据）⇒ 当场转为/派发截击，而不是新造一条任务 | 中（要处理任务态切换/归属） | 中 |
| **D（建议组合）** | **A + B**：战斗机之间能互殴，且巡逻也能触发交战（对轰炸/对地仍走原线） | 小–中 | 需要至少一次"同省接触"的定义与节流 |

> 我的倾向：**先 A（1 行级判据扩展，立刻可验收"战斗机互殴"）**，再按你的口味决定 B/C（"巡逻即拦"）。
