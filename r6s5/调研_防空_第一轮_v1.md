# 四、**现有防空雏形**（重要）

`AirForceManager.update(I)V`（**方法起始 @11918**，AAA 段 **@11979–12100**）：

```
对本国每个机场：
  若 该机场所在省 有 AAA（反导阵地）建筑
  且 该省归属 civ ≠ 机场 civ（即机场被敌占/在他国境内）
  则 对该机场内每一架 isAlive 且 !isInFlight 的飞机：hp -= 1.0；hp<=0 ⇒ isAlive=false
```

**现状定性**：这是"**停在敌境内的飞机每 tick 掉 1 血**"的粗放惩罚。
- 没有代际、没有概率、没有雷达参与、没有建筑数量权重；
- **不拦截"在飞"的飞机**（`isInFlight` 的飞机完全不防空效果）；
- 没有日志/提示。

# 六、设计选项（供你选）

| 方案 | 内容 | 落点 | 改动量 |
|---|---|---|---|
| **A 地面防空拦截来袭任务** | 敌机在目标省执行任务时按概率被击落/掉血 | `AirMission`（伤害应用处）+ 新 helper `airDefenseAt(provinceID)F` | 中（1 批） |
| **B 升级现有雏形** | 把 `update(I)V` 里"−1 hp"改成"按防空强度算" | `AirForceManager.update @11979–12100` | 小（可先做） |
| **C 地面减伤** | 被轰炸省若有机场/雷达/反导，减免 pop/军队伤害 | `AirMission.applyPopDamage/applyArmyDamage` 调用前 | 小–中 |
| **D 代际接入** | 防空强度随代际提升（雷达 `ImprovedByGen` 或国家科技代际） | 依赖科技系统（B7/B8 之后） | 中 |

**建议组合**：先 **B（最小可见效果）** → 再 **A + C（真正的防空）** → 最后 **D（与科技代际挂钩）**。
