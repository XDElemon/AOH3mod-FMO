# 调研 · 防空（第二轮 · "空军师"与导弹模型）

日期：2026-10-02 ｜ 目标：回答"除了反导阵地谁还能防空""防空阵地能不能做成'永远停在那的空军师'（会打导弹）"

---

# 一、回答：**目前只有"反导阵地"参与防空逻辑**

| 建筑 | 目前用途 | 性质 |
|---|---|---|
| **反导阵地**（`AAA_BUILDING_ID`） | `AirForceManager.update()V` @12009：**敌境机场里的非飞行飞机每 tick −1 hp** | **唯一参与逻辑的"防空"** |
| 雷达（`RADAR_BUILDING_ID`） | `hasRadarBuilding` → 视野（`PlayerFogOfWar`×2）、`aiVisRadarPass`、地图绘制（`RadarBitmap`、`ProvinceDrawArmy`） | 只探测/绘制，**不开火** |
| 中层反导雷达（`LONGRADAR_BUILDING_ID`） | 与雷达一起被用于"收集雷达省"（@11548/11641、`Province` 三处） | **只探测，不开火** |
| 空军基地（`AIRPORT_BUILDING_ID`） | 机场（`Airport`）存在性判定（UI + 逻辑 @11404） | 驻地，不防空 |

**⇒ 结论**：你想要的"能打导弹的防空阵地"**目前不存在**；反导阵地只有一个很粗的地面惩罚。

# 二、"空军师"在代码里是什么（关键）

`AirMission`（= 一个出击的"空军包"）字段：

| 字段 | 含义 |
|---|---|
| `airhqDivision: ArmyDivision` + `airhqKey: String` | **绑定一个陆军师**作为"空军师"载体（`pickupAirDivision` / `placeAirDivision` / `returnAirDivisionHome`） |
| `airDivisionAtProvinceID / airDivPrevProvinceID / airDivPrevPrevID / airDivSegAnimMs / airDivSegDurMs` | 该"师"在地图上的**移动动画**（所以玩家看到的是一个"空军师"在地图上走） |
| `assignedAircraft / aliveAircraft / lostAircraft / fPoolHP / maxPoolHP` | 编队飞机与**编队血量池** |
| `missilesLeft / missilePerPlane / gunAmmo / lastMissileHours / lastMissileMs` | **导弹与机炮弹药** |
| `enemyAircraftShotDown / attackRoundsExecuted / maxAttackRounds / lingerRounds / maxLingerRounds / state / type` | 战绩、交火轮次、滞空时长、状态、任务类型 |

`Airport`：`aircraft:Map / aircraftDeployed / buildQueue / level / maxCapacity / mode / prefPayload / radarRange / provinceID / civID`

⇒ **"永远停在那的空军师"= 一个不移动、弹药按轮次自动消耗的驻留实体**。这在结构上完全可做：
- 要么**复用一个 `AirMission`**（`lingerRounds` 设无限、不执行 `placeAirDivision` 移动）；
- 要么**新做一个轻量"防空阵地"对象**（只含 provinceID/civID/gen/missiles/雷达参数）。

# 三、导弹系统的现状（可直接复用）

`AirMission.missileTick()` @4912 —— **导弹已经在工作**：

| 机制 | 实现 | 数值 |
|---|---|---|
| 触发条件 | `strikeKind == 1`（导弹打击模式） | — |
| 发射节奏 | 按**小时**：`lastMissileHours` + (`msFlyHours` 或 `HOURS_PER_TURN`) ≤ 当前小时 | 每小时/每回合 |
| 目标选择 | 遍历 `AirForceManager.activeMissions`，按 `strikeTargetMissionID` 找**敌方任务** | 打的是**敌机编队** |
| 弹数（按代） | `missileCountForGen(gen)` | ≤2 代：**0 枚**；3–4 代：**2 枚**；>4 代：**4 枚** |
| 射程（按代） | `missileRangeForGen(gen)` | 当前恒为 **100**（像素，平方比较） |
| 跳数 | `missileHopsForGen(gen)` | 恒为 1 |
| 邻接判定 | `missileIsNeighbor(from,to)`：先查邻省，再按**距离²≤射程²** | 射程 100px |

⇒ **"防空阵地打导弹"可以完全复用这套**：把"发射者"从"移动中的空军任务"换成"停在省里的防空阵地"，目标换成"进入射程的敌方任务/飞机"。

# 四、设计选项（供你选）

| 方案 | 内容 | 复用 | 改动量 | 备注 |
|---|---|---|---|---|
| **① 静态防空师（伪任务）** | 在建筑所在省创建一个**永久 `AirMission`**（不移动、`lingerRounds` 无限），复用 `missileTick` 打进入射程的敌机 | 导弹/空战/伤害全部复用 | 中 | 会进入任务列表，UI 上可能显示为"在飞的空军师" |
| **② 独立"防空阵地"对象** | 新建 `AirDefenseSite`（provinceID/civID/gen/missilesLeft/雷达参数），在 `update()V` 里 tick：探测→选目标→发射 | 复用 `missileCountForGen/RangeForGen` + 伤害函数 | 中高 | 最干净；需新字段 + 存档兼容 |
| **③ 只升级现有 AAA 段** | 把 `update()V` 的"−1 hp"改成"按雷达探测 + 代际的命中概率 + 伤害" | 无需新对象 | **小** | 仍不拦截"在飞"飞机，需再加"扫射在飞任务" |
| **④ 建筑分角色** | **反导阵地**＝近程防空（打飞机）｜**中层反导雷达**＝中段反导（打远程空中目标/**导弹**）｜**雷达**＝探测与命中加成｜**空军基地**＝驻地 | — | 设计与参数层 | 建议作为总纲 |

**建议路线**：`④ 定角色 → ③（最小可见效果，1 批）→ ②（正的防空阵地，1–2 批）→ 与"代际/科技"挂钩（科技系统 B7/B8 之后）`

# 五、参数草稿（待你定）

| 参数 | 建议值 | 来源 |
|---|---|---|
| 弹数 | 3–4 代 2 枚 / 5 代+ 4 枚 | 直接沿用 `missileCountForGen` |
| 射程 | 近程（反导阵地）≈100px；中层（中层反导雷达）≈300–600px | `missileRangeForGen` + `RadarConfig`（ABM_SITE 300 / MIDCOURSE_ABM 2400） |
| 发射节奏 | 每回合 1 次（或每 N 小时） | 沿用 `missileTick` 的小时逻辑 |
| 命中率 | 由雷达精度决定（AIRPORT 0.25 / RADAR 0.5 / ABM 0.8） | `RadarConfig.Precision` |
| 探测前提 | 目标须被发现（雷达覆盖）才能打 | `CanDetectAir` + `radarProvinces` |
| 伤害 | 命中 → 目标编队 `fPoolHP` / 单机 `hp` 扣减 | `applyAirDamage` 范式 |
