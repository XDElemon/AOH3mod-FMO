# 2. 汇总：钢四科技系统 = 10 组 / ~60 个机制

```
A 结构布局(10)  B 门槛成本(7)  C 研究能力(7)  D XP研究(5)  E AI决策(7)
F 解锁对象(6)   G 学说(9)      H 特殊项目(8)  I MIO(9)     J 共享情报(7)   K 其他(6)
```

**四条"最核心"的机制**（如果只挑四条，就是它们）：
1. **B2 `start_year` + B4 提前惩罚** —— 钢四节奏的灵魂
2. **A4 `category` + C5 定向加成** —— 全系统"研究加成"的乘区基础
3. **G 学说树（XP + mastery）** —— 第二套成长线，与科技并行的"长期投注"
4. **F 解锁对象（装备/模块/营连/建筑 + on_research_complete）** —— 科技真正"改变玩法"的出口
