# 雷达圈"切国家滞留" · 调研与修复报告 v1

- 日期：2026-09-16（修复版 R4c164 已装机）
- 现象（用户）：切换国家后，在别的国家视角仍能看到**原国家的雷达圈**。

## 一、调研结论（根因）

1. 雷达圈绘制 = `RadarBitmap`（**烘焙位图**）：`rebuild → refresh()` 全量重绘；重绘时按 `isEnemyProvince` 过滤——**只画"省份归属 == 当前国籍"的雷达圈**。
2. 置脏链：`registerRadar / syncRadar / unregisterRadar → markDirty`（= 位图置脏 + fogRefresh）；`draw()` 每帧检查 dirty，节流 ≤60 帧后重建。
3. **切国路径 `setPlayerCiv` 未置脏** → 旧贴图（原国籍雷达圈的烘焙结果）在新国籍下继续显示。R4c163 只修了迷雾层，未触及圈位图。
4. 机场圈是逐帧现画的（无缓存）→ 没有此问题；滞留的只有"建筑雷达圈"位图。
5. 边界/坐标无忧：位图边界取自 `Game.lProvinces`（全图省份），任何国籍的雷达都覆盖。

## 二、修复（R4c164）

- `setPlayerCiv` 内：R4c163 的 `fogRefresh()` 调用**升级为 `RadarBitmap.markDirty()`**——
  一次调用 = 位图置脏（圈跟随新国籍）＋ fogRefresh（基础＋雷达＋机场三层迷雾，保留 R4c163 成果）。
