# 雷达视野"切国家丢失" · 调研与修复报告 v1

- 日期：2026-09-16（修复版 R4c163 已装机）
- 现象（用户）：建好雷达、雷达圈内省份解除迷雾；**切换国家再切回来，雷达视野丢失**（恢复迷雾）；**不影响飞机拦截**；用户猜测与"节流"有关。

## 一、调研结论（根因链）

1. 迷雾体系（PlayerFogOfWar）分三层：
   - 基础层 `buildFogOfWar(civ)`；**雷达层 `fogFromRadar()`**；机场层 `fogFromAirports(civ)`。
   - 全量重建 = `fogRefresh()` = init + build + **radar** + **airports**，其触发点全工程仅 3 处：`RadarBitmap.markDirty`（造/改雷达时）、`MapScenarios`（载图）、`InitGame`（开局）。
2. 每 tick 更新族（`updateFogOfWar*`）**不做全量重建** → 平时雷达标志自然保持（这就是"平时不丢"的原因）。
3. **切国家路径 `InGame_Sandbox.setPlayerCiv` 只调 `buildFogOfWar`（基础层）**——漏掉 `fogFromRadar` / `fogFromAirports` 两层 → 切走、切回都重放不出雷达视野。
4. 拦截不受影响：拦截走实时位置级判定（雷达圈几何当场算），与迷雾标志无耦合——与用户观察一致。
5. **不是节流问题**（用户猜测排除）：是"切国重建链缺两步"。

## 二、修复（R4c163）

- 单点替换：`setPlayerCiv` 内 `buildFogOfWar(iCivID)` → **`fogRefresh()`**（全量链）。
- 覆盖全部调用方：沙盒选国按钮（$1/$33）、事件 `EventOutcome_PlayerChangeCiv`。
- 旁路登记（本轮未动）：`InGame_Sandbox$2`（选国过渡态 civ0）、`ProvinceTouchExtraAction$24`（长按切国，本身不重建任何迷雾）、`GameLost$2`（旁观）、`ReleaseAVassal$7`（随从接管）——如后续使用中发现同类现象再收编。
